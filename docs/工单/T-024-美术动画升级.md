# T-024 · Spider-Man 主题美术再升级（M23 续 · 动画 + 美术 + 音效）

## 一入一出（In/Out）
- **入**：M23 把纯色块升级成了**程序化蜘蛛侠主题渲染**（面具/蛛网地板/怪物图标/攻击蛛丝/
  蜘蛛感应脉冲/主题 HUD），但仍是「静态贴图 + 轻量淡出特效」——角色不会动、攻击只有一缕
  静止蛛丝、没有脚步与摆荡音、暗处与亮处视觉差别仅靠色调。用户选了 **M23 续 · 主题美术再升级**，
  路线为**纯程序化动画 + 美术再升级 + 音效升级**（零素材文件、确定性满分、自包含）。
- **出**：在**不碰 `Game` 核心、不引入随机、确定性不变**的前提下，让窗口「活起来」：
  1. **动画框架**：所有动画由 renderer 的 `self.frame` 计数器驱动（每帧 +1），纯几何、零随机、
     不读写任何游戏状态 ⇒ #1/#2/#8 不破。
  2. **地形多帧预渲染**：地板蛛网纹理/墙砖缝做相位微动（蛛网轻闪、砖缝呼吸），按 `self.frame`
     在预渲染帧间切换；小 cell（<16）仍只渲染单帧，保证 headless 测试轻量。
  3. **玩家动画**：待机呼吸（轻微上下浮动）；攻击时朝目标**突进**（读取活动 web 特效方向）；
     受击红闪（对比 `player_hp` 跨帧变化，纯视图）。蜘蛛侠面具本身不变。
  4. **怪物动画**：待机上下浮动 + 红眼/蓝眼**眨眼**（眼形/亮度随相位振荡）；`M/m/~` 三种仍区分。
  5. **攻击动画**：蛛网从玩家→目标**行进**（按 progress 伸长），命中处迸发**火花环**（新 effect
     类型 `burst`），替代 M23 的静态一缕丝；蛛网/闪光仍是 renderer 视图状态、按帧衰减、不回写 `Game`。
  6. **蜘蛛感应升级**：`?` 预警从单团脉冲改为**扩散同心环**（2~3 圈随帧外扩淡出），更贴合
     「tingling」的警报感；纯视图。
  7. **氛围层**：① 暗角 vignette（四角径向压暗，noir 纽约夜色）；② 开灯房间**光晕**（仅
     `light_enabled` 时，按 `game.light_level_at` 在明亮格上叠柔光），强化「黑暗三重削弱」的
     视觉反馈。两层皆半透明叠加、不碰状态。
  8. **音效升级**：在 M23 的 thwip/闷响之上**程序化合成**更多短音——脚步（移动 tick）、
     蛛网摆荡 whoosh（扫频）、蜘蛛感应刺痛（高频短鸣）、胜利号角、落败 sting；
     `pygame.mixer` 懒初始化、整段 `try/except` 包裹、不可用则 `sound_on=False` 静默、
     **绝不读写游戏状态**。
  9. `tests/test_gui.py` 扩充 M24 单测（动画帧/多帧 draw/特效/氛围/音效/渲染纯净/确定性回归）；
     `python scripts/gate.py` 四道门全绿。

## 范围边界
- **只换视图层，不动玩法内核**：所有动画/美术/音效用 `pygame` 图元**程序化绘制/合成**
  （不依赖任何外部 png/字体/音频素材，保持自包含、可复现、确定性）；只读 `Game` 公开状态
  （grid/render()/monsters/items/stairs/switches/visible/light_enabled/light_level_at/
  spider_sense/player_hp…），只调 `_handle_key` + `monster_turn`，不新增随机、不修改 `src/rogue/*`。
- **动画是 renderer 自身视图状态**：帧计数器 `self.frame` 由 `draw()` 每帧 +1；蛛网/火花/闪光/
  脉冲存于 `self.effects`，按帧衰减；对比 `player_hp`/`px,py` 的跨帧差异只用于触发视图特效与音效、
  **不回写 `Game`**；确定性回归测试走 `apply_keys`（不经特效/音效路径），仍与终端逐字节同态。
- **音效纯装饰**：懒初始化、整段 `try/except`、不可用则 `sound_on=False` 静默；音效从不读写
  游戏状态 ⇒ #2 不变。
- **headless 友好**：沿用 M22 的 `SDL_VIDEODRIVER=dummy` 守卫 + pygame 缺失 skip；小 cell
  （<16）跳过精细纹理与多帧，保证测试轻量且不崩。
- **opt-in（默认关闭）**：`--gui` 才进窗口；默认仍是脚本 demo / `--play` 终端，行为零回归。

## 不变量增量
- **#24 GUI 动画与美术升级纯净**：`PygameRenderer` 的动画/美术/音效升级只读 `Game` 公开状态、
  只调 `Game` 既有确定性方法（经 `_handle_key`），不引入任何随机 ⇒ #1/#2 不变；动画全部由
  renderer 的 `self.frame` 计数器驱动（每帧 +1，纯几何、零随机）；地形多帧预渲染、玩家呼吸/
  突进/受击红闪、怪物浮动/眨眼、蛛网行进/火花迸发、蜘蛛感应扩散环、暗角/开灯光晕均为 renderer
  自身视图状态（按帧衰减、不回写 `Game`）；`tile_color`/`pixel_pos`/`translate_key`/`apply_keys`
  行为不变（M22/M23 测试钉死的字面契约仍成立）；合成音效懒初始化、失败静默、不读写游戏状态；
  GUI 主循环与 `--play` 终端路径同构（共用 `_handle_key`）⇒ 同 seed+同输入序列 ⇒ 同结果
  （#2，机器判定 `tests/test_gui.py`）；`--gui` 为 opt-in，默认（无 `--gui`）仍走脚本 demo /
  `--play` 终端，行为零回归。
