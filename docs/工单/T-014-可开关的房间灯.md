# T-014 · 可开关的房间灯（M14 · 蛛网射灯）

## 一入一出（In/Out）
- **入**：M11 把「光」做成了环境层——房间中心有固定灯、走廊昏暗。M12 给了玩家**随身**手电
  （玩家处的动态光源），但**房间灯仍是静态的**：玩家无法主动改变房间的亮度。
  蜘蛛侠的蛛网发射器本该能「射中天花板灯的拉链」——把静态光源变成可操作的互动元素。
  接力棒给 M14 的候选方向之一正是「可开关的房间灯（蛛网射中灯开关）」。
- **出**：一套**纯几何、零随机**的可开关房间灯——
  1. 复用 `light` 开关（不新增开关）：M14 只在 `light=True` 时有意义；`light=False` ⇒
     `toggle_light` 是 no-op（没有灯可关），M1~M13 一字节不变（与 M12/M13 同一哲学）。
  2. `Game` 新增 `switched_lights: set[Tile]`（已关灯的房间中心坐标，默认空）与
     `can_toggle_light(x, y)` / `toggle_light(x, y)`：蛛网射中房间中心灯的拉链，翻转该房间的灯。
     三条硬约束：光照开启 + 目标是房间中心 + 玩家**看得见灯**（`has_line_of_sight`）且在射程内
     （切比雪夫 ≤ `WEB_LIGHT_RANGE=6`，含脚下——站在灯正下方伸手就能够到）。
  3. `_light_sources()` 跳过 `switched_lights` 里的房间 ⇒ 关灯后房间变暗
     （M11 暗处缩短怪物感知 + M13 暗处缩短玩家视野——**双刃**：暗处的怪看不远、你也看不远）。
  4. M8 联动：拉链的轻响 `NOISE_TOGGLE_LIGHT=3` 从**灯处**传出（声源不在玩家脚下）⇒
     可作调虎离山的**轻量**手段（比垃圾盖 9 轻、只惊动近处的人，但同时把房间弄暗）。
  5. `toggle_light` 只翻集合 + 重算光照场 + 重算可见集合（`update_fov`），不消耗 `RandomSource`、
     不改写 `grid`/HP/背包/怪物状态（与 `toggle_flashlight` 同一零副作用哲学）；换层（`load_level`）重置。
  6. `render()` 字形一字不差（关灯只改光照场与可见集合，不改字形，#8 延伸）；
     `light=False` 时 `toggle_light` 恒返回 False（no-op）⇒ 既有 342 例零侵入。

## 验收分级
- **A（必过，门禁）**：`tests/test_light_switch.py` 全绿——
  - 关灯是**纯几何、零随机**：`toggle_light` 不引入随机模块、不消耗 `RandomSource`（seed-guard 仍只放行 `rng.py`）。
  - M14 默认关闭（light=False）⇒ `toggle_light` 恒返回 False、不改任何状态（`TestToggleLightDefault`）。
  - 关灯只移除光源（不新增光源）⇒ 光照场只变暗不变亮 ⇒ 有效半径恒 ≤ `SIGHT_RADIUS`(8) ⇒
    机器判定「怪看得见你 ⇒ 你看得见它」在 `light+fov+stealth` 下仍成立（`TestToggleLightSymmetry`）。
  - `render()` 字形在关灯前后**逐字相同**（fov=False 路径）；可见格子仍用原字形（`TestToggleLightRenderPurity`）⇒ 既有 342 例零侵入。
  - 确定性：同 seed + 同输入 ⇒ 同光照场；关灯不消耗随机（`TestToggleLightDeterminism`）。
  - M8 联动：关灯发出 `NOISE_TOGGLE_LIGHT` 响动，声源在**灯处**（不是玩家处）⇒ 调虎离山成立（`TestToggleLightNoise`）。
  - 换层重置：`descend` → `load_level` 清空 `switched_lights`（`TestToggleLightReset`）。
  - `python scripts/gate.py` 四道门 ALL GREEN，棘轮 342 → 372+。
- **B（建议）**：`python main.py --light --stealth` 下蜘蛛侠会主动射灭未察觉敌人所在房间的灯
  （缩短其感知半径 ⇒ 更容易摸哨）；不加 `--light` 的前三条演示（默认/潜行/听觉）与 M13 逐字节一致。
  四条 `--light` 演示（`--light` / `--light --stealth` / `--flashlight` / `--flashlight --stealth`）
  展示关灯战术（`--light --stealth` 才主动关灯，其余三条不关）。
- **C（可选）**：可破坏的灯（一次性、不可恢复）；灯开关作为独立实体（墙上的开关 tile）；
  按地形类型给不同底色；光照影响记忆衰减。

## 范围边界
- **M14 只在 `light=True` 时有意义**：`light=False` ⇒ `_light_sources` 不含房间灯（关不关都一样，
  光照场为空）⇒ `toggle_light` 恒返回 False。不新增开关，复用 `light`（与 M13 同一哲学）。
- **只移除光源、不新增**：关灯把房间灯从 `_light_sources` 里拿掉 ⇒ 房间变暗（DARK/DIM）；
  开灯把房间灯加回去 ⇒ 恢复明亮（LIT）。光照场只变暗或恢复，不会比 M11 更亮 ⇒ #9/#12/#14 不破。
- **不引入任何随机**：`toggle_light` 只翻 `switched_lights` 集合 + 重算 `light_field` + 重算 `visible`，
  纯几何、零随机（与 `toggle_flashlight` 同一零副作用哲学）。
- **声源在灯处、不在玩家处**：`emit_noise(light_x, light_y, NOISE_TOGGLE_LIGHT)`——
  与 M8「被蛛网弹缠住的怪挣扎出声」同一原则（声源未必是玩家）⇒ 调虎离山成立。
- **不改 `render()` 字形**：关灯只改变 `light_field`（影响 M11 怪物感知 + M13 玩家视野）与 `visible`
  （哪些格子可见），不改变可见格子的字形（#8 延伸）。
- **不改 M6 的「进房间点亮整间」规则**：关灯后玩家站在该房间里仍能点亮整间（M6 规则保留）；
  M14 只缩短「跨房间」视野（从走廊看进暗房间看不远），这是预期效果，与 M13「暗处近视」一致。

  声源在灯处（不在玩家处）⇒ M8 调虎离山成立；`toggle_light` 只翻集合 + 重算场，不改写任何玩法状态（换层重置）。

- #8 渲染纯净性（延伸）：关灯只改光照场与可见集合，不改 `render()` 字形。

## 常量表
| 常量 | 值 | 含义 |
|---|---|---|
| `WEB_LIGHT_RANGE` | 6 | M14 蛛网射灯开关的射程（切比雪夫距离，含脚下；与 `DECOY_RANGE` 同值，比视野 8 短） |
| `NOISE_TOGGLE_LIGHT` | 3 | M14 灯开关拉链的轻响（声源在灯处；介于 `NOISE_SNEAK=2` 与 `NOISE_PUNCH=6` 之间） |
| `ROOM_LIGHT_RADIUS` | 9 | 房间中心固定光源半径（M11，关灯时该光源被移除） |

## 设计决策
| 决策 | 选择 | 理由 |
|---|---|---|
| 翻转（toggle）而非一次性破坏 | 是 | 「可开关」= 可重复翻转；主题上即蛛网拉链（拉一下关、再拉一下开）；演示可展示「关灯摸哨 → 开灯清扫」 |
| 复用 `light` 开关，不新增开关 | 是 | M14 是 M11 光照系统的「光源可操作性扩展」，不是新感知通道；light=False ⇒ 没有灯可关 |
| 目标必须是房间中心 | 是 | 灯装在天花板中央（M11 光源位置）；射歪的蛛网打不到拉链 ⇒ 不消耗状态 |
| 射程含脚下（距离 0） | 是 | 站在灯正下方伸手就能够到拉链；与 `can_throw`「甩出去必须离开自己」不同（射灯不是甩东西） |
| 声源在灯处、不在玩家处 | 是 | 拉链的声响从灯那儿传出去 ⇒ 调虎离山（与 M8「被缠住的怪挣扎出声」同一原则） |
| 不改 M6「进房间点亮整间」规则 | 是 | 改它需传 `switched_lights` 给 `visible_tiles`、动 M6/M13 既有规格；关灯的跨房间效果已足够 |
| 换层重置 `switched_lights` | 是 | 新楼层 = 新房间 = 新灯；与 `explored` 清空同一时机（`load_level`） |
