# T-013 · 光照影响玩家自身视野（M13）

## 一入一出（In/Out）
- **入**：M11 把「光」做成了环境层——房间有灯、走廊昏暗，暗处的怪是近视眼。但光照**只缩短怪物感知半径**，
  玩家自己的视野（M6）仍按固定 `SIGHT_RADIUS=8`：不管站在暗巷还是亮街，玩家都能看见 8 格内的东西。
  M12 的随身手电同样只动怪物感知侧。接力棒给 M13 的方向正是「让光照也压短玩家自己的视野半径」。
- **出**：一套**纯几何、零随机**的光照影响玩家视野——
  1. 复用 `light` 开关（不新增开关）：M13 只在 `light=True` 且 `fov=True` 时生效；
     `light=False` 或 `fov=False` ⇒ `visible_tiles` 走 M6 原逻辑（`light_field=None` ⇒ 固定半径 8），
     与 M1~M12 逐字节一致。
  2. `fov.py` 新增 `PLAYER_SIGHT_DARK=2` / `PLAYER_SIGHT_DIM=4` 常量与 `player_sight_radius(light_lvl)` 函数；
     `visible_tiles` 扩展可选 `light_field` 参数，光照开启时逐格查**目标格光照**、按 `player_sight_radius` 算有效视野半径。
  3. `Game.update_fov` 光照开启时先 `update_light`（算光照场）、再传 `light_field` 给 `visible_tiles`。
  4. 玩法：走廊暗处（DARK）⇒ 玩家只能看 2 格（微光区 LIT/DIM 仍按各自半径算）；
     房间亮处（LIT）⇒ 能看 8 格；从暗处看亮处看得清、从亮处看暗处看不清。
     手电开 ⇒ 玩家周围更亮 ⇒ 暗走廊格子从 DARK 升到 LIT/DIM ⇒ 玩家视野恢复（手电双刃性更立体）。
  5. `render()` 字形一字不差（可见集合变小但不改字形，#8 延伸）；进房间点亮整间规则保留。

  - 光照影响玩家视野是**纯几何、零随机**：不引入随机模块、不消耗 `RandomSource`（seed-guard 仍只放行 `rng.py`）。
  - M13 默认关闭（light=False 或 fov=False）⇒ 走 M6 原逻辑，与 M1~M12 逐字节一致（`TestLightFovSwitch`）。
  - 按目标格光照算视野半径，同档位下 `player_r ≥ monster_r` ⇒ 机器判定「怪看得见你 ⇒ 你看得见它」
    在 `light+fov+stealth` 下仍成立（`TestLightFovSymmetry`）。
  - `render()` 字形在光照开/关下逐字相同（fov=False 路径）；可见格子仍用原字形（`TestLightFovRenderPurity`）⇒ 既有 306 例零侵入。
  - 确定性：同 seed + 同输入 ⇒ 同可见集合；光照不消耗随机（`TestLightFovDeterminism`）。
  - `python scripts/gate.py` 四道门 ALL GREEN，棘轮 306 → 342。
- **B（建议）**：`python main.py --light` 下走廊里玩家看不远（暗处近视）；`python main.py --light --stealth`
  下摸黑潜行有真正的视野代价；`python main.py --flashlight` 下开灯能看清暗处（手电双刃性更立体）。
  默认 / 潜行 / 听觉三条演示不加 `--light` 时逐字节不变。
- **C（可选）**：让光照也影响蜘蛛感应半径（目前穿墙预警不受光照约束）；环境光照场（不含微光）与完整光照场分离；
  按地形类型给不同底色；光照影响记忆衰减（暗处记忆更快模糊）。

## 范围边界
- **M13 只在 `light=True` 且 `fov=True` 时生效**：`fov=False` 时全图渲染不用 `visible`，光照只影响怪物感知+颜色；
  `light=False` 时 `light_field` 为空，`visible_tiles` 走 M6 原逻辑。
- **按目标格光照算，不按玩家所在格**：玩家微光让脚下恒 LIT，按玩家所在格算会退化为「视野永远 8」；
  按目标格算则「走廊暗处看不远、房间亮处看得清」，与「暗处近视」的直觉一致。
- **不引入任何随机**：`visible_tiles` 的 `light_field` 分支只查光照场+算距离+判视线，纯几何、零随机。
- **只缩短、不放大**：有效半径恒 ≤ `SIGHT_RADIUS`(8)（暗处缩短、亮处不变）⇒ #9 对称硬性质的数学前提。
- **不改 `render()` 字形**：光照只改变 `visible` 集合（哪些格子可见），不改变可见格子的字形（#8 延伸）。

## 不变量摘录（落 M13）
- #14 光照影响玩家视野（新）：纯几何、零随机；默认关闭（light=False 或 fov=False ⇒ M6 原逻辑）；
  按目标格光照算视野半径，有效半径恒 ≤ `SIGHT_RADIUS`(8)，同档位下 `player_r ≥ monster_r` ⇒ #9 对称硬性质不破。
- #1 随机仅经 `RandomSource`：`fov.py` 的 `visible_tiles` 与 `player_sight_radius` 不引入任何随机调用。
- #2 回合确定性：视野只依赖 `grid` + 玩家坐标 + `light_field` ⇒ 同状态同可见集合，不消耗随机、不扰动回放。
- #8 渲染纯净性（延伸）：光照只改变 `visible` 集合，不改 `render()` 字形。
- #9 感知/潜行确定性（延伸）：按目标格光照算，同档位下 `player_r ≥ monster_r` ⇒ 对称硬性质不破。

## 常量表
| 常量 | 值 | 含义 |
|---|---|---|
| `PLAYER_SIGHT_DARK` | 2 | M13 全黑处玩家视野半径（= MONSTER_SIGHT_DARK，对称） |
| `PLAYER_SIGHT_DIM` | 4 | M13 昏暗处玩家视野半径（= MONSTER_SIGHT_DIM，对称） |
| `SIGHT_RADIUS` | 8 | 明亮处玩家视野半径（= M6 原值，不变） |

## 设计决策
| 决策 | 选择 | 理由 |
|---|---|---|
| 按目标格光照算，不按玩家所在格 | 是 | 玩家微光让脚下恒 LIT，按玩家所在格算退化为「视野永远 8」；按目标格算则「暗处近视、亮处正常」 |
| 复用 `light` 开关，不新增开关 | 是 | M13 是 M11 光照系统的「影响面扩展」（从怪物感知侧扩展到玩家视野侧），不是新能力 |
| 只在 `light=True` 且 `fov=True` 时生效 | 是 | `fov=False` 时全图渲染不用 `visible`；`light=False` 时无光照场可查 |
| 进房间点亮整间规则保留 | 是 | 光照开启时房间内格子 LIT ⇒ 半径 8 ⇒ 与 M6 一致；保留作为兜底 |
| 不影响蜘蛛感应 | 是 | 感应是超能力（穿墙预警），不受光照约束；半径刻意小于视野 |
