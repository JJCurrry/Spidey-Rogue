# T-030 · 交互式射灯 / 碎灯 UI（M30）

## 一入一出（In/Out）
- **入**：HANDOFF-T001「下一步候选」明确——「交互式射灯 / 碎灯 / 开关（M14/M16/M19 的玩家可控版）」：
  `_handle_key` 当前未覆盖「选定某个房间灯 / 墙边开关」的目标选择，仍由 demo 自动战术承担
  （`_player_act` 的 `_light_to_destroy` 自动射碎未察觉敌人所在房间的开关）；玩家在
  `--play` / `--gui` / 网页版下无法手动选择射灭 / 射碎哪个开关，潜行玩法的核心决策权没交到玩家手里。
- **出**：
  1. 新增 `src/rogue/aim_state.py`：瞄准模式**控制层视图状态**（不属于 `Game` 状态）。
     - 模块级 `_AIM` 字典（`active` / `x` / `y`）+ helper 函数：
       `enter(px, py)` / `exit()` / `move(dx, dy, game)` / `is_active()` / `cursor()` / `reset()`；
     - `move` 受 `game.in_bounds` 约束、不引入随机、不写 `Game` 状态；
     - 测试可 `reset()` 复位，保证用例间隔离。
  2. `main.py::_handle_key`：在最前面加瞄准模式分支（只在 `aim_state.is_active()` 时接管）。
     - **进入瞄准**（`T`）：`aim_state.enter(game.px, game.py)`，不消耗回合（`acted=False`）；
       未启用开关（`not game.switches_enabled or not game.light_enabled`）时友好提示、不进入。
     - **瞄准模式下方向键 / WASD / HJKL**：`aim_state.move(dx, dy, game)`，不消耗回合。
     - **确认射灭 / 射亮**（`Enter` / 空格）：调 `game.toggle_switch(x, y)`，成功 ⇒ 消耗回合
       （`acted=True`，调用方随后跑 `monster_turn`）；够不着 ⇒ `acted=False` + 友好提示。
     - **射碎**（`X`）：调 `game.destroy_switch(x, y)`，成功 ⇒ 消耗回合；够不着 ⇒ `acted=False`。
     - **退出瞄准**（`Esc` / `Q` / `T`）：`aim_state.exit()`，不消耗回合。
     - 瞄准模式下其它键被忽略（`acted=False` + 提示「瞄准模式：方向键移动 / Enter 射灭 / X 射碎 / T 退出」）。
  3. `main.py::CONTROLS_HELP`：补瞄准模式说明（`T` 进入瞄准 / 方向键移动光标 /
     `Enter` 射灭射亮 / `X` 射碎 / `T`/`Esc` 退出）。
  4. `main.py::_colored`（终端 `--play` 路径）：瞄准模式下高亮光标格（用 ANSI 反相 /
     方括号包住该格字符），让终端玩家也能看见光标位置；不改 `game.render()` 字形（#8 延伸）。
  5. `src/rogue/render_pygame.py::draw`：在画完地图 / 特效后，若 `aim_state.is_active()` 则
     画光标——目标格画十字准星 + 高亮边框（黄色方框 + 中心十字），并按 `game.can_toggle_switch` /
     `game.can_destroy_switch` 给出绿/红颜色提示（绿=可射灭、红=可射碎、灰=够不着）。
     renderer 只读 `aim_state`、不写它（与 `self.effects` 同性质，#8 延伸）。
  6. `tests/test_aim_mode.py`：≥10 例钉死不变量 #30。

## 范围边界
- **只加控制层视图状态，不改 `Game` 核心**：`aim_state` 是 main / renderer 共享的模块级
  控制层状态，与 `self.effects` 同性质——只决定「画面上画什么 / `_handle_key` 怎么解析按键」，
  不写 `Game` 任何字段、不调 `RandomSource` ⇒ #1/#2/#8 延伸不破（不变量 #30）。
- **复用 M19 几何约束**：确认射灭 / 射碎时调 `game.can_toggle_switch` / `can_destroy_switch`
  （已包含「开关未启用 / 看不见 / 射程外 / 已碎」全部判定），够不着 ⇒ `acted=False` + 友好提示、
  不消耗回合、不改 `Game` 状态。本里程碑**不引入新的几何判定**。
- **opt-in 默认零回归**：不按 `T` 不进入瞄准，`aim_state.is_active()` 恒 `False` ⇒
  `_handle_key` 走原有分支、`_colored` 不高亮、`draw` 不画光标 ⇒ 与 M29 逐字节一致。
  默认 / 潜行 / 听觉 / 光照 / 手电 / Boss 演示不受影响（balance_check 不变）。
- **瞄准不消耗回合**：进入 / 退出 / 移动光标都不调 `monster_turn`，只有确认射灭 / 射碎成功
  （`acted=True`）才由调用方跑 `monster_turn`——这是潜行玩法的核心：玩家可以反复瞄准不惊动敌人，
  只有真正出手才付出回合代价。
- **光标范围**：可在 `game.in_bounds` 内自由移动（不限于射程内，让玩家看见「够不着」的反馈）；
  确认时几何约束拦下、返无效信息。这比「限制光标在射程内」更友好——玩家能学到射程边界。
- **`Q` 在瞄准模式下退出瞄准而非退出游戏**（避免误触退出）；瞄准模式下要退出游戏需先 `T`/`Esc`
  退出瞄准再按 `Q`。这是瞄准模式的「模态」语义。
