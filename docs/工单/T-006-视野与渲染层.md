# T-006 · 视野 / 渲染层（M6）

## 一入一出（In/Out）
- **入**：M1~M5 的 `render()` 是「全图可见」——整张楼层连走廊带怪物一起铺在屏幕上，玩家没有探索感，也没有「拐角后面是什么」的紧张感。
- **出**：玩家只能看见**视线内**（半径 + 无遮挡）的区域；走进房间点亮整间（复用 M5 的 `Game.rooms`）；走过的地方留下**记忆**（地形/楼梯/补给保留，怪物只在可见时显示）；墙后的近处威胁靠**蜘蛛感应**以 `?` 提示轮廓。视野是**可选开关**，默认关闭，保证既有 79 例规格不被破坏。

## 委托级别
- **S（自主完成）**：范围清晰（只加渲染层，不改战斗/AI/生成数值）、红线明确（#1/#2 沿用，#8 本单新增并补机器检查）、无外部依赖、复用 M5 的 `Game.rooms` 与 `tiles.py` 常量。

## 验收分级
- **A（必过，门禁）**：`tests/test_fov.py` 全绿——
  - 开关：默认 `Game(rng=...)` 关闭视野（全图渲染），`fov=True` / `Game.procedural(rng, depth=1, fov=True)` 开启迷雾；既有 79 例规格全部不受影响。
  - 视野几何：玩家所在格恒可见；`visible ⊆ explored`；墙后的格子不可见；超出 `SIGHT_RADIUS` 的格子不可见；玩家所在房间的**全部**格子可见（室内照明，超出半径也亮）。
  - 记忆：走过的格子在看不见之后仍显示地形；楼梯 `>` 与道具 `!` 一旦被看见就留在记忆里；怪物只在可见时显示。
  - 蜘蛛感应：切比雪夫距离 ≤ `SPIDER_SENSE_RADIUS` 的存活怪，即使不可见也渲染为 `?`；超出半径或已阵亡则不提示；可见的怪仍渲染为 `M`（`M` 优先于 `?`）。
  - 渲染优先级：`?` < 楼梯 `>` < 道具 `!` < 怪物 `M` < 玩家 `@`（沿用 M5 的 楼梯<道具<怪物<玩家）。
  - 下潜：`descend()` 后清空记忆，新楼层重新探索。
  - **不变量 #8**：`render()` 只依赖地形 + 实体 + 玩家位置，不引入随机（#1/#2），且**不改写** `grid` / 玩家 / 怪物 / 道具状态（唯一例外是「已探索记忆」单调增长）。
  - `python scripts/gate.py` 四道门 ALL GREEN。
- **B（建议）**：`python main.py` 演示开启迷雾——打印图例，地图随移动逐格点亮，`?` 提示拐角后的威胁；`--no-fog` 可切回全图。
- **C（可选）**：光照衰减（火把半径）、颜色/高亮（ANSI）、怪物视野与潜行、阴影投射（shadowcasting）替换射线法。

## 范围边界
- 不含怪物视野/感知（怪物 AI 仍按 M3 行为，不引入「怪物看得见玩家才追」）。
- 不含颜色与 UI 框架（纯终端 ASCII，新增字符只有空白与 `?`）。
- **视野默认关闭**：与 M5 的「教学图默认、程序化显式开启」同一哲学——新能力不改写既有规格，需显式 opt-in。
- 视野**纯几何、无随机**（不消耗 `RandomSource`），因此不会扰动既有随机序列（#2 的伤害/掉落/生成序列完全不变）。
- 射线法（每个候选格一条 Bresenham 线）而非 shadowcasting：地图只有 33×17，够快且更好懂；C 级再考虑替换。

## 不变量摘录（落 M6）
- #1 随机必须 Seed 注入：`fov.py` **不含任何随机**，也不引入随机模块（seed-guard 拦截）。
- #2 回合确定性：视野只依赖 `grid` + 玩家位置 + `rooms`，同状态 ⇒ 同 `visible`；且不消耗 rng ⇒ 战斗/掉落/生成的随机序列不受影响。
- **#8 视野/渲染纯净性（本单新增）**：`render()` 只依赖地形 + 实体 + 玩家位置；**不改写** `grid`、玩家、怪物、道具的任何状态，唯一允许的写入是「已探索记忆」集合单调增长（`explored |= visible`）。
  - 机器判定：`tests/test_fov.py::TestRenderPurity` / `TestFovDeterminism`。

## 视野参数与图例
| 常量 | 值 | 含义 |
|---|---|---|
| `SIGHT_RADIUS` | 8 | 视野半径（欧氏距离，超出即不可见） |
| `SPIDER_SENSE_RADIUS` | 4 | 蜘蛛感应半径（切比雪夫距离，**穿墙**、只看轮廓） |

| 渲染字符 | 含义 |
|---|---|
| `@` | 蜘蛛侠（恒可见） |
| `M` | 视野内的敌人 |
| `?` | **蜘蛛感应**：看不见但能感知到的威胁轮廓（4 格内穿墙生效） |
| `!` | 补给（看见过就留在记忆里） |
| `>` | 下行楼梯（看见过就留在记忆里） |
| `#` / `.` | 墙 / 地板（走过即记忆，未探索处为空白） |
| ` ` | 未探索区域 |

## 设计决策
| 决策 | 选择 | 理由 |
|---|---|---|
| 默认开关 | 关闭（opt-in） | `test_level.py::test_render_shows_stairs` 等既有规格断言「全图可见」，默认开会把它们打破；熔断②禁止改测试凑绿 |
| 算法 | Bresenham 射线 | 地图 33×17、半径 8 ⇒ 每帧约 200 条线，开销可忽略；代码可读，便于门禁审查 |
| 室内照明 | 玩家所在房间整间点亮 | 复用 M5 的 `Game.rooms`（HANDOFF 下一步指令 3）；房间最大 8×5，点亮后不会出现「站在房里却看不见房角」的割裂感 |
| 记忆内容 | 地形 + 楼梯 + 道具，**不含**怪物 | 楼梯/道具不动（记忆可信），怪物会移动（记忆会骗人） |
| 蜘蛛感应 | 4 格切比雪夫、穿墙、只给 `?` | 契合 MCU 荷兰弟版「Peter Tingle」设定；比视野半径小（8），是预警不是透视 |
