# T-020 · 光照影响蜘蛛感应半径（M20）

## 一入一出（In/Out）
- **入**：M19 完成后，接力候选里唯一剩余项即为「让光照也影响蜘蛛感应半径」
  （`SPIDER_SENSE_RADIUS=4` 穿墙预警目前不受光照约束）。交接文件写明「主题上是否该受光照约束需先定调」，
  经确认采用**对称衰减**方向：蜘蛛感应半径也随光照衰减，与 M11 怪物感知、M13 玩家视野形成「黑暗三重削弱」。
- **出**：一套**纯几何、零随机**的改造——
  1. `src/rogue/fov.py` 新增常量 `SPIDER_SENSE_DARK=2` / `SPIDER_SENSE_DIM=3` 与纯函数
     `spider_sense_radius(light_lvl)`（暗 2 / 昏暗 3 / 明 4 = `SPIDER_SENSE_RADIUS`），只缩短不放大、恒 ≤ 4。
  2. `src/rogue/game.py::spider_sense()` 在 `light_enabled` 时按怪物所在格光照算有效半径
     （`spider_sense_radius(self.light_level_at(m.x, m.y))`），`light=False` 时半径恒为 `SPIDER_SENSE_RADIUS`
     ⇒ 与 M1~M19 逐字节一致（零回归）。
  3. **opt-in（默认关闭）**：`light=False` ⇒ 行为完全等同 M19；只有 `light=True` 且存在黑暗格时，
     远处暗处威胁的 `?` 预警才会收缩（最小半径 2，避免彻底无预警）。

## 范围边界
- **完全复用 M13 的光照定义**：感应半径衰减读 `light_level_at(目标格)`（完整场：房间灯 + 玩家微光 + 手电），
  与 M13 玩家视野「按目标格光照算」完全对称；不改 `render()` 字形（#8 延伸）。
- **只缩短不放大**：有效半径恒 ≤ `SPIDER_SENSE_RADIUS`(4)（暗 2 / 昏暗 3 / 明 4），
  所以「怪看得见你 ⇒ 你看得见它」的 #9 硬性质不破（感应半径恒 ≤ 视野/感知半径）。
- **opt-in（默认关闭）**：`light=False` ⇒ `spider_sense()` 走常量 4，`render()` 行为与 M1~M19 一字不差；
  只有 `--light` 路径（含 `--flashlight`）且存在黑暗格时，远处暗处威胁的 `?` 预警才收缩。
- **最小半径 2 兜底**：即便全黑，距 ≤ 2 的威胁仍会被预警，避免「彻底无感」破坏超能力设定。
- **不改任何玩法状态**：`spider_sense()` 仍是纯查询（只读 `grid` + `light_field` + 坐标），不改写怪物/HP/背包/光照场；
  `render()` 纯净性（#8）仍成立。

## 不变量增量
- **#20 光照影响蜘蛛感应半径**：M6 的蜘蛛感应（穿墙预警 `?`）在 `light=True` 时半径随目标格光照衰减
  （暗 2 / 昏暗 3 / 明 4），与 M11 怪物感知、M13 玩家视野形成「黑暗三重削弱」对称；
  纯几何、零随机、不消耗 `RandomSource`；默认关闭（`light=False` ⇒ 半径恒 4，与 M1~M19 逐字节一致）；
  只缩短不放大、恒 ≤ `SPIDER_SENSE_RADIUS`(4)、暗处保留最小半径 2 ⇒ #9 对称硬性质不破；
  `render()` 字形一字不差（#8 延伸）。
