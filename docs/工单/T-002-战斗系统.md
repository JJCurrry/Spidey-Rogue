# T-002 · 战斗系统（M2）

## 一入一出（In/Out）
- **入**：M1 已具备格子地图 + 玩家移动；本里程碑在 `Game` 上叠加战斗层，仍用固定地图、手摆怪物（AI 留 M3）。
- **出**：玩家有 HP；相邻怪物可被「蛛网拳」攻击，伤害 = 基础 + Seed 注入的随机浮动；怪物 HP 归零即死；玩家 HP 永不为负（引擎钳制）；相同 seed + 相同攻击序列 ⇒ 相同战斗结果。

## 委托级别
- **S（自主完成）**：范围清晰、红线明确（#1/#2/#3）、无外部依赖。

## 验收分级
- **A（必过，门禁）**：`tests/test_combat.py` 全绿——含玩家 HP 初始/不为负、攻击减怪血、怪物归零、不可攻击非相邻、反击扣玩家血、Seed 同种子同结果（确定性 #2）、伤害范围与随机参与（#1）、移动被怪物阻挡；`python scripts/gate.py` 四道门 ALL GREEN。
- **B（建议）**：`python main.py` 能演示一次完整战斗（玩家攻击至怪物倒下）。
- **C（可选）**：多种招式 / 暴击 / 多怪物围攻结算。

## 范围边界
- 不含怪物 AI（追击/随机游走 → M3）、道具/背包（M4）、程序化关卡（M5）。
- 怪物由外部 `spawn_monster` 手摆；本里程碑不引入生成随机（生成随机属 M5/#1 范畴）。
- 反击采用固定值，保持简单；随机仅用于伤害浮动，且必须经 `RandomSource`（红线 #1）。

## 不变量摘录（落 M2）
- #1 随机必须 Seed 注入：`player_attack` 的伤害浮动经 `self.rng.int`，禁止裸 `random`。
- #2 回合确定性：同 seed + 同输入序列 ⇒ 同结果（测试 `test_same_seed_same_result` 实证）。
- #3 玩家 HP 永不为负：由 `Monster.take_damage` 与 `Game._hurt_player` 的 `max(0, ...)` 保证。
