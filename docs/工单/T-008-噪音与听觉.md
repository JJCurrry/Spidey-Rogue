# T-008 · 噪音与听觉（M8）

## 一入一出（In/Out）
- **入**：M7 给了怪物「视觉」——只有看得见玩家时才会被惊动，潜行因此成立。但这条感知链只有一半：隔着两堵墙的敌人照样对你的打斗声毫无反应，而**被蛛网弹缠住的怪在走廊那头挣扎**也引不来同伴。玩家缺少「动静」这个变量 ⇒ 既没有「打完就撤」的压力，也没有「调虎离山」的手段。
- **出**：怪物有了**听觉**——响动沿可通行空间传播、穿过墙会衰减（每堵墙折掉 3 格传播距离），谁在传播范围内就被惊动，并扑向**声源**（不是玩家的实时位置）。于是「在这儿打一架」会把半条走廊的敌人引过来，而「用蛛网弹缠住远处那只」能把它的同伴引到它那儿去。画面上因声音（而非视线）被惊动的敌人画成 `~`——你知道它正在朝动静摸过来，但它还没看见你。走路本身无声（蜘蛛侠落地无响），只有**动作**才发声。听觉是**可选开关**，默认关闭，保证既有 168 例规格不被破坏。

## 委托级别
- **S（自主完成）**：范围清晰（只加听觉层 + 四个声源接入点，不改生成数值/掉落/背包/怪物表）、红线明确（#1/#2 沿用，#10 本单新增并补机器检查）、无外部依赖、复用 M6/M7 的 `grid` 只读几何与 `Monster.alert()` 唯一入口。

## 验收分级
- **A（必过，门禁）**：`tests/test_noise.py` 全绿——
  - 开关：默认 `Game(rng=...)` / `Game.procedural(rng, depth=1)` 关闭听觉；`noise=True` / `Game.procedural(rng, depth=1, noise=True)` 开启；既有 168 例规格全部不受影响。
  - 传播几何（纯函数 `noise_field` / `noise_reaches`）：声源处代价 0、恒被听到；沿空地每格代价 1；**穿墙代价 3**（隔一道墙 ≈ 只剩三分之一的传播距离）；超出响度即听不到；越界格不参与传播；响度 0 ⇒ 谁也听不见（连声源自己都算「有响度 0」⇒ 无人被惊动）。
  - 听觉判定：只有**存活**的怪物会被惊动；死怪不参与；被惊动者 `alerted=True` 且 `last_seen = 声源`（不是玩家位置）⇒ 声源不在玩家处时，怪物会被**误导**。
  - 四个声源接入点（仅 `noise=True` 时生效）：
    1. 蛛网拳（普通攻击）⇒ 玩家位置，响度 `NOISE_PUNCH`；
    2. 倒挂突袭 ⇒ 玩家位置，响度 `NOISE_SNEAK`（**远小于**普通攻击 ⇒ 摸掉哨兵未必惊动全层）；
    3. 蛛网弹命中 ⇒ **被缠住的怪物位置**，响度 `NOISE_STRUGGLE`（挣扎的动静把同伴引向它，这是「调虎离山」的成立条件）；
    4. 下潜落地 ⇒ 新层起点，响度 `NOISE_LANDING`（刚落地就惊动一圈人）。
  - 走路 / 拾取 / 吃三明治 / 注射纳米强化剂：**无声**（蜘蛛侠落地无响，主题自洽）。
  - 渲染：因声音被惊动（且尚未看见玩家）的敌人画 `~`；潜行关闭或听觉关闭时不会出现 `~` ⇒ 既有 `assertIn("M", render())` / `assertIn("m", ...)` 断言仍成立。
  - **不变量 #10**：噪音传播是纯几何、不消耗 `RandomSource`；「是否被听到」只经 `Monster.alert()` 这一唯一入口生效，不额外掷骰；听觉默认关闭。
  - `python scripts/gate.py` 四道门 ALL GREEN。
- **B（建议）**：`python main.py --noise` 演示听觉——「打完就撤」与「蛛网弹调虎离山」；
  状态栏显示上一次动静惊动了几只敌人；不加参数时演示与 M7 逐字节一致。
- **C（可选）**：光照衰减（暗处降低怪物感知半径）、ANSI 颜色高亮、主动制造响动（往远处甩东西引开巡逻）。

## 范围边界
- 不含光照衰减与颜色（见 C 级）：本单只加**听觉**这一条感知通道。
- 不含「主动制造响动」的独立道具/技能：`emit_noise(x, y, loudness)` 已经是公开 API，
  后续要加「往墙那头甩个罐子」只需给个入口，不必改传播层。
- **听觉默认关闭**：与 M5 的「教学图默认」、M6 的「视野默认关闭」、M7 的「潜行默认关闭」
  同一哲学——新能力不改写既有规格，需显式 opt-in。
- 传播**纯几何、无随机**；听觉只改变怪物的 `alerted` 状态，不改变「随机只从 `RandomSource` 流出」这一事实（#1），同一模式内仍满足 #2。
- 听觉**只惊动、不增伤**：被声音引来的怪仍要走到你面前才打得到你，与普通被发现的怪完全同权。

## 不变量摘录（落 M8）
- #1 随机必须 Seed 注入：传播与听觉判定**不含任何随机**；听觉只经 `Monster.alert()` 改 `alerted`。
- #2 回合确定性：传播只依赖 `grid` + 声源 + 响度 ⇒ 同状态 ⇒ 同结果；响度是常量表，不掷骰。
- #8 渲染纯净性：`emit_noise` 不在 `render()` 里被调用；`render()` 读 `alert_cause` 但不改写它。
- **#10 噪音 / 听觉确定性（本单新增）**：
  1. 声音传播（`src/rogue/sound.py::noise_field`）是**纯几何**计算——在 `grid` 上跑最短传播代价
     （空地 1、墙 3，Dijkstra），**不消耗 `RandomSource`**，只依赖 grid + 声源 + 响度；
  2. 「是否被听到」只经 `Monster.alert(...)` 这一**唯一入口**影响 `alerted`，不额外掷骰，
     不改 `grid` / 玩家 / 道具 / 怪物 HP（与 #3/#5/#6 无交集）；
  3. 听觉**默认关闭**（`noise=False`）⇒ M1~M7 的既有玩法与规格完全不变；
  4. 机器判定：`tests/test_noise.py::TestNoiseDeterminism`（rng 序列对照 + 同 seed 快照重放）。

## 响度常量表
| 常量 | 值 | 含义 |
|---|---|---|
| `NOISE_COST_FLOOR` | 1 | 声音沿空地传播一格 |
| `NOISE_COST_WALL` | 3 | 声音穿过一堵墙的代价（闷响 ⇒ 只剩三分之一距离） |
| `NOISE_PUNCH` | 6 | 蛛网拳（正面交手，动静传半条走廊） |
| `NOISE_SNEAK` | 2 | 倒挂突袭（闷哼，几乎无声） |
| `NOISE_STRUGGLE` | 7 | 被蛛网弹缠住的怪挣扎的动静（声源在**怪物**处） |
| `NOISE_LANDING` | 8 | 下潜落地（刚落地就惊动一圈） |

| 渲染字符 | 含义 |
|---|---|
| `M` | **已察觉**玩家的敌人（看得见你） |
| `m` | **未察觉**的敌人（还在巡逻/发呆，可倒挂突袭） |
| `~` | **听见动静但还没看见你**的敌人（正朝声源摸过来） |
| `?` | 蜘蛛感应（M6，穿墙的威胁轮廓） |

## 设计决策
| 决策 | 选择 | 理由 |
|---|---|---|
| 默认开关 | 关闭（opt-in） | 既有 168 例规格建立在「只有视觉」的感知模型上；熔断②禁止改测试凑绿 |
| 传播模型 | Dijkstra 最短代价（空地 1 / 墙 3） | 声音沿走廊**绕**着走，不是直线穿墙；拐角后面的房间听不见，隔一道墙只剩三分之一距离 ⇒ 「躲远一点 / 躲到墙后」都真实有效 |
| 墙不完全隔音（3 而非 ∞） | 是 | 完全隔音会让「一墙之隔」变成绝对安全，听觉退化成第二套视线；留一点泄漏才叫「闷响」 |
| 声源 ≠ 玩家位置 | 被缠住的怪自己发声 | 这是「调虎离山」的成立条件：蛛网弹缠住 A，A 的挣扎把 B、C 引到 A 那儿去，玩家得以脱身 |
| 响度是常量表、不掷骰 | 是 | 与 #9 的突袭倍率同一哲学：感知层不吃随机，随机序列不被扰动（#2） |
| 走路无声 | 是 | 主题自洽（蜘蛛侠落地无响），也让「发声」始终是**玩家的选择**——不做动作就不会暴露 |
| 只惊动、不增伤 | 是 | 听觉是感知层不是战斗层；被声音引来的怪仍要走过来，与目视发现同权 |
| 新增 `Monster.alert_cause` | `"sight"` / `"sound"` | 让 `~` 只在「确实是听见而非看见」时出现；也让「它到底是怎么发现我的」可测试、可解释 |
| 落地声放在 `descend()` 而不是 `load_level` | 只有**下潜**才落地 | 开局那一层你已经在楼里了；放 `load_level` 会让「手搓一张图做单元测试」也凭空多一次落地声 |
| 视听同时以视觉为准 | 是 | 视觉给实时位置，听觉只给声源；`update_awareness` 在世界回合开始时跑，会把「只是听见」改写成「看见了」 |
