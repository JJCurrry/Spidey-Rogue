# T-001 · 格子地图 + 玩家移动（M1）

## 一入一出（In/Out）
- **入**：固定小房间地图（5x7），玩家起点 `@`，其余为地板 `.` 与墙 `#`。
- **出**：`Game` 可渲染 ASCII 地图；玩家能用方向（dx,dy）移动；撞墙/越界不动；状态可查。

## 委托级别
- **S（自主完成）**：范围清晰、无外部依赖、红线明确。

## 验收分级
- **A（必过，门禁）**：`tests/test_game.py` 全绿——含 Seed 确定性、起点正确、边界阻挡、墙阻挡。
- **B（建议）**：`python main.py` 能打印初始与移动后地图。
- **C（可选）**：支持 WASD 实时输入循环。

## 范围边界
- 不含战斗、怪物、道具、程序化生成（留 M2+）。
- 地图固定（非随机生成），故 M1 不触发随机红线。
