# T-003 · 怪物 AI（M3）

## 一入一出（In/Out）
- **入**：M2 已具备 `Monster` 实体、`player_attack`（蛛网拳）、`spawn_monster`，但怪物不会动、不会主动攻击（AI 留 M3）。
- **出**：怪物具备两种行为——`chase`（贪心追击，确定性）与 `wander`（随机游走，随机仅经 `RandomSource`）；相邻玩家时反击（固定伤害）；AI 移动不可越界/穿墙/踩玩家/踩其它怪物；同 seed + 同玩家输入序列 ⇒ 同结果。

## 委托级别
- **S（自主完成）**：范围清晰、红线明确（#1/#2/#3/#4）、无外部依赖、复用 M2 实体。

## 验收分级
- **A（必过，门禁）**：`tests/test_ai.py` 全绿——含追击缩短距离、不穿墙、追到相邻反击、相邻攻击扣玩家血、不踩玩家、玩家 HP 不为负（#3）、双怪不重叠（#4）、随机游走同种子可重现（#2/#1）、游走不越界、死怪不动；`python scripts/gate.py` 四道门 ALL GREEN。
- **B（建议）**：`python main.py` 能演示一只追击怪逼近并反击 + 一只随机游走怪飘移。
- **C（可选）**：多种 AI 性格（胆怯/包围）、视野（fov）触发、Boss 行为树。

## 范围边界
- 不含道具/背包（M4）、程序化关卡（M5）、怪物生成随机（属 M5/#1 范畴，本里程碑怪物仍由 `spawn_monster` 手摆）。
- 怪物反击采用固定伤害，保持简单；随机仅用于 `wander` 的方向选择，且必须经 `RandomSource`（红线 #1）。`chase` 不消耗 rng，保持纯确定性。
- 玩家主动攻击仍走 M2 的 `player_attack`（伤害浮动经 rng）。

## 不变量摘录（落 M3）
- #1 随机必须 Seed 注入：`wander` 的方向选择（`rng.chance` / `rng.choice`）经 `self.rng`；`game.py` 不 import random（seed-guard 拦截）。
- #2 回合确定性：同 seed + 同玩家输入序列 ⇒ 同结果；`monster_turn` 按固定顺序推进，无隐藏随机源（`chase` 完全不调 rng）。
- #3 玩家 HP 永不为负：`monster_attack` 经 `Game._hurt_player` 的 `max(0, ...)` 钳制。
- #4 不可越界/穿墙/穿怪：`_monster_can_enter` 把关（越界、墙、玩家格、其它怪物格均不可入）。
