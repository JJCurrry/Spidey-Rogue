# T-007 · 怪物视野与潜行（M7）

## 一入一出（In/Out）
- **入**：M3 起怪物是「全知的」——不管隔几堵墙、多远，所有怪每回合都朝玩家扑。M6 给了玩家视野与蜘蛛感应，敌人却没有对称的「发现」概念，潜行、绕后、逐个击破都无从谈起；清一层永远是「一群怪同时冲过来」。
- **出**：怪物有了**感知**——只有「看得见」玩家时才会被惊动（半径内 + 无墙遮挡 + 同房间）；被惊动后冲向**最后看见玩家的位置**搜捕若干回合，看不见了就放弃、回巢待命。玩家从敌人看不见的地方一步扑到它面前并立刻出手 ⇒ **倒挂突袭**（伤害翻倍、敌人来不及反击）。画面上未察觉的敌人画成小写 `m`，已察觉的画 `M`，玩家一眼能看出「谁还没发现我」。潜行是**可选开关**，默认关闭，保证既有 121 例规格不被破坏。

## 委托级别
- **S（自主完成）**：范围清晰（只加感知层 + 一个突袭入口，不改生成数值/掉落/背包）、红线明确（#1/#2 沿用，#9 本单新增并补机器检查）、无外部依赖、复用 M6 的 `fov.py` 视线算法与 M5 的 `Game.rooms`。

## 验收分级
- **A（必过，门禁）**：`tests/test_stealth.py` 全绿——
  - 开关：默认 `Game(rng=...)` / `Game.procedural(rng, depth=1)` 关闭潜行（怪物恒「已察觉」，M3 行为一字节不变）；`stealth=True` / `Game.procedural(rng, depth=1, stealth=True)` 开启；既有 121 例规格全部不受影响。
  - 感知几何（纯函数 `monster_can_see`）：贴身（同格）必被察觉；墙后不可见；超出 `MONSTER_SIGHT_RADIUS` 不可见；**玩家与怪物在同一房间内**则必定察觉（房间里没处躲）。
  - 警觉状态机：看得见 ⇒ `alerted=True` 且记下 `last_seen` 与 `alert_turns=ALERT_MEMORY`；失去视线后每回合递减，归零则 `calm()` 放弃搜捕；死怪不参与感知。
  - 潜行 AI：未察觉的 `chase` 怪**回巢**（朝 `home` 走，确定性、不消耗 rng）；未察觉的 `wander` 怪照旧随机游走（偶尔改为回巢，#1）；已察觉的怪扑向 `last_seen`（不是全知追踪）。
  - 倒挂突袭：`stealth` 开启时攻击 `alerted=False` 的敌人 ⇒ 伤害 × `SNEAK_ATTACK_MULT`、**不挨反击**、命中后该敌转为已察觉；已察觉的敌人照旧（M2：攻击必吃反击）；潜行关闭时恒为普通攻击。
  - `web_strike(target)`：蛛网摆荡突袭——荡到目标身旁并立刻出手（移动 + 攻击同回合，这是**主动**潜行唯一的时间窗口）；已相邻则直接出手；够不着（`WEB_STRIKE_RANGE=2` 步内没有落脚点）或目标已阵亡 ⇒ 原地不动、返回 `None`。
  - 渲染：未察觉画 `m`、已察觉画 `M`（两条渲染路径都区分）；潜行关闭时全部是 `M` ⇒ 既有 `assertIn("M", render())` 断言仍成立。
  - **不变量 #9**：感知是纯几何、不消耗 `RandomSource`；突袭倍率是确定性常数、不额外掷骰 ⇒ 不扰动随机序列；HP/背包相关的 #3/#5/#6 不受影响。
  - `python scripts/gate.py` 四道门 ALL GREEN。
- **B（建议）**：`python main.py --stealth` 演示潜行——优先摸掉还没发现你的敌人，能一步扑到就倒挂突袭，状态栏显示「潜行中 / 已被 N 只敌人发现」；不加参数时演示与 M6 完全一致。
- **C（可选）**：噪音（跑步/破门引来注意）、朝向与背身判定、光照衰减（暗处降低怪物感知半径）、ANSI 颜色高亮。

## 范围边界
- 不含噪音系统、不含朝向/背身几何（潜行的成立条件是「感知还没更新到」，见设计决策）。
- 不含颜色与 UI 框架（新增字符只有 `m` 一个）。
- **潜行默认关闭**：与 M5 的「教学图默认、程序化显式开启」、M6 的「视野默认关闭」同一哲学——新能力不改写既有规格，需显式 opt-in。
- 感知**纯几何、无随机**；潜行只改变怪物的行为分支，不改变「随机只从 `RandomSource` 流出」这一事实（#1），同一模式内仍满足 #2。
- 怪物感知半径（7）刻意小于玩家视野（8）：玩家总有「先看到它」的优势，潜行才有操作空间。

## 不变量摘录（落 M7）
- #1 随机必须 Seed 注入：感知与突袭判定**不含任何随机**；潜行只切换行为分支，随机仍只经 `self.rng`。
- #2 回合确定性：感知只依赖 `grid` + 双方位置 + `rooms` ⇒ 同状态 ⇒ 同判定；突袭倍率是常数，不额外掷骰。
- **#9 感知/潜行确定性（本单新增）**：
  1. 怪物感知（`Game.monster_can_see_player` / `fov.monster_can_see`）是**纯几何**计算（复用 M6 的 Bresenham 视线 + 感知半径 + 同房间互通），**不消耗 `RandomSource`**；
  2. 「是否倒挂突袭」只由 `Monster.alerted` 决定，额外伤害是**确定性倍率** `SNEAK_ATTACK_MULT`，不额外掷骰；
  3. 潜行**默认关闭**（`stealth=False`）⇒ 怪物恒为「已察觉」，M1~M6 的既有玩法与规格完全不变；
  4. 机器判定：`tests/test_stealth.py::TestStealthDeterminism`（rng 序列对照 + 同 seed 快照重放）。

## 感知参数与图例
| 常量 | 值 | 含义 |
|---|---|---|
| `MONSTER_SIGHT_RADIUS` | 7 | 怪物感知半径（欧氏距离；小于玩家视野 8） |
| `ALERT_MEMORY` | 3 | 失去视线后还会搜捕几个回合（递减到 0 即放弃） |
| `SNEAK_ATTACK_MULT` | 2 | 倒挂突袭的伤害倍率（确定性常数，不掷骰） |
| `WEB_STRIKE_RANGE` | 2 | 蛛网摆荡突袭的射程（沿可通行格最多荡 2 步，不穿墙） |

| 渲染字符 | 含义 |
|---|---|
| `M` | **已察觉**玩家的敌人（会追上来） |
| `m` | **未察觉**的敌人（还在巡逻/发呆，可从背后倒挂突袭） |
| `?` | 蜘蛛感应（M6，穿墙的威胁轮廓） |

## 设计决策
| 决策 | 选择 | 理由 |
|---|---|---|
| 默认开关 | 关闭（opt-in） | 既有 121 例规格建立在「怪物全知追击」上（M3 的 11 例尤其直接断言追击位移）；熔断②禁止改测试凑绿 |
| 感知算法 | 复用 M6 的 `has_line_of_sight` | 视线本来就是对称的；射线法已通过 #8 的纯净性考验，零随机、可重放 |
| 感知半径 7 < 视野 8 | 差一格 | 玩家永远能先发现敌人，潜行才有操作空间；否则双方同时看见，潜行退化成运气 |
| 同房间即察觉 | 是 | 房间最大 8×5、里面没遮挡，躲在「同一个房间的另一头」不合理；也让「清房」与「潜行摸掉走廊上的怪」有了区分 |
| 感知更新时机 | **世界回合开始时一次性更新**（`monster_turn` 开头） | 这是潜行成立的关键：玩家在自己回合从敌人视野外扑到面前时，敌人还停留在上一回合的「未察觉」状态 ⇒ 突袭窗口天然存在 |
| 突袭入口 | `web_strike(target)`（移动 + 攻击同回合，射程 2 步） | 引擎本就允许 `move()` 后 `player_attack()`，但要让「潜行突袭」成为一个可命名、可测试、可在演示里调用的能力。**射程必须是 2**：只走一步摸不到「看不见你的怪」——相邻格之间必无遮挡（`is_adjacent` ⇒ 必被看见），而两步才能绕过拐角从视野外扑进去（推导见 ADR-003） |
| 突袭免反击 | 是 | 否则潜行毫无收益（还多挨一下）；且突袭后敌人立刻转「已察觉」，下回合照常还手，不会无脑白嫖 |
| 未察觉的 chase 怪 | 回巢（`home`）而非原地不动 | 原地不动等于雕像，潜行会退化成「排队挨个打」；回巢让怪守着自己的房间，绕后有风险也有节奏 |
| 未察觉的 wander 怪 | 保持 M3 随机游走（偶尔改为回巢） | 沿用 M3 的行为定义，rng 消耗形态不变，既有 AI 规格的语义得以保留 |
