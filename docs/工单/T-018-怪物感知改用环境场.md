# T-018 · 怪物感知改用环境场（M18）

## 一入一出（In/Out）
- **入**：M17 把光照拆成两份场——`ambient_field`（仅房间灯）与 `light_field`（房间灯 + 玩家微光 + 手电），
  并显式把「怪物感知改用环境场（仅房间灯 + 手电，不含被动微光）」登记为 C 级 opt-in 后续项。
  原因：M11 当前怪物感知半径判定走 `light_level_at`（完整场），其中**玩家被动微光（PLAYER_GLOW_RADIUS）**
  会照亮附近暗处的怪，使怪的感知半径不被缩短——等于把近视眼照成远视眼（隐性副作用）：
  你身上的微光本该只帮自己看路，结果反而替暗处的怪点了灯，让你在暗中更易被发现。
- **出**：一套**纯几何、零随机**的「怪物感知光场」改造——
  1. 复用 `light` 开关（不新增开关）：M18 只在 `light=True` 时有意义；`light=False` ⇒
     怪物感知光场清空，`monster_light_level_at` 恒返回「明亮」，M1~M17（light=False 三条）逐字节一致。
  2. `Game.update_light()` 同源、幂等重算三份场：
     - `ambient_field`       = 仅房间中心固定灯（静态环境照明，M17）；
     - `light_field`         = 房间灯 + 玩家微光 + 手电（完整场，行为不变）；
     - `monster_light_field` = **房间灯 + 随身手电，不含玩家被动微光**（M18 新增消费场）。
  3. 新增 `_monster_light_sources()`（房间灯集合 + 手电源，跳过 `switched_lights`/`destroyed_lights`）、
     状态 `monster_light_field` 与查询入口 `monster_light_level_at(x, y)`
     （与 `light_level_at`/`ambient_level_at` 对称；光照关闭恒「明亮」）。
  4. **M11 怪物感知半径判定改走 `monster_light_level_at`**（排除被动微光），其余消费点（M13 玩家视野、
     `colorize` 渲染梯度）仍走完整场 `light_field` ⇒ 渲染字形一字不差（#8 延伸）。
  5. 有效半径恒 ≤ `MONSTER_SIGHT_RADIUS`(7)（只缩短不放大）⇒ #9 对称硬性质不破；
     手电双刃（M12）保留：你开手电仍会让自己更易被暗处的怪看见（手电在怪物感知光场里）。

## 范围边界
- **只改怪物感知的消费场，不改渲染**：`render()` / `colorize` 明暗梯度仍走完整场 `light_field`（含微光），
  字形一字不差（#8 渲染纯净性延伸）；仅 M11 怪物感知半径判定走 `monster_light_level_at`。
- **三份场同源**：都由 `update_light()` 在 `light_enabled` 时重算；`load_level`/`descend`/开关灯/开手电
  都经 `update_fov` → `update_light` 重算三份 ⇒ 换层与光操控后三份场同步刷新，无陈旧场。
- **关灯 / 碎灯同时影响三份场**：`_light_sources` / `_ambient_sources` / `_monster_light_sources` 都跳过
  `switched_lights`/`destroyed_lights` ⇒ 三份场都「只移除光源、不新增」⇒ 光照场只变暗不变亮 ⇒ #9/#12/#14 不破。
- **只缩短不放大**：怪物感知光场不含被动微光（且含手电），不代表它更亮；被动微光本就会让怪「看得更远」，
  现在被排除 ⇒ 暗处的怪在玩家附近仍是近视眼、你更难被发现，与「暗处近视」的直觉一致；手电作为主动光仍保留双刃。
- **零回归保证（light=False）**：被动微光只在 `light=True` 才有意义，故 `light=False` 时三条演示（默认/--stealth/--noise）
  与 M17 逐字节一致（仅图例一行差异同前例）。

## 不变量增量
- **#18 怪物感知改用环境场**：M11 怪物感知半径判定改走「怪物感知光场」——仅房间灯 + 随身手电、不含玩家被动微光
  （`Game.monster_light_level_at`，由 `update_light()` 与 `light_field`/`ambient_field` 同源、幂等重算），
  修正「被动微光把附近暗处怪照成近视眼反面」的隐性副作用；有效半径恒 ≤ `MONSTER_SIGHT_RADIUS` ⇒ #9 对称硬性质不破、
  手电双刃（M12）保留；`light=False` 三条演示与 M17 逐字节一致，渲染梯度仍走完整场（#8 延伸）。
