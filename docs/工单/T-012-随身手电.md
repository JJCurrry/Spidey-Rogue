# T-012 · 随身手电（M12 · 动态光源）

## 一入一出（In/Out）
- **入**：M11 把「光」做成了环境层——房间有灯、走廊昏暗，暗处的怪是近视眼。但光源是**静态**的：
  房间中心固定灯 + 玩家随身微光，玩家无法主动改变自己周围的亮度。蜘蛛侠的蛛网发射器本该能
  「探照」——开灯看清、关灯摸黑，把光变成一件**玩家工具**。接力棒给 M12 的候选方向之一正是
  「动态光源：可开关的灯 / 手电」（另一候选「光照影响玩家自身视野」留作 M13）。
- **出**：一套**纯几何、零随机**的随身手电——
  1. `Game` 新增 `flashlight` 开关（**默认关闭、显式 opt-in**，与 `fov`/`stealth`/`noise`/`light` 同一哲学）：
     `Game(..., flashlight=True)` / `Game.procedural(..., flashlight=True)` / `python main.py --flashlight`
     （`--flashlight` 隐含 `--light`）。
  2. `toggle_flashlight()`：翻转 `flashlight_on` 并顺手重算光照场——开灯在玩家处追加一个
     半径 `FLASHLIGHT_RADIUS=6` 的动态光源（比随身微光 4 远、比房间灯 9 近），照亮四周；
     关灯退回微光。这只翻标志 + 重算，不消耗 `RandomSource`、不改写任何玩法状态（换层保留，与 HP / 背包同属跨层状态）。
  3. 玩法：开灯让「微光照不到的远处」变亮 ⇒ 那里的怪感知半径从暗(2)/昏暗(4)升到满值(7)，
     **更容易察觉你**（手电是一把双刃剑：照亮战场也照亮自己）；关灯则退回微光、摸黑潜行更稳。
     半径仍恒 ≤ `MONSTER_SIGHT_RADIUS`(7) ⇒ 不变量 #9 的硬性质「怪看得见你 ⇒ 你看得见它」不破。
  4. `render()` 字形一字不差、默认/潜行/听觉/光照四条既有演示路径不加 `--flashlight` 时一字节不变
     （手电默认不装备）；明暗梯度只在 `color.py` 上色层（开灯后玩家周围更亮）。

  - 手电默认关闭（flashlight=False）⇒ 即使 light=True 也与 M11 逐字节一致（`TestFlashlightSwitch`）。
  - 手电只缩短怪物感知半径（恒 ≤ MONSTER_SIGHT_RADIUS）⇒ 机器判定「怪看得见你 ⇒ 你看得见它」

  - `render()` 字形在手电开/关下**逐字相同**（`TestFlashlightRenderPurity`）⇒ 既有 288 例规格全部不受影响（不变量 #8）。
  - `toggle_flashlight` 零随机、确定性：toggle 不推进怪物、同状态同场（`TestFlashlightDeterminism`）。
  - `python scripts/gate.py` 四道门 ALL GREEN，棘轮 288 → 306。

- **C（可选）**：可开关的房间灯（蛛网射中灯开关）、按地形类型给不同底色、把「明暗梯度」也做成可配置主题、
  光照影响玩家自身视野（目前只影响怪物感知，与 M6「视野是渲染层」一致，故不改——见 M13 候选）。

## 范围边界
- **手电只缩短怪物感知半径，不改变「显示什么」给玩家**：玩家视野（M6）仍按原逻辑，手电不动它；
  明暗梯度只在 `color.py` 上色层（与 M10/M11 同哲学：展示层不进 `Game`/`render()`）。
- **不引入任何随机**：手电只是翻转一个标志位并重算 `light_field`（纯几何、零随机），不消耗 `RandomSource`、不读游戏状态以外。
- **只缩短、不放大**：手电点亮玩家周围 ⇒ 怪所在格最多「明亮」⇒ 感知半径最多 `MONSTER_SIGHT_RADIUS`(7)，
  这是「对称硬性质不破」的数学前提，也是门禁机器判定守住的红线。
- **光遇墙即断**（与 M6 视线、M11 光照同哲学）：手电半径内的墙后仍是绝对遮挡，不会凭空透亮。
- **默认关闭、opt-in**：`flashlight=False` 时 `_light_sources` 不追加手电光源、`toggle_flashlight` 也不会改变任何
  既有行为 ⇒ M1~M11 一字节不变。

## 不变量摘录（落 M12）
- #13 随身手电（新）：纯几何、零随机；手电默认关闭（flashlight=False ⇒ 即使 light=True 也与 M11 逐字节一致）；
  开启时只在玩家处追加一个半径 `FLASHLIGHT_RADIUS` 的光源，同样只缩短怪物感知半径（恒 ≤ 7）⇒ #9 对称硬性质不破；
  `toggle_flashlight` 只翻标志 + 重算光照场，不改写任何玩法状态（换层保留）。
- #1 随机仅经 `RandomSource`：`game.py` 的 `toggle_flashlight` 不引入任何随机调用。
- #2 回合确定性：手电只依赖 `grid` + 玩家坐标 ⇒ 同状态同场，不消耗随机、不扰动回放。
- #8 渲染纯净性（延伸）：明暗梯度只在 `colorize` 包裹层，不改 `render()` 字形。
- #9 感知/潜行确定性（延伸）：手电只缩短感知半径、不引入随机、不放大 ⇒ 对称硬性质不破。

## 常量表
| 常量 | 值 | 含义 |

## 设计决策
| 决策 | 选择 | 理由 |
|---|---|---|
| 手电是玩家开关，不是新环境光源 | 是 | 把「光」变成玩家工具：开灯看清/亮明战场、关灯摸黑潜行；主题上即蛛网发射器探照灯 |
| 手电半径 6（介于微光与房间灯之间） | 是 | 既比微光照得远（有「扩亮」效果，让远处怪更易察觉你），又不喧宾夺主盖过房间灯 |
| `toggle_flashlight` 只翻标志 + 重算场 | 是 | 纯状态操作、零随机、不推进任何怪物 ⇒ 不扰动随机序列与回放（#1/#2） |
| 手电默认关闭、opt-in | 是 | 与 `fov`/`stealth`/`noise`/`light` 同一哲学；关闭时 `_light_sources` 不追加 ⇒ M1~M11 一字节不变 |
| 手电只影响怪物感知、不动玩家视野 | 是 | 与 M6「视野是渲染层、不参与玩法」一致；让光照也压短玩家视野留作 M13 |
