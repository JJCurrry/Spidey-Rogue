# T-019 · 灯开关独立实体（M19）

## 一入一出（In/Out）
- **入**：M14（蛛网射中房间中心灯的拉链翻转灯）+ M16（蛛网射碎房间中心灯泡，一次性不可逆）把
  「光操控」做成了射中**灯具 `room.center`** 的战术；接力候选里登记的「灯开关独立实体」
  （墙上开关 tile，与灯泡分离）正是把「控制点」从天花板中央挪到**墙边开关**——更真实，也把
  「灯具坐标」与「控制手柄」解耦。
- **出**：一套**纯几何、零随机**的「灯开关独立实体」改造——
  1. **opt-in（默认关闭）**：`switches=False` ⇒ 不摆开关、不出 `=`、默认/潜行/听觉三条演示与 M18 逐字节一致；
     `switches=True` ⇒ 每个房间在**房间外沿相邻且本身是墙**的格子上确定性摆一个 `LightSwitch`
     （北→南→西→东 固定顺序取首个命中，零随机、不消耗 `RandomSource`），渲染字形 `=`，已碎退回 `#`。
  2. **新增平行 switch API**（与 M14/M16 同源、复用同一份状态）：`switch_at` / `can_toggle_switch` /
     `toggle_switch` / `can_destroy_switch` / `destroy_switch` / `switch_light_is_on`。
     `toggle_switch` 翻 `switched_lights[room.center]`、`destroy_switch` 把 `room.center` 加入
     `destroyed_lights` 并标记 `sw.destroyed`（不可逆）——**翻的是灯具坐标，不是开关格**，
     因此完全复用 M14/M16 的光照场逻辑 ⇒ 行为零回归。
  3. **几何约束与 M14/M16 同构，但瞄准「开关格」**：四条（toggle）/ 五条（destroy）——开关已启用 + 光照已开
     + (x,y) 是某开关 + 开关未碎 + 切比雪夫距离 ≤ `WEB_LIGHT_RANGE`(6)（含脚下）+ 玩家**看得见开关**
     （`has_line_of_sight`，蛛网走直线遇墙即断）。
  4. **声源仍在灯具处**（不在开关格、不在玩家处）：toggle 发 `NOISE_TOGGLE_LIGHT=3`、destroy 发
     `NOISE_SHATTER_BULB=3`，都从 `room.center` 传出 ⇒ M8 调虎离山成立，与 M14/M16 同源、演示可复现。
  5. **主线演示接入**：`main.py` 现在 `switches=light`（有光才有开关）；`--light --stealth` 下
     `step 0b` 改为蛛网射碎「未察觉敌人所在房间**墙边开关**的灯泡」（永久黑暗、摸黑接近），
     `_light_to_destroy` 遍历 `game.switches`（房间含未察觉敌人 + 玩家够得着墙上开关），行为等价于
     M18 的「射碎灯具」，只是瞄准坐标从 `room.center` 换成墙边开关。

## 验收分级
- **A（必过，门禁）**：`tests/test_light_switch_entity.py` 33 例全绿——
  - **opt-in 默认关闭**：`switches=False` ⇒ 无开关实体、`render()` 不含 `=`、且 `can_toggle/destroy_switch`
    恒返回 False、no-op（默认/潜行/听觉三条演示与 M18 逐字节一致）。
  - **确定性摆位**：每房间一个开关、摆在墙格、零随机、同 seed 同摆位、摆位不消耗 `RandomSource`。
  - **几何约束**：开关在射程内 + 视线清晰 ⇒ 可 toggle/destroy；非开关坐标 / 超射程 / 墙挡视线 /
    光照关闭 / 开关未启用 / 已碎 ⇒ 不可（纯几何、零随机）。
  - **行为等价 M14/M16**：toggle 翻 `switched_lights[room.center]` 使房间变暗、destroy 加入
    `destroyed_lights` 并标记 `sw.destroyed` 且不可再 toggle、destroy 后 `switched_lights` 同步清除；
    两者都不消耗 `RandomSource`、都不改写玩法状态、换层（`load_level`）重置（开关重摆、集合清空）。
  - **声源在灯具处**：toggle/destroy 后未察觉怪物被惊动、`alert_cause=CAUSE_SOUND`、
    `last_seen == room.center`（不是开关格、不是玩家位置）⇒ 调虎离山成立。
  - **多房间解耦**：关/碎一个房间的开关只影响它自己（其它房间灯仍亮、开关完好）。
  - **渲染纯净**：`=` 字形（全图 + 迷雾已探索格）、已碎退回 `#`；`render()` 不改写任何 world state
    （world state 前后快照比对）、同输入同画面（不变量 #8）。
  - **#9 对称硬性质在开关下仍成立**：怪看得见你 ⇒ 你看得见它（开关只是控制手柄，不动光照几何）。
  - `python scripts/gate.py` 四道门 ALL GREEN，棘轮 445 → 478。
- **B（建议）**：`python scripts/balance_check.py` 默认 30/30、潜行 28/30（不变，与 M18 逐字节一致）；
  `python main.py` 与 `--stealth` 与 `--noise` 与 `--light` 与 `--light --stealth` 与 `--flashlight`
  与 `--flashlight --stealth` 七条演示均通关（默认/潜行/听觉三条与 M18 逐字节一致；`--light --stealth`
  经对照 **与 M18 灯具基线同 7/10 通关率、无回归**，canonical seed 19 三层通关；`--flashlight --stealth` 10/10）。

  主题上「蜘蛛感应是超能力」是否该受光照约束需先定调）。

## 范围边界
- **保留 M14 `toggle_light(room.center)` / M16 `destroy_light(room.center)` API 不动**：既有 445 例规格零回归
  （`test_light_switch.py` / `test_destructible_light.py` 仍断言 `render()` 字形子集不含 `=`，因为默认不开开关）；
  M19 是**平行新增**的开关实体 + 开关 API，翻同一份 `switched_lights`/`destroyed_lights`（按 `room.center` 记录）。
- **开关只是「灯具的解耦控制手柄」**：摆位只决定蛛网够得到哪里，翻的永远是 `room.center` 那盏灯
  ⇒ 光照几何、暗处缩短怪物感知/玩家视野、声源位置全部与 M14/M16 同源 ⇒ #9/#12/#14 不破。
- **opt-in（默认关闭）**：`switches=False` ⇒ `_place_switches` 不摆实体、`render()` 不含 `=`
  ⇒ 默认/潜行/听觉三条演示与 M18 逐字节一致（仅图例一行差异同前例）；只有 `switches=True`（即 `light=True`
  的演示路径）才出现开关实体，且行为等价于 M18 的「射碎灯具」战术。
- **已碎开关退回 `#`**：`=` 是开关实体的渲染字形；`destroyed` 后不再作为控制点、
  退回底层墙 `#`，不引入新字形到 world state（`render()` 纯净性 #8 延伸）。
- **换层重置**：`load_level` 清空 `switched_lights`/`destroyed_lights` 并重摆 `switches`
  （`switches_enabled` 跨层保留），新楼层 = 新房间 = 新开关 = 新灯。

## 不变量增量
- **#19 灯开关独立实体**：`LightSwitch` 是墙边开关实体（与天花板灯具 `room.center` 分离的独立控制手柄），
  opt-in（`switches=False` ⇒ 不摆、无 `=`、与 M18 逐字节一致）；摆位确定性、零随机、不消耗 `RandomSource`；
  `toggle_switch`/`destroy_switch` 翻同一份 `switched_lights`/`destroyed_lights`（按 `room.center` 记录）
  ⇒ 完全复用 M14/M16 光照场逻辑、行为零回归；几何约束纯几何零随机（瞄准开关格的 LOS + 切比雪夫 ≤ `WEB_LIGHT_RANGE`）；
  已碎开关不可再 toggle、destroy 后 `switched_lights` 同步清除、换层重置；
  **声源在灯具处**（不在开关格、不在玩家处）⇒ M8 调虎离山成立；`render()` 只加 `=` 字形、不改写任何 world state（#8 延伸）。
