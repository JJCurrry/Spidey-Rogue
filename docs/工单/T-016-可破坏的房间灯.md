# T-016 · 可破坏的房间灯（M16 · 蛛网射碎灯泡）

## 一入一出（In/Out）
- **入**：M14 把「房间灯」做成了**可翻转**的互动元素——蛛网射中拉链，关了还能再拉开。但这仍是「可逆」的：
  灯始终在那儿，只是开关状态变了。蜘蛛侠的蛛网带着冲量甩出去，本该能把**灯泡本身射碎**——
  一种比「拉链翻开关」更彻底、一次性不可逆的「光操控」：`M14` 是「关灯」，M16 是「把灯打没」。
  接力棒给 M16 的候选方向之一正是「可破坏的灯（M14 是翻转式，可破坏 = 一次性不可恢复）」。
- **出**：一套**纯几何、零随机**的可破坏房间灯——
  1. 复用 `light` 开关（不新增开关）：M16 只在 `light=True` 时有意义；`light=False` ⇒
     `destroy_light` 是 no-op（没有灯泡可碎），M1~M15 一字节不变（与 M11/M12/M13/M14 同一哲学）。
  2. `Game` 新增 `destroyed_lights: set[Tile]`（已射碎灯泡的房间中心坐标，默认空）与
     `can_destroy_light(x, y)` / `destroy_light(x, y)`：蛛网射碎房间中心灯泡，一次性不可逆。
     五条硬约束：光照开启 + 目标是房间中心 + 玩家**看得见灯**（`has_line_of_sight`）且在射程内
     （切比雪夫 ≤ `WEB_LIGHT_RANGE=6`，含脚下）+ 该灯**尚未被破坏**。
  3. `_light_sources()` 同时跳过 `switched_lights` 与 `destroyed_lights` ⇒ 碎灯后房间彻底黑暗
     （M11 暗处缩短怪物感知 + M13 暗处缩短玩家视野——**双刃**：暗处的怪看不远、你也看不远，但暗处你更难被发现）。
  4. M8 联动：碎裂的轻响 `NOISE_SHATTER_BULB=3` 从**灯处**传出（声源不在玩家脚下）⇒
     调虎离山的轻量手段（与 M14 拉链轻响同值、同原则）。
  5. `destroy_light` 只翻 `destroyed_lights` 集合 + 重算光照场 + 重算可见集合（`update_fov`），
     不消耗 `RandomSource`、不改写 `grid`/HP/背包/怪物状态（与 `toggle_light`/`toggle_flashlight` 同一零副作用哲学）；
     换层（`load_level`）重置。
  6. `render()` 字形一字不差（破坏只改光照场与可见集合，不改字形，#8 延伸）；
     `light=False` 时 `destroy_light` 恒返回 False（no-op）⇒ 既有 432 例零侵入。

## 验收分级
- **A（必过，门禁）**：`tests/test_destructible_light.py` 全绿——
  - 破坏是**纯几何、零随机**：`destroy_light` 不引入随机模块、不消耗 `RandomSource`（seed-guard 仍只放行 `rng.py`）。
  - M16 默认关闭（light=False）⇒ `destroy_light` 恒返回 False、不改任何状态（`TestDestroyDefault`）。
  - 破坏只移除光源（不新增光源）⇒ 光照场只变暗不变亮 ⇒ 有效半径恒 ≤ `SIGHT_RADIUS`(8) ⇒
    机器判定「怪看得见你 ⇒ 你看得见它」在 `light+fov+stealth` 下仍成立（`TestDestroySymmetry`）。
  - `render()` 字形在破坏前后**逐字相同**（fov=False 路径）；可见格子仍用原字形（`TestDestroyRenderPurity`）⇒ 既有 432 例零侵入。
  - 确定性：同 seed + 同输入 ⇒ 同光照场；破坏不消耗随机（`TestDestroyDeterminism`）。
  - M8 联动：破坏发出 `NOISE_SHATTER_BULB` 响动，声源在**灯处**（不是玩家处）⇒ 调虎离山成立（`TestDestroyNoise`）。
  - 换层重置：`descend` → `load_level` 清空 `destroyed_lights`（`TestDestroyReset`）。
  - 与 M14 交互：已破坏的灯不可再 toggle；先关灯再碎灯 ⇒ 永久黑暗、不可恢复（`TestDestroyInteractionWithToggle`）。
  - `python scripts/gate.py` 四道门 ALL GREEN，棘轮 389 → 432。
- **B（建议）**：`python main.py --light --stealth` 下蜘蛛侠改为**蛛网射碎**未察觉敌人所在房间的灯泡
  （永久黑暗、不可逆，比 M14 关灯更彻底），三层仍能通关；不加 `--light` 的前两条演示（默认/潜行）与 M15 逐字节一致
  （默认 30/30、潜行 28/30）。
- **C（可选）**：可破坏的灯作为独立实体（墙上的开关/灯具 tile）；按地形类型给不同底色；
  光照影响蜘蛛感应半径；破坏也可由环境事件（如战斗误伤）触发。

## 范围边界
- **M16 只在 `light=True` 时有意义**：`light=False` ⇒ `_light_sources` 不含房间灯（碎不碎都一样，光照场为空）⇒
  `destroy_light` 恒返回 False。不新增开关，复用 `light`（与 M13/M14 同一哲学）。
- **只移除光源、不新增**：碎灯把房间灯从 `_light_sources` 里拿掉（与 `switched_lights` 合并跳过）⇒ 房间彻底黑暗
  （DARK/DIM，且不会恢复）；光照场只变暗，不会比 M11 更亮 ⇒ #9/#12/#14 不破。
- **不可逆（与 M14 的根本区别）**：`destroyed_lights` 一旦加入就永留本层；`can_toggle_light` 对已破坏者返回 False、
  `destroy_light` 对已破坏者返回 False（不可重复消耗回合）；破坏也可作用于「已关灯」的房间（switched → discard，
  永久黑暗）。换层重置。
- **不引入任何随机**：`destroy_light` 只翻 `destroyed_lights` 集合 + 重算 `light_field` + 重算 `visible`，
  纯几何、零随机（与 `toggle_light`/`toggle_flashlight` 同一零副作用哲学）。
- **声源在灯处、不在玩家处**：`emit_noise(light_x, light_y, NOISE_SHATTER_BULB)`——
  与 M8「被蛛网弹缠住的怪挣扎出声」、M14「拉链轻响」同一原则（声源未必是玩家）⇒ 调虎离山成立。
- **不改 `render()` 字形**：破坏只改变 `light_field`（影响 M11 怪物感知 + M13 玩家视野）与 `visible`
  （哪些格子可见），不改变可见格子的字形（#8 延伸）。
- **不改 M6 的「进房间点亮整间」规则**：碎灯后玩家站在该房间里仍能点亮整间（M6 规则保留）；
  M16 只缩短「跨房间」视野（从走廊看进暗房间看不远），这是预期效果，与 M13「暗处近视」一致。

## 不变量摘录（落 M16）
- #16 可破坏的灯（新）：纯几何、零随机；默认关闭（light=False ⇒ destroy_light 恒返回 False）；
  破坏只移除光源（不新增）⇒ 光照场只变暗，有效半径恒 ≤ `SIGHT_RADIUS`(8) ⇒ #9/#12/#14 不破；
  已破坏的灯不可再 toggle；破坏也可作用于已关灯的房间 ⇒ 永久黑暗、不可恢复；
  声源在灯处（不在玩家处）⇒ M8 调虎离山成立；`destroy_light` 只翻集合 + 重算场，不改写任何玩法状态（换层重置）。
- #1 随机仅经 `RandomSource`：`game.py` 的 `destroy_light` / `can_destroy_light` 不引入任何随机调用。
- #2 回合确定性：破坏只依赖 `grid` + 玩家坐标 + `rooms` + `destroyed_lights` ⇒ 同状态同场，不消耗随机、不扰动回放。
- #8 渲染纯净性（延伸）：破坏只改光照场与可见集合，不改 `render()` 字形。
- #9 感知/潜行确定性（延伸）：破坏只缩短感知半径（移除光源 ⇒ 变暗 ⇒ 半径缩短），不引入随机、不放大 ⇒ 对称硬性质不破。
- #10 噪音/听觉确定性（延伸）：碎裂的轻响仍只经 `emit_noise` → `Monster.alert(cause=CAUSE_SOUND)` 唯一入口生效。
- #12 光照衰减（延伸）：破坏移除房间灯 ⇒ 房间变暗 ⇒ 怪物感知只缩短不放大（恒 ≤ `MONSTER_SIGHT_RADIUS`）。
- #14 光照影响玩家视野（延伸）：破坏后暗处目标格光照降档 ⇒ 玩家视野半径缩短（恒 ≤ `SIGHT_RADIUS`）。

## 常量表
| 常量 | 值 | 含义 |
|---|---|---|
| `WEB_LIGHT_RANGE` | 6 | M14/M16 蛛网射灯的射程（切比雪夫距离，含脚下；与 `DECOY_RANGE` 同值，比视野 8 短） |
| `NOISE_SHATTER_BULB` | 3 | M16 灯泡碎裂的轻响（声源在灯处；与 `NOISE_TOGGLE_LIGHT=3` 持平，保全已验证的 `--light --stealth` 演示通关行为） |
| `ROOM_LIGHT_RADIUS` | 9 | 房间中心固定光源半径（M11，碎灯时该光源被永久移除） |

## 设计决策
| 决策 | 选择 | 理由 |
|---|---|---|
| 破坏性（destroy），不是翻转（toggle） | 是 | M16 在 M14 翻转式之上加「不可逆」维度：碎了就没了，没有「再拉开」的选项；主题即蛛网带着冲量射碎灯泡 |
| 复用 `light` 开关，不新增开关 | 是 | M16 是 M11 光照系统的「光源可破坏性扩展」，不是新感知通道；light=False ⇒ 没有灯泡可碎 |
| 新增独立集合 `destroyed_lights`，不并入 `switched_lights` | 是 | 二者语义不同（可恢复 vs 不可逆），分开便于查询/渲染/测试；`_light_sources` 合并跳过 |
| 目标必须是房间中心 | 是 | 灯泡装在天花板中央（M11 光源位置）；射歪的蛛网打不到 ⇒ 不消耗状态 |
| 射程含脚下（距离 0） | 是 | 站在灯正下方伸手就能够到灯泡；与 `can_throw`「甩出去必须离开自己」不同（射灯不是甩东西） |
| 声源在灯处、不在玩家处 | 是 | 碎裂声响从灯那儿传出去 ⇒ 调虎离山（与 M8/M14 同一原则） |
| 碎裂响度与 M14 拉链持平（3） | 是 | 保全「已验证的 `--light --stealth` 演示」通关行为不变（噪声值相同 ⇒ 惊动集合相同）；如需更响可后续评估 |
| 不改 M6「进房间点亮整间」规则 | 是 | 改它需动 M6/M13 既有规格；碎灯的跨房间效果（走廊看进暗房看不远）已足够展示 M16 |
