# T-009 · 主动制造响动（M9）

## 一入一出（In/Out）
- **入**：M8 给了怪物「听觉」，也顺带给了玩家一条解法——「调虎离山」。但这条解法是**被动**的：唯一的非玩家声源是「被蛛网弹缠住的怪在挣扎」，也就是说玩家必须先**打中**一只怪，才能把它的同伴引开。动静是玩家唯一无法主动制造的感知变量：想引开巡逻就得先动手，而动手本身（蛛网拳响度 6）已经先把半个视野的人招来了。**「引开他们」和「不惊动他们」互相排斥**，调虎离山因此只在「已经开打」之后才成立。
- **出**：一件**只为响而存在**的道具——**皇后区垃圾桶盖**。蜘蛛侠抄起脚边的垃圾盖甩到远处，落地「哐」的一声，把听得见的敌人全引到**落点**（不是你脚下）。于是动静第一次成为玩家的**主动选择**：可以先把敌人聚到走廊那头，再摸掉落单的那只；也可以在被两只怪夹住时甩一记，把其中一个引开、逐个击破。投掷是**纯几何**（射程 + 视线 + 落点可通行），响动走 M8 的 `emit_noise` 唯一入口，因此不新增任何随机、也不新增感知通道——M9 不是第五条感知链，而是**玩家第一次能写这条链的输入**。
  与 `fov` / `stealth` / `noise` 同一哲学：诱饵挂在 `noise` 开关下，**默认关闭** ⇒ 既有 215 例规格与默认/潜行两条演示**逐字节不变**。

## 委托级别
- **S（自主完成）**：范围清晰（一件一次性道具 + 一个投掷动作 + 一处演示决策，不改生成数值/掉落表/怪物表/传播层）、红线明确（#1/#2 沿用，#11 本单新增并补机器检查）、无外部依赖、完全复用 M8 的 `emit_noise` 与 M6 的 `has_line_of_sight`。

## 验收分级
- **A（必过，门禁）**：`tests/test_decoy.py` 全绿——
  - 开关：默认 `Game(rng=...)` / `Game.procedural(rng, depth=1)` **既不会刷出垃圾盖、也甩不响**；
    `noise=True` 时开局脚边躺着一个垃圾盖；既有 215 例规格全部不受影响。
  - 掉落表 `ITEM_KEYS` **保持三项不变**（诱饵不进掉落池）⇒ 不扰动随机序列（#1/#2）。
  - 投掷几何（纯几何、零随机）：落点须在界内且**不是墙**；切比雪夫距离须在 `1..DECOY_RANGE`
    （甩出去，不是放脚下）；玩家须**看得见落点**（复用 `fov.has_line_of_sight`）。
    三条任一不满足 ⇒ `can_throw` 为 False、`throw_decoy` 返回 `None`、**不消耗道具**。
  - 响动：成功投掷 ⇒ 在**落点**发出 `NOISE_DECOY` 的响动，被惊动者 `last_seen = 落点`
    （不是玩家位置）⇒ 调虎离山成立；`alert_cause == CAUSE_SOUND` ⇒ 画面上是 `~`。
  - `use_item(index, target=...)`：只对诱饵要求 `target`；其它三件道具传不传都一样（向后兼容）。
    落点非法 / 听觉关闭 ⇒ 返回 False 且**不消耗**（与「满血不吃三明治」「场上无怪不射蛛网弹」同款不浪费规则）。
  - 听觉关闭时 `throw_decoy` 恒为 `None`、不消耗道具 ⇒ M1~M8 的行为一字节不变。
  - **不变量 #11**：投掷几何纯几何、不消耗 `RandomSource`；响动只经 `emit_noise` 唯一入口生效；
    诱饵只在听觉开启时出现。机器判定：`tests/test_decoy.py::TestDecoyDeterminism`。
  - `python scripts/gate.py` 四道门 ALL GREEN。
- **B（建议）**：`python main.py --noise` 演示主动调虎离山——被 ≥2 只敌人盯上且没人贴脸时，
  把盖子甩到「听得见的人最多、离你最远」的落点；状态栏照旧显示上一次动静惊动了几只。
- **C（可选）**：光照衰减（暗处降低怪物感知半径）、ANSI 颜色高亮、盖子的多次弹跳/残留物。

## 范围边界
- 不含光照衰减与颜色（见 C 级）：本单只做「玩家能主动制造响动」这一件事。
- **不改传播层**：`src/rogue/sound.py` 一个字都不动——响动仍由 `emit_noise(x, y, loudness)`
  发出，M9 只是第一次让玩家亲手指定那个 `(x, y)`。
- **不进掉落表**：诱饵若进 `ITEM_KEYS`，`rng.choice` 的取值域从 3 变 4，`_randbelow` 的拒绝采样
  就会改变随机数消耗 ⇒ 既有演示的回放全部作废。所以它改由**开关**供给，而不是靠掉落碰运气。
- **诱饵挂在 `noise` 开关下**，不新增第四个开关：它属于听觉这条链，听觉关掉的世界里没人听得见，
  它就是占背包的垃圾。三个开关仍是三条链各一个（视野 / 潜行 / 听觉）。
- 诱饵是**一次性消耗品**（与三明治 / 蛛网芯 / 纳米强化剂一致），**不落地留存**：
  否则演示 AI 会陷入「甩—捡—甩—捡」的循环，回合数失控。
- 投掷**不造成伤害**：它只制造响动（沿用 #10 的「听觉只惊动、不增伤」）。

## 不变量摘录（落 M9）
- #1 随机必须 Seed 注入：投掷几何**不含任何随机**；诱饵不进掉落池 ⇒ 随机序列一字节不变。
- #2 回合确定性：投掷只依赖 grid + 玩家位置 + 落点 ⇒ 同状态 ⇒ 同结果；响度是常量、不掷骰。
- #8 渲染纯净性：`throw_decoy` 不在 `render()` 里被调用；`render()` 读 `alert_cause` 但不改写它。
- #10 听觉确定性：诱饵的响动仍只经 `Monster.alert(cause=CAUSE_SOUND)` 这一唯一入口生效。
- **#11 主动制造响动 / 投掷确定性（本单新增）**：
  1. 投掷可行性（`Game.can_throw`）是**纯几何**判定（界内 + 非墙 + `1..DECOY_RANGE` 切比雪夫
     射程 + `fov.has_line_of_sight` 视线），**不消耗 `RandomSource`**，只依赖 grid + 玩家位置 + 落点；
  2. 诱饵的响动只经 `Game.emit_noise` → `Monster.alert(cause=CAUSE_SOUND)` 这一**唯一入口**
     影响 `alerted`，不额外掷骰，不改 `grid` / HP / 背包（与 #3/#5/#6 无交集）；
  3. 诱饵**只在听觉开启时出现**（`noise=False` ⇒ 不刷垃圾盖、`throw_decoy` 恒为 `None`、不消耗道具）
     ⇒ M1~M8 的既有玩法与规格完全不变，默认与潜行两条演示与 M8 逐字节一致；
  4. 机器判定：`tests/test_decoy.py::TestDecoyDeterminism`（rng 序列对照 + 同 seed 重放）
     与 `::TestThrowGeometry`（四条几何约束各自一条用例）。

## 常量表
| 常量 | 值 | 含义 |
|---|---|---|
| `DECOY_KEY` | `"decoy"` | 诱饵道具的 key（**不在** `ITEM_KEYS` 掉落池里） |
| `NOISE_DECOY` | 9 | 垃圾盖落地的响动（**全场最响**——它的全部意义就是响；比落地声 8 还响一档） |
| `DECOY_RANGE` | 6 | 甩出距离上限（切比雪夫）⇒ 隔着房间甩不过去，得走到能看见的地方 |
| `DECOY_MIN_THREAT` | 2 | 演示里「至少被几只敌人盯上」才值得甩盖子（main.py 的演示启发式，非引擎常量） |

| 现有响度（M8） | 值 | 与诱饵的关系 |
|---|---|---|
| `NOISE_SNEAK` | 2 | 倒挂突袭：闷哼，几乎无声（摸掉哨兵） |
| `NOISE_PUNCH` | 6 | 蛛网拳：正面交手，传半条走廊 |
| `NOISE_STRUGGLE` | 7 | 被缠住的怪挣扎：**被动**的调虎离山（M8，声源在怪物处） |
| `NOISE_LANDING` | 8 | 下潜落地：刚落地就惊动一圈 |
| `NOISE_DECOY` | 9 | 垃圾盖落地：**主动**的调虎离山（M9，声源由玩家指定） |

| 道具 | 效果 | 声源 |
|---|---|---|
| 梅姨的三明治 | 回血 6（不超上限，#6） | 无声 |
| 蛛网发射器备用芯 | 最近存活怪 5 伤害 + 束缚 1 回合 | 被缠住的怪处（响 7） |
| 斯塔克纳米强化剂 | 蛛网拳基础伤害 +2（本局累加） | 无声 |
| **皇后区垃圾桶盖（M9）** | **在指定落点发出响度 9 的动静** | **玩家指定的落点** |

## 设计决策
| 决策 | 选择 | 理由 |
|---|---|---|
| M9 选「主动制造响动」而非「光照衰减 / 颜色高亮」 | 主动制造响动 | M8 是刚落地的听觉链，ADR-004 明确把它列为 C 级并写下「`emit_noise` 已是公开 API，只需给个入口」——改动面最小、与上一棒衔接最紧；光照衰减要新增逐格光照数据（同时碰 M5 与 M6），颜色是表现层不产生玩法 |
| 载体做成**道具**而不是新指令 | 道具（背包里的一格） | 与 M4 的三件道具同构，走 `use_item` 同一入口；也让「要不要带它」成为背包容量（#5）下的取舍 |
| 诱饵**不进掉落表** | 是 | 进 `ITEM_KEYS` 会把 `rng.choice` 的取值域从 3 改成 4，`_randbelow` 的拒绝采样随即改变随机数消耗 ⇒ 既有三条演示的回放全部作废；改由开关供给则**零随机扰动** |
| 诱饵挂在 `noise` 开关下，不新增开关 | 是 | 它属于听觉这条链；听觉关掉的世界里没人听得见，它只是占背包的垃圾。三个开关仍各管一条链 |
| 开局**脚边**躺着一个（零随机） | 是 | 用 rng 在起始房撒点会消耗随机数（哪怕只在听觉模式）；直接放在起点则**听觉模式的地形与撒点仍与 M8 逐字节相同** ⇒ 回归证据链不断 |
| 每层都给一个 | 是 | 主题自洽（纽约的楼里到处是垃圾）；也保证演示里「新机制至少用得上一次」 |
| 一次性消耗、**不落地留存** | 是 | 与三件既有道具同构；若落地可再捡，演示 AI 会陷入「甩—捡—甩」循环，回合数失控 |
| 落点须**看得见**（`has_line_of_sight`） | 是 | 「甩没看见的地方」不算瞄准；复用 M6 的几何 ⇒ 零新增概念。也让诱饵与视野形成配合：先探路，再甩 |
| 落点须**非墙** | 是 | 盖子得落地才响；甩进墙里就哑了（与 `spawn_item` 对墙格返回 `None` 同款边界观，#4） |
| 射程下限 = 1（不能甩在脚下） | 是 | 甩在脚下 = 把敌人引到自己身上，那是 bug 不是战术；「甩出去」本身就意味着离开自己 |
| 响度 9 > 落地声 8 | 是 | 它是全场唯一「**为了响而存在**」的道具——比任何动作都响才对得起玩家花掉的那一回合与那一格背包 |
| 甩不出去**不消耗**道具 | 是 | 与「满血不吃三明治」「场上无怪不射蛛网弹」同一条不浪费规则 ⇒ `use_item` 返回 False |
| 投掷**不造成伤害** | 是 | 沿用 #10「听觉只惊动、不增伤」；它是战术道具不是武器 |
