# T-004 · 道具与背包（M4）

## 一入一出（In/Out）
- **入**：M2 有战斗结算、M3 有怪物 AI，但地图上没有任何可交互物，玩家除了攻击与移动别无选择；击杀怪物也没有正反馈。
- **出**：地面可放置道具实体；玩家可拾取进背包（有容量上限）、可按序号使用并产生效果；怪物死亡时按 Seed 概率掉落道具。全程随机仅经 `RandomSource`，同 seed + 同输入序列 ⇒ 同结果。

## 委托级别
- **S（自主完成）**：范围清晰、红线明确（#1/#2/#3/#4 已落地，#5/#6 由本单新增）、无外部依赖、复用 M2 `Monster` 与 M3 `monster_act`。

## 验收分级
- **A（必过，门禁）**：`tests/test_items.py` 全绿——含地面生成（墙/越界拒绝）、拾取进包、地面移除、**背包容量上限 #5**（满包拾取失败且道具留在地面）、三明治治疗且不超上限 #6、满血不消耗、蛛网弹对最近怪物造成伤害 + 束缚 1 回合、纳米强化剂提升蛛网拳伤害、无效序号返回 False、掉落同 seed 可重现（#1/#2）、渲染显示道具；`python scripts/gate.py` 四道门 ALL GREEN。
- **B（建议）**：`python main.py` 能演示「走到道具格 → 拾取 → 背包内容 → 残血吃三明治 / 用蛛网弹束缚 → 击杀掉落」。
- **C（可选）**：道具堆叠、背包排序/丢弃、装备槽、商店。

## 范围边界
- 不含程序化关卡（M5）、视野/迷雾（后续）、道具随机属性的稀有度词条。
- 道具只在地面生成（M5 程序化生成时复用 `spawn_item`）；**怪物生成仍手摆**（M5 范畴）。
- 掉落概率与掉落种类均经 `self.rng`（`chance` / `choice`），不引入第二个随机源（#1）。
- 背包满时**拾取失败、道具留在地面**，不做自动替换/丢弃（避免引入新规则歧义）。
- 「蛛网弹」目标取曼哈顿距离最近的存活怪物，平局取生成顺序靠前者（确定性）。

## 不变量摘录（落 M4）
- #1 随机必须 Seed 注入：掉落判定 `rng.chance`、掉落种类 `rng.choice` 均经 `self.rng`；`game.py` 不直接引入随机模块（seed-guard 拦截）。
- #2 回合确定性：掉落仅在「怪物死亡」这一确定性事件上掷骰；`chase` 依旧不消耗 rng；同 seed + 同输入序列 ⇒ 同掉落。
- #3 玩家 HP 永不为负：仍由 `_hurt_player` 的 `max(0, ...)` 钳制。
- #4 不可越界/穿墙：道具只生成在「界内且非墙」的格子；`spawn_item` 对非法格返回 `None`。
- **#5 背包容量上限（本单新增）**：`len(inventory) <= INVENTORY_CAPACITY(=5)`；满包时 `pick_up()` 返回 `None` 且道具留在地面。判定：`tests/test_items.py::TestInventoryCapacity`。
- **#6 玩家 HP 不超过上限（本单新增）**：治疗经 `_heal_player` 的 `min(max_hp, ...)` 钳制。判定：`tests/test_items.py::TestSandwich`。

## 道具登记（蜘蛛侠 MCU 荷兰弟版主题）
| key | 名称 | 效果 |
|---|---|---|
| `sandwich` | 梅姨的三明治 | 恢复 6 点 HP（不超过上限 #6）；满血时不被消耗 |
| `web_cartridge` | 蛛网发射器备用芯 | 向最近存活敌人射出蛛网弹：5 点伤害 + **束缚 1 回合**（跳过其下一次行动） |
| `nano_boost` | 斯塔克纳米强化剂 | 蛛网拳基础伤害永久 +2（本局内累加） |

## 掉落规则
- 触发时机：怪物 HP 归零时（蛛网拳或蛛网弹击杀均可）。
- `DROP_PROB = 0.5`：先 `rng.chance`，再 `rng.choice(ITEM_KEYS)`；目标格已有道具则放弃生成（不叠放）。
- 掉落格 = 怪物死亡时所在格。
