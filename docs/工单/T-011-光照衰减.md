# T-011 · 光照衰减（M11）

## 一入一出（In/Out）
- **入**：从 M1 起，整张地图是「全亮」的——房间、走廊、死角一律平等可见，怪物感知半径也恒为满值（7）。
  但蜘蛛侠的纽约是夜：房间有灯、走廊与死角昏暗。缺少「明暗」这一维，潜行/摸哨就少了「环境」这一层筹码
  （M8 接力时已把光照衰减列为下一步候选，与 ANSI 颜色高亮并列）。HANDOFF 给 M11 的指令就是它：
  **暗处降低怪物感知半径 / 明暗梯度**。
- **出**：一套**纯几何、零随机**的光照层——
  1. 光照场 `src/rogue/light.py`：光源 = 房间中心固定灯（`ROOM_LIGHT_RADIUS=9`）+ 玩家随身蛛丝微光
     （`PLAYER_GLOW_RADIUS=4`）；光**遇墙即断**、随距离线性衰减；每格落到「暗 / 昏暗 / 明」三档。
  2. 玩法：暗处的怪物感知半径被缩短（全黑只看 2 格、昏暗 4 格、明亮 7 格），且**只缩短、不放大**
     ⇒ 不变量 #9 的硬性质「怪看得见你 ⇒ 你看得见它」不被破坏。
  3. 表现：地图按光照给出**明暗梯度**（`color.py` 在 `colorize` 里压暗暗处的地板），纯装饰、不改字形。
  - 新开关 `light`（**默认关闭、显式 opt-in**，与 `fov`/`stealth`/`noise` 同一哲学）：
    `Game(..., light=True)` / `Game.procedural(..., light=True)` / `python main.py --light`。
    关闭时怪物感知半径恒满、`render()` 字形一字不差 ⇒ M1~M10 一字节不变。

## 验收分级
- **A（必过，门禁）**：`tests/test_light.py` 全绿——
  - 光照是**纯几何、零随机**：`light_contribution` / `light_level` / `light_field` 不引入随机模块、
    不消耗 `RandomSource`（seed-guard 仍只放行 `rng.py`）。
  - 暗处怪物感知半径缩短且**恒 ≤ MONSTER_SIGHT_RADIUS**（7）⇒
    机器判定「怪看得见你 ⇒ 你看得见它」在 `light+stealth` 下仍成立
    （`TestLightSymmetry::test_light_monster_sees_you_you_can_see`）。
  - `render()` 字形在 `light=True` 与 `light=False` 下**逐字相同**（`TestRenderPurity::test_render_glyphs_identical_with_light`）
    ⇒ 既有 260 例规格全部不受影响（不变量 #8）。
  - `colorize(..., light=...)` 只压暗地形、实体字形不变；`light=None` 时退化为旧行为、地板原样返回。
  - `python scripts/gate.py` 四道门 ALL GREEN，棘轮 260 → 288。
- **B（建议）**：`python main.py --light` 在终端里地图按光照变暗；`python main.py --light --stealth`
  下暗处的哨兵在更远的距离上才发现不了你（摸哨更有操作空间）。默认 / 潜行 / 听觉三条演示路径
  不加 `--light` 时逐字节不变（光照默认关）。
- **C（可选）**：动态光源（开关灯、手电）、按地形类型给不同底色、把「明暗梯度」也做成可配置主题、
  光照影响玩家自身视野（目前只影响怪物感知，与 M6「视野是渲染层」一致，故不改）。

## 范围边界
- **光照只缩短怪物感知半径，不改变「显示什么」给玩家**：玩家视野（M6）仍按原逻辑，光照不动它；
  明暗梯度只在 `color.py` 上色层（与 M10 同哲学：展示层不进 `Game`/`render()`）。
- **不引入任何随机**：光照场只依赖 `grid` + 光源坐标，是确定性几何；不消耗 `RandomSource`，不读游戏状态以外。
- **只缩短、不放大**：`monster_sight_radius` 对任何光照等级返回值 ≤ `MONSTER_SIGHT_RADIUS`（7），
  这是「对称硬性质不破」的数学前提，也是门禁机器判定守住的红线。
- **光遇墙即断**（与 M6 视线同哲学）：与 M8 声音「绕墙」本质不同——光照场用视线 + 距离衰减，
  不是 Dijkstra 绕墙；于是「房间亮、走廊暗」的梯度天然成立，墙后是绝对遮挡而非「变闷」。
- **默认关闭、opt-in**：`light=False` 时 `light_level_at` 恒返回「明」、`update_light` 清空场，
  任何查询都不走光照分支 ⇒ M1~M10 行为与回放一字节不变。

## 不变量摘录（落 M11）
- #12 光照衰减（新）：纯几何、零随机；光照默认关闭（`light=False` ⇒ 怪物感知半径恒满、
  `render()` 字形一字不差，M1~M10 一字节不变）；暗处只缩短怪物感知半径（恒 ≤ MONSTER_SIGHT_RADIUS），
  所以「怪看得见你 ⇒ 你看得见它」的硬性质不破。
- #1 随机仅经 `RandomSource`：`light.py` 不引入任何随机调用。
- #2 回合确定性：光照场只依赖 `grid` + 光源 ⇒ 同状态同场，不消耗随机、不扰动回放。
- #8 渲染纯净性（延伸）：明暗梯度只在 `colorize` 包裹层，不改 `render()` 字形。
- #9 感知/潜行确定性（延伸）：光照只缩短感知半径、不引入随机、不放大 ⇒ 对称硬性质不破。

## 常量表
| 常量 | 值 | 含义 |
|---|---|---|
| `ROOM_LIGHT_RADIUS` | 9 | 房间中心固定光源半径（大到能照亮整间房） |
| `PLAYER_GLOW_RADIUS` | 4 | 蜘蛛侠随身蛛丝微光半径（只够看清脚下几步） |
| `LIGHT_LEVEL_DARK` / `DIM` / `LIT` | 0 / 1 / 2 | 光照三档：全黑 / 昏暗 / 明亮 |
| `LIT_CUTOFF` / `DIM_CUTOFF` | 3 / 1 | 光源贡献 ≥ 此值 ⇒ 落到对应档位 |
| `MONSTER_SIGHT_DARK` / `DIM` | 2 / 4 | 对应档位下怪物感知半径（均 < 7） |

## 设计决策
| 决策 | 选择 | 理由 |
|---|---|---|
| 光源 = 房间中心灯 + 玩家微光 | 是 | 房间有灯、走廊暗，天然形成明暗梯度；玩家微光让你脚下总有一圈亮，但远处的暗角仍是怪的盲区 |
| 光遇墙即断（视线 + 衰减） | 是 | 与 M6 视线同哲学；区别于 M8 声音绕墙——墙在光照里是绝对遮挡，梯度才有意义 |
| 只缩短、不放大怪物半径 | 是 | 数学上守住「怪看得见你 ⇒ 你看得见它」（怪半径 7 < 玩家 8）；否则会出现看不见你的幽灵猎手 |
| 明暗梯度放 `color.py` 展示层 | 是 | 与 M10 同哲学：`render()` 字形零改动 ⇒ 260 例既有规格零风险 |
| 默认关闭、显式 opt-in | 是 | 与 `fov`/`stealth`/`noise` 同一哲学；关闭时一字节不变 |
| 玩家视野不受光照影响 | 是 | 与 M6「视野是渲染层、不参与玩法」一致；光照只动「怪物能否看见你」这一感知侧 |
