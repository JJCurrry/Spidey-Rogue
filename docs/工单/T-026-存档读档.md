# T-026 · 存档 / 读档（save / load）

## 一入一出（In/Out）
- **入**：游戏状态目前不持久化——关掉终端 / 关掉窗口即丢，一局只要没通关（或没走到想玩的层）就得从头打。
  交接文档（HANDOFF-T001，下一步候选②）明确把「存档 / 读档」列为后续里程碑。用户根据交接文档要求实现它。
- **出**：在**不碰玩法内核、不引入随机、确定性不变、默认零回归**的前提下，给游戏加一套序列化存档：
  1. **完整状态快照**：新增 `Game.to_dict()`（导出）/ `Game.apply_state()`（恢复）/ `Game.from_dict()`（重建）
     / `Game.save(path)` / `Game.load(path)` / `Game.load_into(path)`。序列化「seed + PRNG 内部状态 + 全部玩法状态」
     （玩家 HP / 背包 / 纳米加成 / 地图 grid / rooms / stairs / 怪物 / 道具 / 灯开关 / 灯光场 / 视野记忆 / 各类开关与 boss）。
  2. **确定性不破（不变量 #2 / #26）**：PRNG 内部状态经 `RandomSource.get_state/set_state` 完整保存，
     读档后随机序列无缝衔接；`to_dict` 对所有集合 / 字典按可复现顺序排序导出 ⇒ 导出幂等、可还原、
     同状态同字节。
  3. **交互可玩**：`main.py` 的 `_handle_key` 新增大写 `S`（存档）/ `L`（读档）键，`--play` / `--gui`
     模式下一键存取（默认路径 `savegame.json`，已加入 `.gitignore`）。小写 `s`/`l` 仍是移动，不冲突。
  4. **opt-in、默认零回归**：游戏照常运行不会触发任何存读档；不加参数时与 M25 逐字节一致。
     `tests/test_save.py`（10 例）覆盖 JSON 可序列化 / dict 往返幂等 / 文件往返 / load_into 原地恢复 /
     读档后确定性 / rng 序列衔接 / 灯光开关状态保留 / 教学图零回归；`python scripts/gate.py` 四道门全绿（564 → 574）。

## 委托级别
- 红线（不变量）改造：**否**。全在既有红线内新增能力，不放松任何一条；新增 #26（存读档确定性）只是把
  「save→load 逐字节同态、读档后续演化与并行推进一致」显式钉成机器可判定项。
- 玩法内核改造：**否**。`Game` 核心（rng/level/fov/sound/light/战斗/AI）一字未改；存读档只做「状态快照 ↔ 文件」
  的搬运，不调用任何随机、不写任何玩法状态（#1/#2/#8 延伸）。
- 视图层改造：**否**（仅 `_handle_key` 增两个按键分支 + 帮助文案，M21/M22 测试钉死的契约不变）。

## 设计要点（与全项目一致）
- **本质保存「seed + 输入序列」的等价物**：交接文档点明「存档本质就是存 seed + 输入序列」。本实现更稳妥地
  直接存「seed + PRNG 内部状态 + 完整状态快照」——除 rng 内部位置外，连衍生状态（visible/explored/灯光场/
  switched_lights 等）也原样保存，读档即「原地还原」，不需要重放整段输入即可精确恢复，且对 fov/light/switch
  等开关的全状态一致。
- **PRNG 状态是关键**：只存 seed 不够——游戏进行到中途时 rng 早已消费过（关卡生成、撒点、怪物游走、伤害浮动），
  必须把 `random.Random.getstate()` 一并存下；`set_state` 还原后，后续每一次 rng 调用都与「从未存读」逐字节衔接。
- **确定性导出**：坐标集合转列表后 `sorted`，`dict` 项转 `(list(key), value)` 后 `sorted`，`json.dump(sort_keys=True)`
  ⇒ 同状态永远导出同一字节，往返零漂移。
- **opt-in 默认关闭**：游戏不自动存；只有玩家按 `S` 或显式 `Game.save()` 才写盘，与 M6~M25 的 opt-in 哲学一致，
  不加参数时演示与 M25 逐字节一致。

## 验证
- 门控：`python scripts/gate.py` 四道门全绿（574 例，+10）。
- 回归：`python main.py` 默认与 M25 逐字节一致（存读档未触发）；`--play` 下按 `S` 存、`L` 读回，继续游玩状态无缝。
- 机器判定：`tests/test_save.py` —— JSON 可序列化 / dict 往返幂等 / 文件往返 / load_into 原地恢复 /
  读档后确定性（同存档 + 同后续输入 ⇒ 同终态）/ rng 序列衔接 / 灯光开关状态保留 / 教学图零回归 / 存档不改玩法结果。
- 确定性证据：`test_determinism_after_load` 在存档点之后对「原实例」与「读档实例」施加同一段输入序列，
  断言两者 `to_dict()` 完全相同。
