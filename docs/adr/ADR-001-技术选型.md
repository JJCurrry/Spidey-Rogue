# ADR-001 · 技术选型

## 状态
已采纳（M1）

## 背景
要一个人用 AI Coding 方式长期迭代一个游戏，且能演示课程的七件套 + 流水线。

## 决策
- **Python 3.11 + 终端 ASCII**：零前端负担，能直接复用 demo 的 unittest/gate 流水线；
  先把玩法逻辑跑顺，后续可升级 Web。
- **unittest（零依赖）**：门禁在任意环境都能跑，不依赖 pytest 安装。
- **随机集中到 `rng.py` 的 `RandomSource`**：把"可测性"红线落成单点，便于 seed-guard 扫描。
- **不引入游戏引擎**：保持代码可读、AI 易改。

## 后果
- 优点：管线可原样复用；红线清晰；新人读 `CLAUDE.md` 即上手。
- 取舍：终端画面表现力弱（后续里程碑再考虑渲染层）。
