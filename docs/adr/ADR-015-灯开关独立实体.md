# ADR-015 · 灯开关独立实体（M19）

## 状态
已采纳（M19）

## 背景
M14 让蛛网射中房间中心灯的拉链翻转房间灯，M16 进一步让蛛网射碎房间中心灯泡（一次性不可逆）。
两者都把「控制点」放在天花板中央的灯具 `room.center`。接力候选里登记了「灯开关独立实体」：
把现实里「墙边的开关」与「天花板上的灯泡」分开——蛛网够得到的是**墙边开关**，翻/碎的是它控制的房间灯。

约束与 M6~M18 同款：
- 熔断②禁止改/删测试凑绿 ⇒ 既有 445 例不能破；
- 不变量 #1/#2 ⇒ 摆位/开关操作若消耗 `RandomSource`，同一 seed 的既有回放全部作废；
- 不变量 #9 的硬性质「怪看得见你 ⇒ 你看得见它」不能被破坏（开关只移除光源、不放大）；
- 不变量 #8 ⇒ `render()` 字形一字不差、新能力必须是 opt-in 默认关闭（默认无 `=`）；
- 不变量 #10 ⇒ 轻响只经 `emit_noise` → `Monster.alert(cause=CAUSE_SOUND)` 唯一入口、声源在灯具处。

## 决策
- **保留 M14/M16 的 `toggle_light(room.center)` / `destroy_light(room.center)` API 不动**，平行新增
  开关实体与开关 API：既有 445 例（含断言 `render()` 字形子集不含 `=` 的 `test_fov_on_uses_original_glyphs`）
  零回归。M19 的 `=` 字形只在 `switches=True` 时出现，而该测试不开开关 ⇒ 不受影响。
- **开关是「灯具的解耦控制手柄」**：每个房间在**房间外沿相邻且本身是墙**的格子上摆一个 `LightSwitch`
  （扫描顺序 北→南→西→东 取首个命中墙格，确定性、零随机、不消耗 `RandomSource`）。蛛网够得到开关，
  翻/碎的却是该房间天花板那盏灯（`room.center`）⇒ 光照几何、暗处缩短怪物感知/玩家视野、声源位置
  全部与 M14/M16 同源 ⇒ 行为零回归。
- **复用同一份状态集合**：`toggle_switch` 翻 `switched_lights[room.center]`（与 M14 `toggle_light` 同源），
  `destroy_switch` 把 `room.center` 加入 `destroyed_lights`（与 M16 `destroy_light` 同源）并标记
  `sw.destroyed`（不可逆）；`_light_sources()` 跳过这两个集合的逻辑**完全不用改**。
- **几何约束与 M14/M16 同构，但瞄准「开关格」**：`can_toggle_switch` / `can_destroy_switch` 校验——
  开关已启用 + 光照已开 + (x,y) 是某开关 + 开关未碎 + 切比雪夫距离 ≤ `WEB_LIGHT_RANGE`(6)（含脚下）
  + 玩家**看得见开关**（`has_line_of_sight`，蛛网走直线遇墙即断）。五条（destroy 多一条「尚未被碎」）。
- **声源在灯具处、不在开关格、不在玩家处**：toggle 发 `NOISE_TOGGLE_LIGHT=3`、destroy 发
  `NOISE_SHATTER_BULB=3`，都从 `room.center` 传出 ⇒ M8 调虎离山成立（与 M14/M16 同值、同原则）。
  这是「开关路径保留 M16 已验证 3 关演示」的关键：声学行为一字不差。
- **opt-in（默认关闭）**：`switches=False` ⇒ `_place_switches` 不摆实体、`render()` 不含 `=`、
  默认/潜行/听觉三条演示与 M18 逐字节一致；`main.py` 设 `switches=light`（有光才有开关）。
- **`render()` 只加字形、不改状态**：全图 `_render_full` 在怪物之后把未碎开关画成 `=`；迷雾 `_render_fog`
  在已探索格画 `=`（已碎则不画，退回底层墙 `#`）。`render()` 不改写 `grid`/HP/背包/怪物状态（#8 延伸）。
- **换层重置**：`load_level` 清空 `switched_lights`/`destroyed_lights` 并重摆 `switches`
  （`switches_enabled` 跨层保留），新楼层 = 新房间 = 新开关 = 新灯。
- **主线演示接入**：`--light --stealth` 下 `step 0b` 改为蛛网射碎「未察觉敌人所在房间**墙边开关**的灯泡」，
  `_light_to_destroy` 遍历 `game.switches`（房间含未察觉敌人 + 玩家够得着墙上开关），行为等价于
  M18 的「射碎灯具」，只是瞄准坐标从 `room.center` 换成墙边开关。

## 后果
- 优点：把「控制点」从天花板灯具解耦到墙边开关——更真实的「摸黑找墙上的开关」体验，且开关/灯具
  坐标解耦后，未来若要「开关在 A 墙、灯在 B 房」或「一个开关控多盏灯」都只需扩展 `LightSwitch`，
  不动 M14/M16 的光照场逻辑。M14 的「可逆关灯」与 M16 的「不可逆碎灯」两条战术通过开关实体照常生效，
  `--light --stealth` 演示 7/10 通关（与 M18 灯具基线一致、无回归）、`--flashlight --stealth` 10/10。
- 取舍：
  - 开关摆在房间外沿墙格，玩家需对「墙」而非「房间中心」有视线与射程——在凸房间里从内部看外沿墙一般清晰，
    但大房间远墙开关可能超射程，玩家需走近；这是 M14/M16「够得着灯具」的同构约束，不引入新风险；
  - 已碎开关退回 `#` 且不可再 toggle，与 M16「已碎灯不可 toggle」一致；
  - `=` 字形只出现在 `switches=True` 路径，默认演示与 M18 逐字节一致（熔断②友好）；
  - 声源刻意仍在 `room.center`（不在开关格），保全 M16 已验证的「听觉调虎离山」演示行为不变。

## 不变量
- 新增 #19：灯开关独立实体（`LightSwitch`）是墙边开关、与天花板灯具 `room.center` 分离的独立控制手柄；
  opt-in（默认关闭、与 M18 逐字节一致）；摆位确定性、零随机、不消耗 `RandomSource`；
  `toggle_switch`/`destroy_switch` 翻同一份 `switched_lights`/`destroyed_lights`（按 `room.center` 记录）
  ⇒ 完全复用 M14/M16 光照场逻辑、行为零回归；几何约束纯几何零随机（瞄准开关格的 LOS + 切比雪夫 ≤ `WEB_LIGHT_RANGE`）；
  已碎不可再 toggle、destroy 后 `switched_lights` 同步清除、换层重置；
  声源在灯具处（不在开关格、不在玩家处）⇒ M8 调虎离山成立；`render()` 只加 `=` 字形、不改写 world state（#8 延伸）。
