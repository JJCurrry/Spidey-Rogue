# ADR-008 · 随身手电（M12 · 动态光源）

## 状态
已采纳（M12）

## 背景
M11 把「光」做成了环境层：房间有灯、走廊与死角昏暗，暗处的哨兵是近视眼。但所有光源是**静态**的
（房间中心固定灯 + 玩家随身微光），玩家无法主动改变自己周围的亮度——蜘蛛侠的蛛网发射器本该能
「探照」。接力棒给 M12 的方向之一正是「动态光源：可开关的灯 / 手电」（另一候选「光照影响玩家自身视野」
留作 M13）。

约束与 M1~M11 同款：
- 熔断②禁止改/删测试凑绿 ⇒ 既有 288 例不能破；
- 不变量 #1/#2 ⇒ 手电若消耗 `RandomSource`，同一 seed 的既有回放全部作废；
- 不变量 #9 的硬性质「怪看得见你 ⇒ 你看得见它」不能被破坏（怪半径 7 < 玩家 8 是数学前提）；
- 不变量 #8 ⇒ `render()` 字形一字不差，新能力必须是 opt-in 默认关闭。

## 决策
- **手电默认关闭，显式 opt-in**（`Game(..., flashlight=True)` / `Game.procedural(..., flashlight=True)` /
  `python main.py --flashlight`，后者隐含 `--light`）。与 M5「教学图默认」、M6「视野默认关」、M7「潜行默认关」、
  M8「听觉默认关」、M11「光照默认关」同一哲学。关闭时 `flashlight_on` 恒为 False ⇒
  `_light_sources` 不追加手电光源、`toggle_flashlight` 不改变任何行为 ⇒ M1~M11 一字节不变。
- **纯几何、零随机**：手电只在玩家处追加一个半径 `FLASHLIGHT_RADIUS=6` 的光源（介于微光 4 与房间灯 9 之间），
  复用 M11 的 `light_field`（光遇墙即断、随切比雪夫距离线性衰减）。`toggle_flashlight` 只翻转
  `flashlight_on` 标志并调用 `update_light()` 重算场——不消耗 `RandomSource`、不读游戏状态以外。
- **只缩短、不放大怪物感知半径**：开灯让玩家周围的格更亮 ⇒ 站在亮处的怪感知半径升到满值(7)，
  但恒 ≤ 7 ⇒ 「怪看得见你」必然落在玩家视野半径(8)之内，#9 硬性质不破。
  关灯则退回微光，远处的怪仍是近视——这就是手电的双刃性：**照亮战场也照亮自己**。
- **明暗梯度只在展示层**：`color.py` 的 `colorize` 已按 `light_field` 压暗地形；手电点亮玩家周围后，
  那片地板在带色渲染里更亮，实体字形不变、`render()` 一字不差 ⇒ 既有 288 例零侵入（不变量 #8 延伸）。
- **手电只动「怪物能否看见你」这一感知侧**：玩家自身视野（M6）仍按原逻辑，手电不动它——
  与「视野是渲染层、不参与玩法」一致。让光照也压短玩家视野留作 M13。

## 后果
- 优点：光从「环境」升级为「玩家工具」——潜行时关灯摸黑、交手时开灯照亮；演示里蜘蛛侠自动
  「潜行摸黑、交手开灯」（日志可见交替的「关掉/打开蛛网探照灯」）。`python main.py --flashlight`
  下玩家周围更亮；`python main.py --flashlight --stealth` 下暗处的哨兵因你关灯而更晚察觉你。
  `python main.py`（不加 `--flashlight`）的演示输出与 M11 逐字节一致（手电默认关、玩法日志零差异）。
- 取舍：
  - 手电半径(6) 刻意介于微光(4)与房间灯(9)之间：比微光照得远（有「扩亮」效果），又不喧宾夺主；
  - 手电是双刃剑：开灯让你更易被暗处的怪察觉（感知半径升到 7），所以「关灯潜行」才是它的真正收益；
  - 手电是玩家随身装备，`descend()` 跨层保留（与 HP / 背包 / 纳米加成同属跨层状态），不像落地声那样只在下潜触发；
  - 没有「可开关的房间灯」（蛛网射中灯开关）：那是另一条动态光源分支，留作后续候选。

## 不变量
- 新增 #13：随身手电纯几何零随机、默认关闭、只缩短怪物感知半径（恒 ≤ 7）⇒ #9 对称硬性质不破；
  `toggle_flashlight` 只翻标志 + 重算光照场，不改写任何玩法状态（换层保留）。
