# ADR-014 · 怪物感知改用环境场（M18）

## 状态
已采纳（M18）

## 背景
M11 引入光照衰减：暗处怪物感知半径缩短（全黑 2 / 昏暗 4 / 明 7，恒 ≤ 7），光源 = 房间中心固定灯 + **玩家随身微光**。
M12 追加随身手电、M14/M16 让房间灯可关/可碎。M17 把光照拆成两份场（`ambient_field` 仅房间灯 / `light_field` 房间灯 + 微光 + 手电），
并把「怪物感知改用环境场」登记为 C 级 opt-in 后续项。

待立项的核心问题是：**玩家被动微光（PLAYER_GLOW_RADIUS=4）也在怪物感知的完整场里**。
这造成一个隐性副作用——玩家走到暗处走廊时，身上的微光会把附近暗处的怪照到「明亮」档，
怪的感知半径不被缩短（等于把近视眼照成远视眼）。这与直觉相反：你身上的光本该只帮自己看路，
结果反而替暗处的怪点了灯，让你在暗中更易被发现。蜘蛛侠的被动微光不该是怪的探照灯。

约束与 M6~M17 同款：
- 熔断②禁止改/删测试凑绿 ⇒ 既有 443 例不能破（其中 `TestMonsterPerceptionUnchanged` 钉的是旧行为，需改写为新语义）；
- 不变量 #1/#2 ⇒ 改造若消耗 `RandomSource`，同一 seed 的既有回放全部作废；
- 不变量 #9 的硬性质「怪看得见你 ⇒ 你看得见它」不能被破坏（光照只缩短、不放大）；
- 不变量 #8 ⇒ `render()` 字形一字不差，新能力不改变任何既有渲染结果；
- 不变量 #12/#14 ⇒ 光照只缩短怪物感知/玩家视野（恒 ≤ 满值）；
- M12 手电双刃（开灯让你更易被暗处怪察觉）必须保留——不能因为排除微光就把手电也从怪物感知里拿掉。

## 决策
- **怪物感知半径判定改走「怪物感知光场」**：`monster_can_see_player` 中
  `monster_sight_radius(self.light_level_at(...))` 改为 `monster_sight_radius(self.monster_light_level_at(...))`。
  该光场 = **房间中心固定灯 + 随身手电，不含玩家被动微光**，精确修正上述副作用。
- **复用 `light` 开关，不新增开关**：M18 只在 `light=True` 时有意义；`light=False` ⇒
  怪物感知光场清空，`monster_light_level_at` 恒返回「明亮」，M1~M17（light=False 三条）逐字节一致。
  与 M11「复用 light」、M13/M14「复用 light」、M17「复用 light」同一哲学。
- **新增一份场，与既有两份同源**：`update_light()` 现在重算三份——`ambient_field` / `light_field` / `monster_light_field`。
  新增 `_monster_light_sources()` = `_ambient_sources()`（房间灯，跳过 `switched_lights`/`destroyed_lights`）+（手电源，若 `flashlight_on`）；
  显式**不追加**玩家被动微光源。三份场同源、幂等、纯几何、零随机、不消耗 `RandomSource`、不改写 `grid`/HP/背包/怪物状态。
- **新增只读查询 `monster_light_level_at(x, y)`**：与 `light_level_at`/`ambient_level_at` 对称（光照关闭恒「明亮」），
  作为「怪物感知该看哪份光」的入口对外暴露；只供 M11 怪物感知半径判定消费。
- **渲染梯度不变**：`colorize` 明暗上色仍走完整场 `light_field`（含微光，按目标格光照算），`render()` 字形一字不差（#8 延伸）。
  排除微光只影响「怪物能不能看见你」，不影响「画面怎么画」。
- **保留手电双刃（M12）**：手电源仍在怪物感知光场里 ⇒ 你开手电仍会让自己在暗处的怪眼里更易被察觉；
  排除的只有「被动微光」，不是主动打出的手电。这一区分让 M12 的设计意图（双刃）不受损。

## 后果
- **正向**：怪物感知的照明语义变得自洽——只有「环境光（房间灯）+ 你主动打出的手电」才算数，
  玩家被动微光不再替暗处怪点灯；暗处怪仍是其应得的近视眼、你更难被暗处怪发现，
  「暗处近视」的直觉真正成立。`tests/test_flashlight.py::test_flashlight_makes_distant_monster_see_you`
  继续成立（手电仍照亮怪），证明双刃保留。
- **负向 / 成本**：这是一次**玩法修正**而非纯重构——`light=True` 下怪物在暗处走廊对你的感知更弱了
  （你更难被发现），平衡向玩家略微倾斜。已用 `python scripts/balance_check.py`（默认 30/30、潜行 28/30，与 M15/M17 基线一致）
  与七条演示（均通关、light=False 三条逐字节一致）确认无回归。
- **可观测性**：新增 `tests/test_ambient_light.py::TestMonsterPerceptionUsesAmbientExcludingGlow`
  （覆盖「排除被动微光 / 含手电 / 含房间灯」三态）与改写 `tests/test_light.py::test_passive_glow_does_not_light_monster`
  （原 `test_player_glow_lights_nearby_monster` 钉的是旧副作用，已改为断言新正确语义，非删测试凑绿）；
  gate 443 → 445。
- **风险**：该改动只影响 `light=True` 的怪物感知半径，不影响 `light=False` 的任何回放（恒满半径），
  也不影响 M13 玩家视野（仍走完整场）——二者消费点被测试钉死，误用会立即被 `TestUpdateFovUsesFullField` 拦下。

## 替代方案
- **（弃）直接用 M17 的 `ambient_level_at`（仅房间灯）**：会同时把**手电**也从怪物感知里排除，
  破坏 M12 手电双刃（`test_flashlight_makes_distant_monster_see_you` 会失败），且不符合候选本意
  「房间灯 + 手电，不含被动微光」。故新增独立的「怪物感知光场」而非复用环境场。
- **（弃）在 `monster_light_level_at` 里再排掉手电**：会让开手电的暗处怪退回全黑、失去 M12 双刃，
  违背「开灯让你更易被察觉」的设计，且会让上述 flash­light 测试失败。
- **（留作 C 级）光照影响蜘蛛感应半径 / 灯开关独立实体**：与 M18 正交，留待后续立项。
