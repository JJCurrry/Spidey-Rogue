# ADR-016 · 光照影响蜘蛛感应半径（M20）

## 状态
已采纳（M20）

## 背景
M6 引入蜘蛛感应（`SPIDER_SENSE_RADIUS=4`，切比雪夫、穿墙、只给 `?` 轮廓）作为「预警不是透视」的玩家辅助感知。
M11 让暗处缩短怪物感知半径、M13 让暗处缩短玩家视野半径——二者形成「黑暗削弱感知」的对称体系。
唯独蜘蛛感应半径一直恒为 4、不受光照约束。接力候选登记了「让光照也影响蜘蛛感应半径」，
但交接文件注明「蜘蛛感应是超能力，主题上是否该受光照约束需先定调」。

经确认采用**对称衰减**方向：蜘蛛感应半径也随光照衰减，补齐「黑暗三重削弱」的最后一块拼图。

约束与 M6~M19 同款：
- 熔断②禁止改/删测试凑绿 ⇒ 既有 478 例不能破；
- 不变量 #1/#2 ⇒ 半径衰减若消耗 `RandomSource`，同一 seed 的既有回放全部作废；
- 不变量 #9 的硬性质「怪看得见你 ⇒ 你看得见它」不能被破坏（感应半径只缩短不放大）；
- 不变量 #8 ⇒ `render()` 字形一字不差、新能力必须是 opt-in 默认关闭（`light=False` 时一字节不变）；
- 不变量 #20（新增）⇒ 光照衰减的纯几何、零随机、默认关闭语义。

## 决策
- **复用 M13 的光照定义**：`spider_sense()` 在 `light_enabled` 时按**目标（威胁）所在格**的光照等级算有效半径，
  读 `light_level_at(目标格)`（完整场：房间灯 + 玩家微光 + 手电），与 M13 玩家视野「按目标格光照算」完全对称。
  暗处缩短、亮处不变；只缩短不放大、恒 ≤ `SPIDER_SENSE_RADIUS`(4)。
- **三档映射**：`fov.spider_sense_radius(light_lvl)` —— 暗(0)→2、昏暗(1)→3、明(2)→4。
  新增常量 `SPIDER_SENSE_DARK=2` / `SPIDER_SENSE_DIM=3`（明档复用 `SPIDER_SENSE_RADIUS=4`）。
  暗处仍保留最小半径 2，避免「彻底无预警」破坏超能力设定。
- **纯几何、零随机**：`spider_sense_radius` 是纯函数，不涉及 `RandomSource`；`spider_sense()` 仍是只读查询
  （`grid` + `light_field` + 坐标），不改写怪物/HP/背包/光照场 ⇒ #2/#8 不破。
- **opt-in（默认关闭）**：`light=False` ⇒ `spider_sense()` 走常量 `SPIDER_SENSE_RADIUS=4`，
  与 M1~M19 逐字节一致；只有 `--light`（含 `--flashlight`）路径且存在黑暗格时，远处暗处威胁的 `?` 预警才收缩。
- **`render()` 字形一字不差**：`spider_sense()` 只改变「哪些隐藏威胁被列为 `?`」，不改任何字形；`render()` 纯净性（#8）仍成立。
- **对称硬性质不破**：感应半径恒 ≤ 视野/感知半径（暗 2 / 昏暗 3 / 明 4 ≤ 视野 8、≤ M13 玩家视野同档位），
  所以「怪看得见你 ⇒ 你看得见它」的 #9 硬性质不被破坏。

## 后果
- 优点：补齐「黑暗三重削弱」——M11 暗处缩短怪物感知、M13 暗处缩短玩家视野、M20 暗处缩短蜘蛛感应预警，
  体系在语义上完全自洽；暗处玩家既看不远、也感不到远处的潜伏威胁，但保留最小半径 2 的兜底预警。
  与 M13 同一定义（都按目标格光照、都读 `light_level_at`），认知成本最低、零新增光源概念。
- 取舍：
  - 暗处感应半径缩到 2，意味着暗走廊里距 3~4 的隐藏威胁不再给 `?` 预警——这是「黑暗更危险」的刻意设计，
    与 M11/M13 同一哲学；设计师若觉得过狠，可调 `SPIDER_SENSE_DARK`/`SPIDER_SENSE_DIM` 常量（纯调参、不破不变量）；
  - 与 M13 同款「按目标格光照」意味着玩家微光会照亮近处暗格、使其感应半径回升——物理上合理（你带着微光，近处东西你仍感得到）；
  - 默认演示（不加 `--light`）行为与 M19 逐字节一致，熔断②友好；
  - 新测试 28 例（纯函数档位 + 关灯零回归 + 开灯三档衰减 + 渲染联动 + 纯净 + 确定性），gate 棘轮 478 → 506。

## 不变量
- 新增 #20：光照影响蜘蛛感应半径——`light=True` 时 `spider_sense()` 按目标格光照算有效半径
  （暗 2 / 昏暗 3 / 明 4），与 M11 怪物感知、M13 玩家视野形成「黑暗三重削弱」对称；
  纯几何、零随机、不消耗 `RandomSource`；默认关闭（`light=False` ⇒ 半径恒 4，与 M1~M19 逐字节一致）；
  只缩短不放大、恒 ≤ `SPIDER_SENSE_RADIUS`(4)、暗处保留最小半径 2 ⇒ #9 对称硬性质不破；
  `render()` 字形一字不差（#8 延伸）。
