# ADR-011 · M15 怪物追击修正与攻击配平

- 状态：已采纳（Implemented）
- 日期：2026-08-30
- 关联工单：T-015
- 关联不变量：#2（回合确定性）、#9（感知/潜行确定性，未触及）

## 背景
M3 的默认追击路径 `_step_toward` 只比曼哈顿距离、平局按方向顺序裁决，会在玩家轴向往复时
让怪物锁轴震荡、永不贴上（seed 19 实测锁死 30+ 回合）。M7 潜行分支已用切比雪夫二次关键字
（`close_in=True`）修正，但老路径刻意留作后续项。本 ADR 决定在 M15 正式修掉它，并配平攻击值。

## 决策
1. **统一走 close_in=True**：默认 chase（潜行关闭）也调用
   `_step_toward_point(candidates, (px,py), close_in=True)`，与潜行分支一致。
   - 理由：曼哈顿平局时切比雪夫更小的那一步才是真的在逼近；只比曼哈顿会选「横跳」的那步。
   - 不变量影响：纯几何、零随机，不消耗 `RandomSource` ⇒ #2（确定性）不变。
2. **攻击值各降 1（1~3 → 0~2）**：`MONSTER_TABLE` 改为 `(0,0,1,1,2,1)`。
   - 理由：修复让怪物更可靠地贴上，整体威胁上升。实测三态：
     - 旧追击 + 旧攻击：默认 26/30（HANDOFF「现状」）
     - 新追击 + 旧攻击：**22/30**（「只修不配平」会掉）
     - 新追击 + 新攻击：**默认 30/30 / 潜行 28/30**（配平后，≥ 基线）
   - 0 伤害地板怪（街头小混混 / 迷途无人机）是 harmless fodder：仍占位、可被杀死、清场才能下潜，
     挠一下不破防。这是「各降 1」配平的代价，刻意保留（主题自洽）。

## 备选方案（已否决）
- **只降顶部那只怪（cap 到 2，保留 1/2）**：不足以抵消修复的威胁上升，实测落点接近 22/30，不达标。
- **降撒怪密度 0.55→0.45**：HANDOFF 实测无效（22/30，怪更快贴身把收益抵消）。
- **玩家 HP 20→24**：HANDOFF 实测 27/30，不如攻击配平（28/30）且改动更重。
- **不修、继续留作后续项**：违反本项目「已登记项终要立项」的约定，且 bug 在种子 19 演示中显著。

## 后果
- 默认追击行为改变（预期，核心玩法修正）；opt-in 开关（fov/stealth/noise/light）的既有字节一致性不受影响。
- 新增 5 例回归测试（`tests/test_chase_fix.py`）+ 平衡实测脚本（`scripts/balance_check.py`）。
- 既有无敌/相邻反击规则（M2/M3）不变，攻击值只是常量表下调。
