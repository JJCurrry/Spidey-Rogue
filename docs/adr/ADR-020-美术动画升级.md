# ADR-020 · Spider-Man 主题美术再升级（M24 · 动画 + 美术 + 音效）

## 状态
已采纳（M24）

## 背景
M23 把 M22 的纯色块升级成了程序化蜘蛛侠主题渲染（面具/蛛网地板/怪物图标/攻击蛛丝/感应脉冲/
主题 HUD），第一次「看起来像蜘蛛侠」。但仍是**静态贴图 + 轻量淡出特效**：角色不会动、攻击只有
一缕静止蛛丝、没有脚步与摆荡音、暗/亮差异仅靠色调。用户对「下一步」选了 **M23 续 · 主题美术再升级**，
路线为**纯程序化动画 + 美术再升级 + 音效升级**。

约束与 M1~M23 同款：
- 熔断②禁止改/删测试凑绿 ⇒ M23 的 541 例不能破；
- 不变量 #1/#2 ⇒ 任何新增随机都会让同 seed 的既有回放作废；
- 不变量 #8 渲染纯净性 ⇒ 视图层不改写游戏状态。

## 决策
- **动画由 `self.frame` 计数器驱动，零随机**：`PygameRenderer` 在 `draw()` 末尾 `self.frame += 1`，
  所有动画相位取 `self.frame % N`，纯几何、不消耗 `RandomSource`、不读写 `Game` ⇒ 确定性（#2）
  不受影响——机器判定的 `test_apply_keys_parity_with_terminal` 走 `apply_keys`（不经 draw/特效路径），
  仍与终端逐字节同态。
- **地形多帧预渲染**：`_make_floor`/`_make_wall` 增加 `phase` 参数，在 `__init__` 预渲染若干相位帧
  （地板蛛网轻闪、墙砖缝呼吸），`draw()` 按 `self.frame` 选帧 `blit`；小 cell（<16）仍只渲染单帧，
  保证 headless 测试轻量。保留 `tile_floor`/`tile_wall`/`tile_unseen` 等 M23 测试钉死的属性名
  （指向 phase-0 帧）。
- **角色动画（纯视图偏移）**：玩家待机呼吸（垂直浮动）、攻击突进（读取活动 web 特效方向做位移）、
  受击红闪（对比 `player_hp` 跨帧变化）；怪物待机浮动 + 红/蓝眼眨眼（眼形/亮度随相位振荡）。
  这些只是绘制时的偏移/颜色调制，不进 `Game`。
- **攻击动画：蛛网行进 + 火花迸发**：web 特效从「静止一缕丝」改为按 `progress` 从玩家向目标伸长；
  命中处新增 `burst` 特效（扩散同心环火花）。两者均为 `self.effects` 的视图状态、按帧衰减、不回写 `Game`。
- **蜘蛛感应扩散环**：`?` 预警由单团脉冲改为 2~3 圈随帧外扩淡出的同心环，更贴合「tingling」警报感；
  仍纯视图、不改字形。
- **氛围层**：① 暗角 vignette（四角径向压暗，noir 纽约夜色）；② 开灯房间光晕（`light_enabled` 时
  按 `game.light_level_at` 在明亮格叠柔光），强化 M11/M13/M20「黑暗三重削弱」的视觉反馈。两层皆
  半透明叠加、不碰状态。
- **音效升级（程序化合成 + 静默降级）**：在 M23 的 thwip/闷响之上，用 `wave`+`array` 内存合成更多
  短音——脚步 tick、蛛网摆荡 whoosh（扫频）、蜘蛛感应刺痛（高频短鸣）、胜利号角、落败 sting；
  `pygame.mixer` 懒初始化、整段 `try/except` 包裹；不可用（headless dummy / 缺音频）则
  `sound_on=False` 静默。触发点（仅视图）：移动→脚步、攻击→thwip+whoosh+闷响、新出现 `?`→刺痛、
  终局→胜/败。音效从不读写游戏状态 ⇒ #2 不变。
- **保持 M22/M23 契约**：`tile_color`/`pixel_pos`/`translate_key` 三个被钉死的函数**行为不变**（实体
  字形仍返回 M22 的颜色元组）；`run` 主循环仍与 `--play` 终端路径同构（共用 `_handle_key`）；
  `_draw_*` helper 签名保持（新增可选动画参数带默认值，旧调用仍成立）；`--gui` 仍 opt-in，默认仍是
  脚本 demo / `--play` 终端，零回归。

## 后果
- 优点：窗口第一次「活起来」——角色呼吸、怪物眨眼浮动、蛛网甩出并命中迸火花、蜘蛛感应扩散预警、
  纽约暗夜的暗角与开灯光晕，配合脚步/摆荡/感应音效，沉浸感显著强于 M23 静态画面；且对 M1~M23 的
  541 例规格与红线零侵入（门禁四道门全绿）。
- 取舍：
  - 美术仍是**几何程序化 + 帧动画**，非手绘骨骼动画——零素材依赖、确定性满分，精细度受限于图元；
    若日后要做像素美术，预渲染贴图已按帧组织，换成 `tiles/*.png` 序列帧即可（接口已留好）。
  - 动画相位基于帧计数而非真实时间 ⇒ 帧率变化会改动画速度，但纯属观感、不影响任何状态/确定性。
  - 音效为内存合成短音，非专业音轨；默认开但可静默降级，不阻断任何流程。
- 引入/改动仅限 `src/rogue/render_pygame.py` 与 `tests/test_gui.py` 与 `scripts/.ratchet`；
  `src/rogue/*` 玩法内核一字未改。
