# ADR-019 · Spider-Man 主题化 GUI 渲染（M23）

## 状态
已采纳（M23）

## 背景
M22 用 Pygame 把 ASCII 视图层换成了真实窗口，但受「v1 用纯色块、不做
Sprite/动画/音效（留 M23）」的限制，`PygameRenderer.draw()` 只是给每个格子画一个
`pygame.draw.rect` 色块，角色也是 `game.render()` 的 ASCII 字形套调色板。结果窗口里
只有红/品红/绿的方块，与「MCU 荷兰弟版蜘蛛侠」主题毫无关联——用户明确反馈
「画面非常简陋，和蜘蛛侠感觉完全无关」。

约束与 M1~M22 同款：
- 熔断②禁止改/删测试凑绿 ⇒ M22 的 533 例不能破；
- 不变量 #1/#2 ⇒ 任何新增随机都会让同 seed 的既有回放作废；
- 不变量 #8 渲染纯净性 ⇒ 视图层不改写游戏状态。

## 决策
- **程序化绘制，不引入素材文件**：所有美术用 `pygame` 图元（圆/线/椭圆/矩形 +
  预渲染 `Surface` 贴图）在运行时画出来，**不依赖任何外部 png/字体**。理由：
  自包含（无需分发资源）、可复现、且天然满足确定性（无随机、无 IO）；
  蜘蛛侠面具/蛛网纹理/怪物图标全靠几何绘制，红蓝黑配色直接呼应战衣。
- **地形贴图：预渲染 Surface + 按可见性双版**：在 `__init__` 按 `self.cell` 预先
  画出 `floor / floor_dim / wall / wall_dim / unseen` 五张小贴图（地板带 faint 蛛网
  纹理、墙带砖缝 + 红蓝描边），`draw()` 直接 `blit`，避免每帧每格重画矢量（性能 +
  确定性一致）。小 cell（<16）跳过精细纹理，保证 headless 测试轻量。
- **实体分层绘制**：每格先 `blit` 地形贴图（地形取自 `game.grid`，墙/地板），
  再按 `game.render()` 的字形叠加实体图标——`render()` 已负责迷雾可见性门控与
  优先级（`?`<`>`<`!`<`M`<`@`），视图只负责「画得好看」。`@`→蜘蛛侠面具、
  `M/m/~`→读 `game.monster_at(x,y)` 取实体画不同图标、`!`→按 `game.items` 的
  `key` 画不同道具图标、`>`→绿色下行门、`=`→黄色开关、`?`→红色脉冲光晕。
- **攻击蛛网特效 + 命中闪光（纯视图状态）**：把 M22 主循环里的「按键→handle_key」
  抽成 `step(token, handle_key)`，在动作前快照怪物 HP 集合、动作后检测「谁掉血」
  ⇒ 在玩家→目标间生成一缕淡出蛛丝（数帧 TTL）与命中白闪。`self.effects` 是
  renderer 自己的状态，按帧衰减、**不回写 `Game`**，故确定性（#2）不受影响——
  机器判定的 `test_apply_keys_parity_with_terminal` 走 `apply_keys`（不经特效路径），
  仍与终端逐字节同态。
- **合成音效（懒初始化 + 静默降级）**：用 `wave`+`array` 在内存合成「蛛网发射
  thwip」「命中闷响」两个短音，`pygame.mixer` 懒初始化、整段 `try/except` 包裹；
  不可用（headless dummy / 缺音频）则 `sound_on=False` 静默。音效从不读写游戏状态
  ⇒ #2 不变。
- **主题化 HUD**：底部红蓝标题条「SPIDER-MAN」+ 蛛网分隔线、红色血条
  （按 `player_hp/player_max_hp`）、楼层名、按道具上色的背包格、模式旗标、操作提示。
- **保持 M22 契约**：`tile_color` / `pixel_pos` / `translate_key` 三个被既有测试
  钉死的函数**行为不变**（实体字形仍返回 M22 的颜色元组）；`run` 主循环仍与
  `--play` 终端路径同构（共用 `_handle_key`）；`--gui` 仍 opt-in，默认仍是脚本
  demo / `--play` 终端，零回归。

## 后果
- 优点：窗口第一次「看起来像蜘蛛侠」——红底黑蛛网的战衣面具、带蛛网纹理的纽约
  楼层、攻击时一缕白蛛丝甩出、蜘蛛感应红色预警脉冲、红蓝主题 HUD；且对 M1~M22 的
  533 例规格与红线零侵入（门禁四道门全绿）。
- 取舍：
  - 美术是**几何程序化**而非手绘 Sprite——零素材依赖、确定性满分，但精细度受限于
    图元；后续若要做像素美术，可把预渲染贴图换成 `tiles/*.png`（接口已留好：地形
    走预渲染 `Surface`，实体走 `_draw_*` 矢量，替换其一即可）。
  - 动画是「淡出特效 + 脉冲光晕」的轻量方案，未做骨骼/帧动画（保持确定性与简单）；
  - 音效为内存合成短音，非专业音轨；默认开但可静默降级，不阻断任何流程。
- 引入/改动仅限 `src/rogue/render_pygame.py` 与 `tests/test_gui.py` 与 `main.py`
  的 `--gui` 构造参数；`src/rogue/*` 玩法内核一字未改。
