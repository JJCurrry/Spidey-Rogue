# ADR-003 · 怪物感知与潜行（M7）

## 状态
已采纳（M7）

## 背景
M3 的怪物 AI 是「全知」的：不管隔几堵墙、相距多远，所有怪每回合都朝玩家逼近。
M6 给玩家补上了视野与蜘蛛感应，却没有给敌人对称的「发现」概念，于是：
1. 一层楼永远退化成「一群怪同时冲过来」，潜行、绕后、逐个击破都不存在；
2. M6 明确了「视野是渲染层、不影响玩法」——如果怪物感知反过来改变 AI，
   会不会破坏不变量 #2（回合确定性）？会不会让既有 121 例规格失效？

约束与 M6 同款：
- 熔断②禁止改/删测试凑绿 ⇒ `test_ai.py` 的 11 例直接断言「怪物朝玩家位移」，
  新能力不能把它们打破；
- 不变量 #1/#2 ⇒ 感知若消耗 `RandomSource`，同一 seed 的既有回放全部作废。

## 决策
- **潜行默认关闭，显式 opt-in**（`Game(..., stealth=True)` / `Game.procedural(rng, depth=1, stealth=True)`）。
  与 M5 的「教学图默认、程序化显式开启」、M6 的「视野默认关闭」同一哲学。
  关闭时 `Monster.alerted` 恒为 True ⇒ 怪物全知追击，M1~M6 的行为一字节不变。
- **感知纯几何、零随机**：`fov.monster_can_see` 复用 M6 的 `has_line_of_sight`
  （Bresenham 射线判遮挡），外加感知半径 7 与「同房间即察觉」两条。
  不引入随机模块、不消耗 `RandomSource`。
- **感知半径 7 < 玩家视野 8**：刻意差一格，保证玩家总能先发现敌人，
  否则双方同时看见，潜行退化成运气。
- **感知在世界回合开始时一次性更新**（`monster_turn` 开头调 `update_awareness`）。
  这是潜行成立的关键：玩家在自己回合从敌人视野外一步扑到面前时，
  敌人还停留在上一回合的「未察觉」状态——突袭窗口天然存在，
  不需要引入朝向 / 背身几何（那会让状态空间和测试用例数都翻倍）。
- **倒挂突袭（Web-Strike Takedown）**：攻击 `alerted=False` 的敌人 ⇒
  伤害 × `SNEAK_ATTACK_MULT(=2)`（确定性常数，不额外掷骰）、**不挨反击**；
  命中后该敌立刻转「已察觉」，下回合照常还手。
  入口是 `Game.web_strike(target)`：荡到目标身旁并立刻出手（移动 + 攻击同回合）。
- **摆荡射程必须是 2 步**（`WEB_STRIKE_RANGE=2`）。这是几何推导的结果，不是手感调参：
  攻击要求切比雪夫相邻，而相邻格之间的 Bresenham 线没有中间格 ⇒ **相邻必被看见**；
  只走一步则玩家出发点到怪物的曼哈顿距离恒为 2，而这条线上唯一的中间格正是落脚点本身
  ——要挡住视线就必须把落脚点变成墙，落脚点也就没了。两步才能「站在拐角外、绕过去扑面」。
  射程仍在可通行空间内 BFS（不穿墙，不变量 #4 成立）。
- **警觉状态机**：`alerted` / `alert_turns(=ALERT_MEMORY=3)` / `last_seen` / `home`。
  被惊动后扑向 `last_seen`（不是全知追踪）；看不见了就每回合递减，归零放弃、回巢待命。
  未察觉的 `chase` 怪回巢（确定性、不消耗 rng）；未察觉的 `wander` 怪照旧随机游走（偶尔改为回巢）。
- **画面上区分**：未察觉画小写 `m`、已察觉画 `M`。潜行关闭时全是 `M`
  ⇒ 既有 `assertIn("M", render())` 断言仍成立。
- **新增不变量 #9**：感知不消耗随机、突袭倍率是常数、潜行默认关闭。

## 后果
- 优点：潜行、绕后、逐个击破成立，清一层从「群殴」变成「有节奏的摸哨」；
  既有 121 例规格零改动全绿；`python main.py`（不加 `--stealth`）的演示输出与 M6 完全一致。
- 取舍：
  - 潜行开启后怪物行为分支改变 ⇒ `wander` 怪的 rng 消耗序列会与关闭时不同，
    同一 seed 下开启/关闭潜行的**演示结果不再一致**（这是玩法改变，不是确定性被破坏：
    同一模式内重放仍然逐字节相同，由 `TestStealthDeterminism` 判定）；
  - 演示脚本的寻路 AI 依然「知道全图」，它不会因为潜行而绕路躲视线——
    潜行只影响怪物是否发现你，不影响脚本的目标选择；
  - 没有朝向/背身 ⇒ 「从背后接近」在几何上等价于「从任何方向接近但此前不在视线内」，
    简化的代价是突袭判定不看方向。验收 C 再考虑补朝向。
