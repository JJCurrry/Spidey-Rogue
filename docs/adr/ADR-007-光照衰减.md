# ADR-007 · 光照衰减（M11）

## 状态
已采纳（M11）

## 背景
M1~M10 的地图是「全亮」的：房间、走廊、死角一律平等可见，怪物感知半径也恒为满值（7）。
但蜘蛛侠的纽约是夜——房间有灯、走廊与死角昏暗。HANDOFF 给 M11 留的指令就是
**暗处降低怪物感知半径 / 明暗梯度**：让「环境明暗」成为潜行/摸哨的一层筹码。

约束与 M6/M7/M8 同款：
- 熔断②禁止改/删测试凑绿 ⇒ 既有 260 例不能破；
- 不变量 #1/#2 ⇒ 光照若消耗 `RandomSource`，同一 seed 的既有回放全部作废；
- 不变量 #9 的硬性质「怪看得见你 ⇒ 你看得见它」不能被破坏（怪半径 7 < 玩家 8 是数学前提）。

## 决策
- **光照默认关闭，显式 opt-in**（`Game(..., light=True)` / `Game.procedural(..., light=True)` /
  `python main.py --light`）。与 M5「教学图默认」、M6「视野默认关」、M7「潜行默认关」、M8「听觉默认关」
  同一哲学。关闭时 `light_level_at` 恒返回「明」、`update_light` 清空场 ⇒ M1~M10 一字节不变。
- **纯几何、零随机**：新增 `src/rogue/light.py`，光照场 = 房间中心固定灯（`ROOM_LIGHT_RADIUS=9`）
  + 玩家随身蛛丝微光（`PLAYER_GLOW_RADIUS=4`）；光**遇墙即断**（复用 `fov.has_line_of_sight`）、
  随切比雪夫距离线性衰减；每格落到「暗 / 昏暗 / 明」三档。不引入随机模块、不消耗 `RandomSource`。
- **光遇墙即断（与 M6 视线同哲学，与 M8 声音绕墙不同）**：光照场用「视线 + 距离衰减」，
  不是声音那种绕墙 Dijkstra。墙在光照里是绝对遮挡 ⇒ 「房间亮、走廊暗」的梯度天然成立，
  也才配得上「躲进暗角」vs「站在灯下」的取舍。
- **只缩短、不放大怪物感知半径**：暗处 `MONSTER_SIGHT_DARK=2`、昏暗 `MONSTER_SIGHT_DIM=4`、
  明亮 `MONSTER_SIGHT_RADIUS=7`（均 < 7 不成立，仅等于）。`monster_sight_radius` 对任何光照等级
  返回值 ≤ 7 ⇒ 「怪看得见你」必然落在玩家视野半径（8）之内，#9 硬性质不破。
- **明暗梯度只在展示层**：`color.py` 的 `colorize` 扩展出可选 `light` 光照场，压暗暗处的地板；
  实体字形（`@ M m ~ ? ! > #`）颜色不变，`render()` 字形一字不差 ⇒ 既有 260 例零侵入（不变量 #8 延伸）。
- **光照只动「怪物能否看见你」这一感知侧**：玩家自身视野（M6）仍按原逻辑，光照不动它——
  与「视野是渲染层、不参与玩法」一致。

## 后果
- 优点：潜行从「只要在视野外就安全」多了一层「环境」——暗处的哨兵是近视眼，摸哨更有操作空间；
  `python main.py --light --stealth` 下玩家可在暗角里贴近而不被远处发现。`python main.py`
  （不加 `--light`）的演示输出与 M10 逐字节一致（光照默认关、玩法日志零差异）。
- 取舍：
  - 光照开启后演示回合数：默认路径不受影响（光照关）；`--light --stealth` 与 `--stealth` 同为
    `TURNS_PER_LEVEL * MAX_DEPTH = 240` 上限内（seed 19 下 `--light --stealth` 也能走完三层）；
  - 玩家微光半径（4）刻意小于房间灯半径（9）：你脚下总有一圈亮，但远处的暗角仍是盲区，
    这是「贴脸才被察觉」的操作窗口所在；
  - 没有「动态光源」（开关灯 / 手电）：目前光源是楼层几何（房间中心）+ 玩家位置，确定性、零随机；
  - 未让光照影响玩家自身视野：避免把「渲染层」概念改成玩法，守住 M6 的边界。

## 不变量
- 新增 #12：光照纯几何零随机、默认关闭、只缩短怪物感知半径（恒 ≤ 7）⇒ #9 对称硬性质不破。
