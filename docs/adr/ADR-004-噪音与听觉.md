# ADR-004 · 噪音与听觉（M8）

## 状态
已采纳（M8）

## 背景
M7 给怪物补上了「视觉」，潜行因此成立——但这条感知链只有一半：
1. 隔着两堵墙的敌人对你正在打的这一架毫无反应 ⇒ 「打完就撤」没有压力，
   潜行退化成「只要不在视线里就绝对安全」；
2. 被蛛网弹缠住、在走廊那头挣扎的怪也引不来同伴 ⇒ 玩家缺少「调虎离山」这类
   **用环境而非拳头**解决问题的手段。

HANDOFF 给 M8 留了三个候选：光照衰减 / 颜色高亮 / 噪音系统。选**噪音**的理由：
- 听觉是 M7「视觉」的直接对称项——同一套「感知 ⇒ `alerted` ⇒ 改变 AI 分支」的骨架
  可以原样复用，改动面最小；
- 光照衰减需要逐格光源数据（楼层生成要新增光照层、渲染要新增亮度），
  会同时碰 M5 与 M6 两条既有规格链；
- 颜色高亮是表现层，不产生玩法，且在纯 ASCII 门禁里难以机器判定。

约束与 M6/M7 同款：
- 熔断②禁止改/删测试凑绿 ⇒ 既有 168 例不能破；
- 不变量 #1/#2 ⇒ 听觉若消耗 `RandomSource`，同一 seed 的既有回放全部作废。

## 决策
- **听觉默认关闭，显式 opt-in**（`Game(..., noise=True)` / `Game.procedural(..., noise=True)`）。
  与 M5 的「教学图默认」、M6 的「视野默认关闭」、M7 的「潜行默认关闭」同一哲学。
  关闭时 `emit_noise` 是空操作、返回空表 ⇒ M1~M7 的行为一字节不变。
- **传播纯几何、零随机**：新增 `src/rogue/sound.py`，`noise_field` 在 `grid` 上跑 Dijkstra——
  踏入空地代价 1、踏入墙代价 3、声源自身 0，超过响度的格子不入場。
  不引入随机模块、不消耗 `RandomSource`。
- **墙是「闷」不是「隔音」**（代价 3 而非 ∞）：完全隔音会让「一墙之隔」变成绝对安全，
  听觉就退化成第二套视线；留一点泄漏才叫闷响，也才配得上「躲远一点 vs 躲到墙后」的取舍。
- **声音绕着走**：正因为墙要付费，三格厚的墙不如绕下面的走廊便宜 ⇒
  声音沿走廊传播而不是直线穿透。这是与视线（遇墙即断）的本质差别，
  也是「声音」在几何上值得单独开一个模块的原因。
- **响度是常量表、不掷骰**：与 #9 的突袭倍率同一哲学——感知层不吃随机，
  随机序列不被扰动，既有回放继续有效。
- **只有动作会响**：走路 / 拾取 / 吃三明治 / 注射纳米强化剂全无声
  （主题自洽：蜘蛛侠落地无响）。发声始终是玩家自己的选择。
- **声源未必是玩家**：被蛛网弹缠住的怪自己会挣扎出声（`NOISE_STRUGGLE`，声源在**它**那儿），
  同伴被引向它而不是你 ⇒ 听觉不只添压力，还添了一条「调虎离山」的解法。
  落地点是 `descend()`（下潜），开局那一层不发落地声——开局你已经在楼里了。
- **视听同时发生时以视觉为准**：视觉给的是实时位置，听觉只给声源。
  `update_awareness` 在世界回合开始时跑，会把「只是听见」的怪改写成「看见了」。
- **`Monster.alert_cause`**：`"sight"` / `"sound"` / `None`。被**直接命中**的怪记成「看见」
  （它正在挨打，不可能不知道人在哪）⇒ 画面上 `~` 只出现在「还没看见你」的敌人身上。
- **只惊动、不增伤**：听觉是感知层不是战斗层，被声音引来的怪仍要走过来才打得到你。
- **新增不变量 #10**：传播纯几何零随机、只经 `Monster.alert()` 生效、听觉默认关闭。

## 后果
- 优点：潜行从「不在视线里就绝对安全」变成「还要管住自己的动静」；
  `python main.py`（不加 `--noise`）的演示输出与 M7 逐字节一致（玩法日志零差异）。
- 取舍：
  - 听觉开启后演示回合数变长（seed 19 下约 208 回合跑完三层，潜行模式约 165，
    默认模式约 95；上限 `TURNS_PER_LEVEL * MAX_DEPTH = 240` 仍够用）；
  - 蛛网拳的响度（6）略小于怪物感知半径（7），落地声（8）略大——
    这是有意的：正面交手会惊动半个视野，悄悄摸哨则几乎无声；
  - 没有「主动制造响动」的技能（验收 C）：`emit_noise(x, y, loudness)` 已是公开 API，
    以后要加「往墙那头甩个罐子」只需给个入口，不必改传播层；
  - 未做声音的**方向性**与**持续时长**：一次发声 = 一帧噪声场，怪物不会「记着声音慢慢消失」。
