# ADR-017 · 可键盘操作玩法（M21）

## 状态
已采纳（M21）

## 背景
此前 `main.py` 只有一个脚本自动驾驶 demo：`_player_act` 是写死的寻路 AI，按 seed 程序化演示「逐层清怪下潜」，
用于回归与展示——玩家并不能手动操作。用户明确「游戏需要真正可键盘操作的玩法，且要能边开发边自己游玩测试」。

约束与 M1~M20 同款：
- 熔断②禁止改/删测试凑绿 ⇒ 既有 506 例不能破；
- 不变量 #1/#2 ⇒ 交互层若引入隐藏随机，同一 seed 的 demo 回放与平衡实测全部作废；
- 不变量 #4 ⇒ 移动不能斜向穿墙角；
- 不变量 #8 ⇒ 控制层不得改写 `grid`/HP/背包/怪物等玩法状态；
- 项目哲学（M6 起）⇒ 新能力默认 opt-in，不破坏默认 demo 行为。

## 决策
- **只加控制层，不碰玩法内核**：`_handle_key` / `_player_interactive` 完全调用 `Game` 既有公开方法
  （`move`/`player_attack`/`web_strike`/`pick_up`/`use_item`/`descend`/`toggle_flashlight`），
  不新增任何随机 ⇒ #1/#2 不破；`src/rogue/*` 一字未改（既有测试零回归）。
- **bump-to-attack（经典 roguelike 手感）**：`move` 遇怪返回 False（M2 不可穿怪），交互层据此改调 `player_attack`；
  不改写 `grid` 以外状态（#8 延伸）。
- **move 保持 4 向**（与 M1 网格一致）：避免斜向穿墙角破坏不变量 #4；方向键原始转义序列也纳入 `MOVE_KEYS` 映射，
  但默认用 `input()` 读取，WASD / hjkl 始终可用（前端是否发转义序列取决于终端，不强制）。
- **回合模型与 demo 一致**：有效动作（移动/攻击/拾取/用道具/等待/手电/突袭/下潜）消耗一个回合（随后 `game.monster_turn()`），
  无效/纯信息键（未知/`?`/`q`）不消耗回合 ⇒ 不扰动随机序列（#2）。
- **确定性（不变量 #2）**：玩家按键是「输入序列」的一部分；同 seed + 同按键序列 ⇒ 同结果。
  循环用注入式 `get_key` 单测验证（`test_determinism_same_keys_same_result`）。
- **opt-in（默认关闭）**：`main()` 新增 `--play` 进入交互；默认（无 `--play`）仍走 `_player_act` 自动驾驶 demo，
  `main()` 其余分支一字未动 ⇒ 演示与 M20 逐字节一致、balance_check 不受影响。
- **测试可注入**：`_player_interactive(game, color_on, get_key=input, echo=print)` 的 `get_key`/`echo` 均可注入，
  单测用假输入 + 静默回显，不依赖真实终端 stdin（跨平台、可复现）。

## 后果
- 优点：游戏从「只能看 demo」变成「能自己上手玩、能在开发中实测」，闭合了用户的核心诉求；
  控制层是薄封装，零玩法风险，门禁/平衡/评审全绿、零回归；操作说明内置（随时按 `?`）。
- 取舍：
  - 默认仍是自动驾驶 demo（opt-in），保证回归/平衡实测链路不被交互改动影响——这是「先登记后开工」流程与确定性红线的自然结果；
  - 交互模式暂未覆盖「射灭/射碎房间灯（或墙边开关）」的目标选择 UI（需选定房间，属 demo 自动战术），
    留作后续细化，不阻塞 M21；M9 垃圾桶盖在交互模式按 `1~5` 触发时复用 demo 的 `_decoy_spot` 自动选最优落点；
  - 方向键依赖终端发原始转义序列，部分前端可能只认 WASD/hjkl——已在操作说明与代码注释中注明。
- 新测试 15 例（动作映射 + 循环结局 + 确定性），gate 棘轮 506 → 521。

## 不变量
- 新增 #21：可键盘操作——`main._player_interactive` 键盘控制，`_handle_key` 只调用 Game 既有确定性方法，
  不引入任何随机 ⇒ #1/#2 不变；与脚本自动驾驶 demo（`_player_act`）共用同一套 Game 方法、互不影响（默认无 `--play` 仍走 demo，零回归）；
  撞怪即攻击（bump-to-attack，不改写 `grid` 以外状态，#8 延伸）；有效动作消耗一个回合、无效/纯信息键不消耗（不扰动随机序列，#2）；
  相同 seed + 相同按键序列 ⇒ 相同结果（#2，机器判定 `tests/test_interactive.py`）；move 保持 4 向（#4）；`--play` 为 opt-in。
