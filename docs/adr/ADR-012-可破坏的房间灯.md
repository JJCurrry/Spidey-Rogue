# ADR-012 · 可破坏的房间灯（M16）

## 状态
已采纳（M16）

## 背景
M11 把「光」做成了环境层——房间中心有固定灯、走廊昏暗，暗处的哨兵是近视眼。M14 进一步让玩家能
**翻转**房间灯（蛛网射中拉链，关了还能再拉开），把静态光源变成可操作的互动元素。但翻转始终是「可逆」的：
灯还在那儿，只是开关状态变了。

蜘蛛侠的蛛网带着冲量甩出去，本该能把**灯泡本身射碎**——一种比「拉链翻开关」更彻底、一次性不可逆的
「光操控」：`M14` 是「关灯」（可恢复），M16 是「把灯打没」（不可恢复）。
接力棒给 M16 的候选方向之一正是「可破坏的灯（M14 是翻转式，可破坏 = 一次性不可恢复）」。

约束与 M6~M15 同款：
- 熔断②禁止改/删测试凑绿 ⇒ 既有 432 例不能破；
- 不变量 #1/#2 ⇒ 破坏若消耗 `RandomSource`，同一 seed 的既有回放全部作废；
- 不变量 #9 的硬性质「怪看得见你 ⇒ 你看得见它」不能被破坏（破坏只缩短、不放大）；
- 不变量 #8 ⇒ `render()` 字形一字不差，新能力必须是 opt-in 默认关闭；
- 不变量 #12/#14 ⇒ 光照只缩短怪物感知/玩家视野（恒 ≤ 满值），破坏移除光源 ⇒ 只变暗。

## 决策
- **破坏性（destroy），不是翻转（toggle）**：M16 在 M14 翻转式之上加「不可逆」维度。
  主题上即蛛网带着冲量「啪」地射碎灯泡——碎了就没了，没有「再拉开」的选项。这让「光操控」从
  「可恢复开关」升级出一条「一次性永久战术承诺」：潜行路线里你本就不打算回来点亮它，
  碎灯 = 把这条路彻底封进黑暗。状态用 `destroyed_lights: set[Tile]`（已射碎灯泡的房间中心坐标），
  与 M14 的 `switched_lights` **分开**存（语义不同：可恢复 vs 不可逆），但 `_light_sources()` 合并跳过两者。
- **复用 `light` 开关，不新增开关**：M16 只在 `light=True` 时有意义；`light=False` ⇒
  `_light_sources` 不含房间灯（碎不碎都一样，光照场为空）⇒ `destroy_light` 恒返回 False（no-op）。
  与 M13「复用 light、不新增开关」、M14「复用 light」同一哲学。
- **纯几何、零随机**：`destroy_light` 只翻 `destroyed_lights` 集合 + 重算 `light_field`（`update_fov`）
  + 发出碎裂轻响（`emit_noise`，M8 联动）。不引入随机模块、不消耗 `RandomSource`、不改写 `grid`/HP/背包/怪物状态。
  与 `toggle_light`（M14）/`toggle_flashlight`（M12）同一零副作用哲学。
- **目标必须是房间中心**：灯泡装在天花板中央（M11 光源位置 = `room.center`）。射歪的蛛网打不到 ⇒
  不消耗状态（返回 False）。`can_destroy_light` 校验五条：光照开启 + 目标是某房间中心 + 玩家看得见灯
  （`has_line_of_sight`）且在射程内（切比雪夫 ≤ `WEB_LIGHT_RANGE=6`，含脚下——站在灯正下方伸手就能够到）
  + 该灯**尚未被破坏**（碎了的没东西再碎，也避免重复消耗回合）。
- **破坏只移除光源、不新增**：`_light_sources()` 同时跳过 `switched_lights` 与 `destroyed_lights` 里的房间 ⇒
  房间彻底黑暗（M11 暗处缩短怪物感知 + M13 暗处缩短玩家视野——**双刃**：暗处的怪看不远、你也看不远，但暗处你更难被发现）。
  光照场只变暗，不会比 M11 更亮 ⇒ #9/#12/#14 不破：
  - #9：怪物感知半径 ≤ `MONSTER_SIGHT_RADIUS`(7)（只缩短不放大）；
  - #12：光照只缩短怪物感知（恒 ≤ 7）；
  - #14：玩家视野半径 ≤ `SIGHT_RADIUS`(8)（按目标格光照，暗处缩短）。
- **已破坏的灯不可再 toggle**：`can_toggle_light` 对已破坏者直接返回 False（`destroy_light` 顺手把
  `switched_lights` 里的该房间清除——碎了就无所谓开关了）。破坏也可作用于「已关灯」（switched）的房间 ⇒
  永久黑暗、不可恢复。
- **声源在灯处、不在玩家处**：碎裂轻响 `NOISE_SHATTER_BULB=3` 从**灯的位置**传出（不是玩家脚下）⇒
  调虎离山的轻量手段（与 M14 拉链轻响同值、同原则：比垃圾盖 `NOISE_DECOY=9` 轻、只惊动近处的人，但同时把房间弄暗）。
  与 M8「被蛛网弹缠住的怪挣扎出声」同一原则（声源未必是玩家）。
- **不改 M6 的「进房间点亮整间」规则**：碎灯后玩家站在该房间里仍能点亮整间（M6 规则保留）；
  M16 只缩短「跨房间」视野（从走廊看进暗房间看不远），这是预期效果，与 M13「暗处近视」一致。
  改这条规则需要传 `destroyed_lights` 给 `visible_tiles`、动 M6/M13 既有规格，风险高、收益有限。
- **换层重置 `destroyed_lights`**：新楼层 = 新房间 = 新灯泡；与 `explored`/`switched_lights` 清空同一时机（`load_level`）。

## 后果
- 优点：房间灯从「可翻转开关」升级出一条「一次性永久破坏」路径——碎灯后房间彻底黑暗（M11 缩短怪物感知
  + M13 缩短玩家视野，双刃）+ 碎裂轻响引开近处敌人（M8，声源在灯处）。与 M14 翻转式并存，
  玩家按战术需要选「可逆关灯」或「不可逆碎灯」。三条既有光照/听觉系统自然联动，
  无需新机制、无需新开关、无需改既有字形。`--light --stealth` 下「蛛网射碎敌人所在房间的灯泡、永夜摸黑潜行」
  成为一条更彻底的战术选择。
- 取舍：
  - 碎灯是双刃——暗处的怪看不远、**你也看不远**（M13）。碎灯后靠近敌人需配合手电（M12）或
    靠蜘蛛感应（M6 `?` 穿墙预警）导航；
  - 碎裂轻响（3）只惊动近处的人——比垃圾盖（9）轻，调虎离山范围小，但同时把房间弄暗
    （双收益：引开 + 变暗），也只消耗一个回合；
  - 没有让破坏影响蜘蛛感应（`SPIDER_SENSE_RADIUS=4` 穿墙预警不受光照约束，与 M13 一致）；
  - 没有改 M6「进房间点亮整间」规则——站在碎了灯的房间里仍能点亮整间（M6 规则保留），
    碎灯的跨房间效果（走廊看进暗房看不远）已足够展示 M16；
  - 碎裂响度刻意与 M14 拉链持平（3），以保全「已验证的 `--light --stealth` 演示」通关行为不变；
    若后续评估需要更响的玻璃碎裂声，可上调 `NOISE_SHATTER_BULB`（仍走 M8 唯一入口 `emit_noise`）。

## 不变量
- 新增 #16：可破坏的灯纯几何零随机、默认关闭（light=False ⇒ destroy_light 恒返回 False）；
  破坏只移除光源（不新增）⇒ 光照场只变暗，有效半径恒 ≤ `SIGHT_RADIUS`(8) ⇒ #9/#12/#14 不破；
  已破坏的灯不可再 toggle；破坏也可作用于已关灯的房间 ⇒ 永久黑暗、不可恢复；
  声源在灯处（不在玩家处）⇒ M8 调虎离山成立；`destroy_light` 只翻集合 + 重算场，不改写任何玩法状态（换层重置）。
