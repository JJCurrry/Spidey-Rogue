# ADR-013 · 环境光照场与完整光照场分离（M17）

## 状态
已采纳（M17）

## 背景
M11 引入 `light_field`（房间中心固定灯 + 玩家随身微光），M12 追加随身手电、M13 用它按目标格光照算
玩家视野半径、M14/M16 让房间灯可关/可碎。整条光照线都把「静态环境照明（房间灯）」与
「玩家随身光源（微光/手电）」混在**同一份** `light_field` 里。

接力棒给 M16 的候选方向之一即「环境光照场与完整光照场分离（复杂度翻倍、收益有限）」：把
「只看环境光」的场单独拆出来，未来可分别取用，而不必每次从完整场里抠。

约束与 M6~M16 同款：
- 熔断②禁止改/删测试凑绿 ⇒ 既有 432 例不能破；
- 不变量 #1/#2 ⇒ 分离若消耗 `RandomSource`，同一 seed 的既有回放全部作废；
- 不变量 #9 的硬性质「怪看得见你 ⇒ 你看得见它」不能被破坏（光照只缩短、不放大）；
- 不变量 #8 ⇒ `render()` 字形一字不差，新能力默认不改变任何既有渲染/玩法结果；
- 不变量 #12/#14 ⇒ 光照只缩短怪物感知/玩家视野（恒 ≤ 满值）。

## 决策
- **拆成两份场，默认消费点不变**：`update_light()` 同源、幂等重算
  `ambient_field`（仅房间灯）与 `light_field`（房间灯 + 微光 + 手电）。
  M11 怪物感知、M13 玩家视野、`colorize` 渲染梯度**继续只走 `light_field`** ⇒ 这是一次
  **行为零回归**的架构重构，gate 432 → 443、演示逐字节一致。这是 HANDOFF 对候选「收益有限」警告下
  最稳妥的落地方式：先把场拆干净、把不变量钉死，再谈玩法取舍。
- **复用 `light` 开关，不新增开关**：M17 只在 `light=True` 时有意义；`light=False` ⇒
  两份场皆清空，`ambient_level_at` / `light_level_at` 恒返回「明亮」（不引入任何行为差）。
  与 M11「复用 light」、M13/M14「复用 light」同一哲学。
- **环境场不含随身光源**：`_ambient_sources()` = 房间中心固定灯（跳过 `switched_lights`/`destroyed_lights`），
  **不追加**玩家微光 / 手电。这是「环境场」的定义——它代表楼层本身的照明，与蜘蛛侠带没带光无关。
  因此：走廊近处在完整场被微光照亮、在环境场仍全黑，两份场可精确区分。
- **关灯 / 碎灯同时作用于两份场**：`_light_sources` 与 `_ambient_sources` 都跳过 `switched_lights`/`destroyed_lights`
  ⇒ 两份场都「只移除光源、不新增」⇒ 光照场只变暗不变亮 ⇒ #9/#12/#14 不破。
- **纯几何、零随机**：两份场都由 `light.light_field(grid, sources)` 算出，不引入随机模块、不消耗 `RandomSource`、
  不改写 `grid`/HP/背包/怪物状态。`update_light` 幂等（同状态重算同场）⇒ #2 成立。
- **新增只读查询 `ambient_level_at(x, y)`**：与 `light_level_at` 对称（光照关闭恒「明亮」），
  作为「只看环境光」的入口对外暴露。默认不被任何玩法/渲染判定消费——它存在的目的：让后续里程碑
  （如「怪物感知改用环境场」「光照影响蜘蛛感应」）能直接取用，而不必再重构 `light_field` 本身。
- **不改 M6「进房间点亮整间」等既有规则**：分离只新增状态与查询，不动视野/渲染既有规格。

## 后果
- **正向**：光照模型从「一份混装场」升级为「环境场 + 完整场」双场，语义清晰、可分别取用；
  为候选 #1（光照影响蜘蛛感应）、候选 #3（灯开关独立实体）等后续方向铺好地基；
  不变量 #9/#12/#14 在双场下仍由「完整场只缩短不放大」保证。
- **负向 / 成本**：这是一次**架构分离**而非玩法新增——按 HANDOFF 自评「收益有限、复杂度翻倍」。
  直接的即时玩法变化为零（默认消费点不变）。真正的玩法收益（如怪物感知改用环境场）是 C 级后续项，
  **不在 M17 默认开启**，需另立项并重跑 `--light`/`--flashlight` 演示确认平衡不被破坏。
- **可观测性**：新增 `tests/test_ambient_light.py`（11 例）钉死「环境场不含微光/手电」「两份场同时随关灯/碎灯变化」
  「M13/M11 消费点仍走完整场（零回归）」。
- **风险**：若未来某处误用 `ambient_level_at` 替代 `light_level_at`（如怪物感知），会悄悄改变 M11 平衡——
  `tests/test_ambient_light.py::TestMonsterPerceptionUnchanged` 已钉死当前走完整场，改动会被测试拦下。

## 替代方案
- **（弃）直接让 M13 玩家视野改用环境场**：分析表明 M13 按目标格光照逐格判定，完整场与环境场的唯一差异是
  「玩家微光覆盖的近处格」——而这些格本就该被玩家看见，改环境场反而会让贴近玩家的暗处威胁看不见（回归），
  故不采用。
- **（留作 C 级）让 M11 怪物感知改用环境场（仅房间灯 + 手电，不含被动微光）**：能修正「被动微光把附近暗处怪照成近视眼反面」
  的隐性副作用，但会改变 M11 平衡，需重跑演示确认，不在本 ADR 范围。
