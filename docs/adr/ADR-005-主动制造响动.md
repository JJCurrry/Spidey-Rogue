# ADR-005 · 主动制造响动（M9 / 皇后区垃圾桶盖）

## 状态
已采纳（M9）

## 背景
M8 给了怪物「听觉」，也顺带给了玩家一条解法——「调虎离山」：被蛛网弹缠住的怪在挣扎
（`NOISE_STRUGGLE=7`，声源在**它**自己那儿），同伴被引向它而不是你。但这条解法是**被动**的：
唯一的非玩家声源来自「你已经打中了一只怪」之后。想引开巡逻，就得先动手，而动手（蛛网拳
响度 6）已经先把半个视野的人招来了。「引开他们」和「不惊动他们」互相排斥，调虎离山因此
只在「已经开打」之后才成立。

动静是玩家唯一无法主动制造的感知变量。M9 要把它变成玩家的**主动选择**：
先甩一记把敌人聚到走廊那头，再摸掉落单的那只；或者被两只怪夹住时甩一记，把其中一个支开、
逐个击破。

HANDOFF 给 M9 的三个候选本是「光照衰减 / ANSI 颜色 / 主动制造响动」。选**主动制造响动**的理由：
- M8 的 `emit_noise(x, y, loudness)` 已是公开 API，ADR-004 的「后果」里明写「以后要往墙那头
  甩个罐子只需给个入口，不必改传播层」——改动面最小、与上一棒衔接最紧；
- 光照衰减要新增逐格光照数据，会同时碰 M5 与 M6 两条既有规格链；
- 颜色高亮是表现层，纯 ASCII 门禁里难以机器判定。

约束与 M6~M8 同款：
- 熔断②禁止改/删测试凑绿 ⇒ 既有 215 例不能破；
- 不变量 #1/#2 ⇒ 任何新增随机都会让同 seed 的既有回放全部作废。

## 决策
- **载体做成道具「皇后区垃圾桶盖」，挂在 `noise` 开关下**：
  它属于听觉这条链；听觉关掉的世界里没人听得见，它就是占背包的垃圾。
  三个开关仍是「视野 / 潜行 / 听觉」各管一条链，**不新增第四个开关**。
- **诱饵不进掉落表 `ITEM_KEYS`**：
  进表会把 `rng.choice` 的取值域从 3 改成 4，`_randbelow` 的拒绝采样随之改变随机数消耗
  ⇒ 既有三条演示（默认 / 潜行 / 听觉）的回放全部作废。
  改由「听觉开启 ⇒ 开局脚边躺着一个」供给，一个随机数都不碰 ⇒ 听觉模式的楼层生成与 M8
  逐字节相同，回归证据链不断。
- **每层都给一个**：主题自洽（纽约的楼里到处是垃圾），也保证这条机制在演示里至少用得上一次。
- **一次性消耗、不落地留存**：与三明治 / 蛛网芯 / 纳米强化剂同构；若落地可再捡，演示 AI 会陷入
  「甩—捡—甩」循环，回合数失控。
- **投掷是纯几何、零随机**：落点须同时满足——界内且非墙（盖子得落地才响）、
  切比雪夫距离 `1..DECOY_RANGE`（甩在脚下 = 把敌人引到自己身上，是 bug 不是战术）、
  玩家看得见落点（复用 `fov.has_line_of_sight`）。三条任一不满足 ⇒ `can_throw` 为 False、
  `throw_decoy` 返回 `None`、**不消耗道具**。
- **响动仍只经 `emit_noise` 唯一入口生效**：落点处的 `NOISE_DECOY=9`（全场最响，
  比落地声 8 还响一档，因为「为了响而存在」）发出，被惊动者 `last_seen = 落点`，
  不是玩家位置 ⇒ 调虎离山成立；`alert_cause == CAUSE_SOUND` ⇒ 画面上是 `~`。
- **`use_item(index, target=...)`**：`target` 只对诱饵有意义（苍蝇笼要甩到指定落点），
  其余三件道具传不传都一样（向后兼容既有 215 例规格）。落点非法 / 听觉关闭 ⇒ 返回 False 且
  **不消耗**，与「满血不吃三明治」「场上无怪不射蛛网弹」同一条不浪费规则。
- **投掷不造成伤害**：沿用 #10「听觉只惊动、不增伤」——它是战术道具不是武器。
- **新增不变量 #11**：投掷几何纯几何、不消耗 `RandomSource`；响动只经 `emit_noise`
  （→ `Monster.alert(cause=CAUSE_SOUND)`）这一唯一入口生效；诱饵只在听觉开启时出现。
  机器判定见 `tests/test_decoy.py::TestDecoyDeterminism` 与 `::TestThrowGeometry`。

## 后果
- 优点：M8 的「调虎离山」从被动变成主动——玩家第一次能亲手指定听觉链的输入 `(x, y)`；
  `python main.py`（不加 `--noise`）与 `python main.py --stealth` 的玩法日志与 M8 逐字节一致
  （唯一差异是图例那一行多了 `皇后区垃圾桶盖` 的提示语义，但默认/潜行模式根本不刷它，故零差异）。
- 取舍：
  - 听觉模式的演示回合数进一步变长（seed 19 下约 208 回合跑完三层，仍在上限
    `TURNS_PER_LEVEL * MAX_DEPTH = 240` 内）；
  - 落点要求「看得见」让诱饵与视野形成配合——先探路，再甩；隔着房间甩不过去，
    得走到能看见的地方（射程上限 `DECOY_RANGE=6` 是切比雪夫距离）；
  - 未做盖子的多次弹跳 / 残留物（验收 C）：一次性消耗已足够支撑「主动调虎离山」这一件事，
    弹跳只会让落点预测更难、演示 AI 更乱；
  - 光照衰减 / ANSI 颜色高亮仍为下一步候选（见 CLAUDE.md 当前里程碑）。
