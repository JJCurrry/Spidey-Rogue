# ADR-010 · 可开关的房间灯（M14）

## 状态
已采纳（M14）

## 背景
M11 把「光」做成了环境层——房间中心有固定灯、走廊昏暗，暗处的哨兵是近视眼。M12 给了玩家
**随身**手电（玩家处的动态光源），但**房间灯仍是静态的**：玩家无法主动改变房间的亮度。
蜘蛛侠的蛛网发射器本该能「射中天花板灯的拉链」——把静态光源变成可操作的互动元素，
让「光」从环境层升级为玩家可操控的战术工具。

接力棒给 M14 的候选方向之一正是「可开关的房间灯」。约束与 M6~M13 同款：
- 熔断②禁止改/删测试凑绿 ⇒ 既有 342 例不能破；
- 不变量 #1/#2 ⇒ 关灯若消耗 `RandomSource`，同一 seed 的既有回放全部作废；
- 不变量 #9 的硬性质「怪看得见你 ⇒ 你看得见它」不能被破坏（关灯只缩短、不放大）；
- 不变量 #8 ⇒ `render()` 字形一字不差，新能力必须是 opt-in 默认关闭；
- 不变量 #12/#14 ⇒ 光照只缩短怪物感知/玩家视野（恒 ≤ 满值），关灯移除光源 ⇒ 只变暗。

## 决策
- **翻转式（toggle），不是一次性破坏**：「可开关」= 可重复翻转。主题上即蛛网射中灯的拉链——
  拉一下关（房间变暗）、再拉一下开（房间恢复明亮）。这让演示能展示「关灯摸哨 → 开灯清扫」的
  完整战术循环，而不是一次性消耗。状态用 `switched_lights: set[Tile]`（已关灯的房间中心坐标）。
- **复用 `light` 开关，不新增开关**：M14 只在 `light=True` 时有意义；`light=False` ⇒
  `_light_sources` 不含房间灯（关不关都一样，光照场为空）⇒ `toggle_light` 恒返回 False（no-op）。
  与 M13「复用 light、不新增开关」同一哲学。
- **纯几何、零随机**：`toggle_light` 只翻 `switched_lights` 集合 + 重算 `light_field`（`update_fov`）
  + 发出轻响（`emit_noise`，M8 联动）。不引入随机模块、不消耗 `RandomSource`、不改写 `grid`/HP/背包/怪物状态。
  与 `toggle_flashlight`（M12）同一零副作用哲学。
- **目标必须是房间中心**：灯装在天花板中央（M11 光源位置 = `room.center`）。射歪的蛛网打不到拉链 ⇒
  不消耗状态（返回 False）。`can_toggle_light` 校验三条：光照开启 + 目标是某房间中心 + 玩家看得见灯
  （`has_line_of_sight`）且在射程内（切比雪夫 ≤ `WEB_LIGHT_RANGE=6`，含脚下——站在灯正下方伸手就能够到）。
- **关灯只移除光源、不新增**：`_light_sources()` 跳过 `switched_lights` 里的房间 ⇒ 房间变暗
  （M11 暗处缩短怪物感知 + M13 暗处缩短玩家视野——**双刃**：暗处的怪看不远、你也看不远）。
  开灯把光源加回去 ⇒ 恢复明亮。光照场只变暗或恢复，不会比 M11 更亮 ⇒ #9/#12/#14 不破：
  - #9：怪物感知半径 ≤ `MONSTER_SIGHT_RADIUS`(7)（只缩短不放大）；
  - #12：光照只缩短怪物感知（恒 ≤ 7）；
  - #14：玩家视野半径 ≤ `SIGHT_RADIUS`(8)（按目标格光照，暗处缩短）。
- **声源在灯处、不在玩家处**：拉链的轻响 `NOISE_TOGGLE_LIGHT=3` 从**灯的位置**传出（不是玩家脚下）⇒
  可作调虎离山的**轻量**手段（比垃圾盖 `NOISE_DECOY=9` 轻得多、只惊动近处的人，但同时把房间弄暗）。
  与 M8「被蛛网弹缠住的怪挣扎出声」同一原则（声源未必是玩家）。
- **不改 M6 的「进房间点亮整间」规则**：关灯后玩家站在该房间里仍能点亮整间（M6 规则保留）；
  M14 只缩短「跨房间」视野（从走廊看进暗房间看不远），这是预期效果，与 M13「暗处近视」一致。
  改这条规则需要传 `switched_lights` 给 `visible_tiles`、动 M6/M13 既有规格，风险高、收益有限。
- **换层重置 `switched_lights`**：新楼层 = 新房间 = 新灯；与 `explored` 清空同一时机（`load_level`）。

## 后果
- 优点：房间灯从「静态环境」升级为「玩家工具」——关灯缩短暗处敌人感知（M11）+ 缩短玩家自身视野
  （M13，双刃）+ 轻响引开近处敌人（M8，声源在灯处）。三条既有光照/听觉系统自然联动，
  无需新机制、无需新开关、无需改既有字形。`--light --stealth` 下「射灭敌人所在房间的灯、摸黑潜行」
  成为一条真正的战术选择。
- 取舍：
  - 关灯是双刃——暗处的怪看不远、**你也看不远**（M13）。关灯后靠近敌人需配合手电（M12）或
    靠蜘蛛感应（M6 `?` 穿墙预警）导航；
  - 拉链轻响（3）只惊动近处的人——比垃圾盖（9）轻，调虎离山范围小，但同时把房间弄暗
    （双收益：引开 + 变暗），也只消耗一个回合（与甩垃圾盖同）；
  - 没有让关灯影响蜘蛛感应（`SPIDER_SENSE_RADIUS=4` 穿墙预警不受光照约束，与 M13 一致）；
  - 没有改 M6「进房间点亮整间」规则——站在关了灯的房间里仍能点亮整间（M6 规则保留），
    关灯的跨房间效果（走廊看进暗房看不远）已足够展示 M14。

## 不变量
- 新增 #15：可开关房间灯纯几何零随机、默认关闭（light=False ⇒ toggle_light 恒返回 False）；
  关灯只移除光源（不新增）⇒ 光照场只变暗或恢复，有效半径恒 ≤ `SIGHT_RADIUS`(8) ⇒ #9/#12/#14 不破；
  声源在灯处（不在玩家处）⇒ M8 调虎离山成立；`toggle_light` 只翻集合 + 重算场，不改写任何玩法状态（换层重置）。
