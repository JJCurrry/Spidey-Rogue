# 术语表（只收会望文生义的词）

| 词 | 本项目的确切含义 |
|---|---|
| 种子 / seed | 随机源的初始整数；相同 seed ⇒ 相同随机序列（可重现测试） |
| 回合 / turn | 玩家一次行动 + 世界随之推进的单位；不是"游戏时间" |
| 层 / level | 一张地牢地图；不是"等级"。M5 起按 seed 程序化生成，楼层名取纽约都市地标（按层号循环） |
| 房间 / room | 程序化生成的基本单元：一个矩形空地，房间之间用 L 形走廊连通 |
| 走廊 / corridor | 连接两间房的 L 形通道（拐向经 Seed 决定），保证楼层连通（不变量 #7） |
| 楼梯 / stairs | 下行入口，渲染为 `>`。**只是坐标**（`Game.stairs`），不改写 `grid`；站上去才能 `descend()` |
| 下潜 / descend | 走到下一层：重生成地图与实体，保留玩家 HP / 背包 / 纳米加成 |
| 拒绝采样 | 摆房间时「随机取一个位置，与已有房间重叠就丢弃重来」的做法（本项目最多试 80 次） |
| 实体 / entity | 地图上的可交互对象（玩家/怪物/道具），非 OOP 泛指 |
| 玩家 / @ | 本作主角是**蜘蛛侠（Spider-Man）**，具体为 **MCU 荷兰弟（Tom Holland）版**：红蓝战衣、蛛网发射器、年轻敏捷、纽约都市；并非泛指的 generic 玩家，美术/剧情/命名均围绕此版蜘蛛侠 |
| 格子 / tile | 地图的最小单元（墙/地板/玩家） |
| 道具 / item | 地面可拾取物（`Item` 实体，渲染为 `!`）；拾取后进入背包，与地图格子解耦（不改写 grid） |
| 背包 / inventory | 玩家携带的道具列表，容量上限 `INVENTORY_CAPACITY=5`（不变量 #5）；满包拾取失败、道具留在地面 |
| 掉落 / drop | 怪物阵亡时按 Seed 掷骰产生地面道具（概率 `DROP_PROB=0.5`，种类经 `rng.choice`） |
| 束缚 / stun | 蛛网弹命中的附加状态：`Monster.stunned` 层数，>0 时该怪跳过整次行动（不移动、不攻击） |
| 视野 / fov | 玩家可见区域（M6 落地）：半径 `SIGHT_RADIUS=8` 内且无墙遮挡的格子；走进房间点亮整间。**默认关闭**，需 `Game(..., fov=True)` 显式开启 |
| 蜘蛛感应 / spider-sense | M6 主题能力：4 格（切比雪夫）内**穿墙**感知敌人，只显示轮廓 `?`，不显示种类也不揭示地形细节。半径比视野小，是预警不是透视 |
| 记忆 / explored | 走过（看见过）的格子集合，只增不减；记忆里保留地形/楼梯/道具，**不保留**怪物。换层清空 |
| 未探索 / unseen | 从没看见过的区域，渲染为空白（只在开启视野时出现） |
| 教学图 | `Game(rng=...)` 默认使用的 M1 固定 7×5 小图，无楼梯、不可下潜；程序化楼层须显式走 `Game.procedural(rng, depth=1)` |
