# 架构地图（按需查，非必读）

```
roguelike-ai-coding/
├── CLAUDE.md
├── CODEOWNERS
├── main.py                  运行入口：python main.py（M1 移动 + M2 战斗 + M3 怪物 AI + M4 道具演示）
├── scripts/
│   ├── gate.py             L1 墙四道门（seed-guard）
│   ├── review_pipeline.py  评审流水线 5 监理
│   ├── hooks/pre-commit
│   └── gate.{sh,ps1}
├── src/rogue/
│   ├── __init__.py         （导出 Game / Monster / RandomSource）
│   ├── rng.py              ★ 唯一 random 入口（RandomSource，Seed 注入）
│   ├── game.py             M1 移动 + M2 战斗 + M3 怪物 AI + M4 道具：
│   │                       Game / Monster / Item / player_attack / spawn_monster /
│   │                       spawn_item / pick_up / use_item（不含裸随机）
│   └── __main__.py
├── tests/
│   ├── test_game.py        M1 行为规格（7 例）
│   ├── test_combat.py      M2 行为规格（10 例）
│   ├── test_ai.py          M3 行为规格（11 例）
│   └── test_items.py       M4 行为规格（23 例）
└── docs/                   七件套
```

调用关系：`main.py → rogue.Game(rng=RandomSource(seed)) → rogue.rng`。
M2 新增：`Monster`（实体）、`Game.player_attack`（攻击结算，伤害经 `rng.int`）、`Game.spawn_monster`（手摆怪物）。
M4 新增：`Item`（实体）、`Game.items`（地面）/ `Game.inventory`（背包，容量 5）/ `spawn_item`、`pick_up`、`use_item`、`_roll_drop`；`Monster.stunned` 接入 `monster_act`。
随机只从 `rng.py` 流出；`game.py` 不直接引入随机模块——战斗浮动伤害、掉落判定与掉落种类全部走注入的 `RandomSource`。
