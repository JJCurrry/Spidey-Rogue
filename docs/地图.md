调用关系：`main.py → rogue.Game.procedural(rng=RandomSource(seed)) → rogue.level.generate_level → rogue.rng`。
M2 新增：`Monster`（实体）、`Game.player_attack`（攻击结算，伤害经 `rng.int`）、`Game.spawn_monster`（手摆怪物）。
M4 新增：`Item`（实体）、`Game.items`（地面）/ `Game.inventory`（背包，容量 5）/ `spawn_item`、`pick_up`、`use_item`、`_roll_drop`；`Monster.stunned` 接入 `monster_act`。
M5 新增：`tiles.py`（格子常量）、`level.py`（`Room` / `Level` / `generate_level`）、
`Game.load_level` / `_populate_level` / `can_descend` / `descend` / `procedural`，
以及 `Game.rooms` / `Game.stairs` / `Game.depth` / `Game.level_name`。
M6 新增：`fov.py`（`visible_tiles` / `has_line_of_sight` / `bresenham_between` / `in_spider_sense`）、
`Game.fov_enabled` / `visible` / `explored` / `update_fov` / `is_visible` / `is_explored` /
`visible_monsters` / `spider_sense`，以及 `render()` 的两条路径（`_render_full` / `_render_fog`）。
M7 新增：`fov.monster_can_see`（双向视线）、`Monster.alerted` / `alert_turns` / `last_seen` /
`home` 与 `alert()` / `calm()`，`Game.stealth_enabled` / `monster_can_see_player` /
`update_awareness` / `can_sneak_attack` / `web_strike` / `_strike_path` / `hidden` /
`alerted_monsters` / `unaware_monsters`，以及渲染上的 `m`（未察觉）/ `M`（已察觉）区分。

随机只从 `rng.py` 流出；`game.py` 与 `level.py` 都不直接引入随机模块——
战斗浮动伤害、掉落判定与种类、楼层地形与撒点全部走注入的 `RandomSource`。

**两条建局路径**（M5 起）：
- `Game(rng=...)` → M1 固定教学图（7×5，无楼梯），M1~M4 的 51 例规格都跑在这张图上；
- `Game.procedural(rng, depth=N)` 或 `Game(rng=..., level=generate_level(rng, N))` → 程序化楼层
  （33×17，房间+走廊，自动撒怪撒道具，带下行楼梯）。

**两条渲染路径**（M6 起，由 `fov` 开关选择）：
- `fov=False`（**默认**）→ `_render_full()`：整张地图一次画完，M1~M5 的既有规格都跑在这条上；
- `fov=True` → `_render_fog()`：只画已探索区域，未探索为空白，看不见的近处威胁画 `?`。
  视野纯几何、不消耗 `RandomSource`，因此开关视野**不改变任何玩法结果**（不变量 #8）。

**两种玩法模式**（M7 起，由 `stealth` 开关选择）：
- `stealth=False`（**默认**）→ 怪物恒为「已察觉」，M3 的全知追击一字节不变
  （M1~M6 的既有规格与 `python main.py` 演示都跑在这条上）；
- `stealth=True` → 怪物只在看得见你时才会被惊动，未察觉的画 `m`；
  从它看不见的地方荡过去（`web_strike`）即可倒挂突袭。
  感知纯几何、不消耗 `RandomSource`（不变量 #9）；演示需显式 `python main.py --stealth`。
