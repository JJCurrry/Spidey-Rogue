# 架构地图（按需查，非必读）

```
roguelike-ai-coding/
├── CLAUDE.md
├── CODEOWNERS
├── main.py                  运行入口：python main.py
├── scripts/
│   ├── gate.py             L1 墙四道门（seed-guard）
│   ├── review_pipeline.py  评审流水线 5 监理
│   ├── hooks/pre-commit
│   └── gate.{sh,ps1}
├── src/rogue/
│   ├── __init__.py
│   ├── rng.py              ★ 唯一 random 入口（RandomSource，Seed 注入）
│   ├── game.py             M1：格子地图 + 玩家移动（不含随机）
│   └── __main__.py
├── tests/test_game.py      unittest（行为规格）
└── docs/                   七件套
```

调用关系：`main.py → rogue.Game(rng=RandomSource(seed)) → rogue.rng`。
随机只从 `rng.py` 流出；`game.py` 不 import random。
