# 不变量（红线，≤20 条，机器可判定优先）

> 这些是 L1 墙 `seed-guard` 会扫描拦截的硬约束。新增红线请同步改 `scripts/gate.py`。

## 当前生效
1. **随机必须 Seed 注入**：游戏内一切随机（掉落/生成/AI）必须经由 `src/rogue/rng.py` 的 `RandomSource`；禁止在 `src/` 其它文件裸调 `random`/`secrets`/`os.urandom`/`randint`。目的：测试可重现（对应 demo 的 Clock 红线）。
2. **回合确定性**：相同 seed + 相同输入序列 ⇒ 相同结果。任何破坏确定性的隐藏随机源都禁止。
3. **玩家 HP 永不为负**（M2 起生效）：`hp = max(0, hp)` 由引擎保证，业务不得直接写负。
4. **不可越界 / 不可穿墙**：移动必须经过 `Game.move` 的边界与墙检查（M1 GB-1）。道具生成亦同：`spawn_item` 对墙格/越界格返回 `None`（M4）。
5. **背包容量上限（M4 起生效）**：`len(Game.inventory) <= INVENTORY_CAPACITY(=5)`；满包时 `pick_up()` 返回 `None` 且道具**留在地面**，不做自动替换/丢弃。机器判定：`tests/test_items.py::TestInventoryCapacity`。
6. **玩家 HP 不超过上限（M4 起生效）**：一切治疗必须经 `Game._heal_player` 的 `min(max_hp, ...)` 钳制。机器判定：`tests/test_items.py::TestSandwich`。
7. **地图连通性（M5 起生效）**：程序化楼层中，玩家起点经四方向洪泛可达**全部**可通行格。
   - 生成期保证：房间按生成顺序首尾相连成链（L 形走廊），链上必连通；
   - 生成后兜底：`level._seal_unreachable` 把不可达的死口袋回填成墙，故该不变量恒真；
   - 机器判定：`tests/test_level.py::TestConnectivity`（30 个 seed × 不同 depth），自检接口 `Level.is_connected()`。

8. **视野/渲染纯净性（M6 起生效）**：`render()` 只依赖地形 + 实体 + 玩家位置；
   禁止裸随机（沿用 #1），且**不得改写** `grid` / 玩家 / 怪物 / 道具的任何状态。
   唯一例外是「已探索记忆」集合 `explored` 单调增长（`explored |= visible`），
   它不影响任何玩法判定（#2 的随机序列、#3 的 HP、#5 的背包都不受影响）。
   - 视野本身是**纯几何**计算（`src/rogue/fov.py`：Bresenham 射线 + 半径 + 房间照明），
     不消耗 `RandomSource` ⇒ 开不开视野，战斗/掉落/生成的随机序列完全一致；
   - 机器判定：`tests/test_fov.py::TestRenderPurity`（world state 前后快照比对）
     与 `::TestFovDeterminism`（同 seed + 同输入 ⇒ 同画面；开视野不消耗随机）。

## 待生效（后续里程碑补机器检查）
- 怪物属性非负。
- 道具属性非负。

## 怪行为登记
- M3 怪物行为（详见 `docs/工单/T-003-怪物AI.md`）：
  - `chase`（贪心追击）：曼哈顿距离逼近玩家；**完全不消耗 rng**，保持纯确定性（不变量 #2）。
  - `wander`（随机游走）：方向选择经 `self.rng.chance` / `self.rng.choice`（不变量 #1）；`chase` 行为不调 rng。
  - 相邻（切比雪夫距离 1）怪物反击玩家，固定伤害，经 `Game._hurt_player` 钳制 HP ≥ 0（不变量 #3）。
  - 移动经 `_monster_can_enter` 把关：越界/墙/玩家格/其它怪物格均不可入（不变量 #4）。

## 道具登记（M4）
- 掉落判定 `rng.chance(DROP_PROB)` → 种类 `rng.choice(ITEM_KEYS)`，均经 `self.rng`（不变量 #1）；只在「怪物阵亡」这一确定性事件上掷骰（不变量 #2）。
- 效果（详见 `docs/工单/T-004-道具与背包.md`）：
  - `sandwich` 梅姨的三明治：回血，经 `_heal_player` 钳制（不变量 #6）；满血时不消耗。
  - `web_cartridge` 蛛网发射器备用芯：对最近存活怪 5 点伤害 + `stunned=1`。
  - `nano_boost` 斯塔克纳米强化剂：`player_dmg_bonus += 2`（本局内累加）。
- 束缚：`Monster.stunned > 0` 时 `monster_act` 直接消耗一层并返回，**不移动、不攻击、不消耗 rng**（保持 #2 纯确定性）。
- 一格只放一个道具：`spawn_item` 遇到该格已有道具返回 `None`。

## 视野登记（M6）
- 视野在 `src/rogue/fov.py`：Bresenham 射线判遮挡 + 半径 `SIGHT_RADIUS=8` + 「进房间点亮整间」（复用 `Game.rooms`）；**纯几何、零随机**（不变量 #1/#2）。
- 蜘蛛感应 `SPIDER_SENSE_RADIUS=4`（切比雪夫、**穿墙**）：看不见的怪物画成 `?`，只给轮廓不给种类；半径刻意小于视野，是预警不是透视。
- 视野是**可选开关**：`Game(..., fov=False)` 默认关闭 ⇒ `render()` 仍是全图（M1~M5 的既有规格都跑在这条路径上）；`fov=True` 才走迷雾渲染。
- 渲染优先级（后者覆盖前者）：蜘蛛感应 `?` < 楼梯 `>` < 道具 `!` < 怪物 `M` < 玩家 `@`（沿用 M5 的 楼梯<道具<怪物<玩家）。
- 记忆规则：地形 / 楼梯 / 道具一旦看见就留在记忆里（它们不动）；**怪物只在当前可见时绘制**（怪物会跑，记忆会骗人）。
- 换层即失忆：`load_level` 清空 `explored`（上一层的记忆对新楼层无意义）。

## 楼层生成登记（M5）
- 地形生成在 `src/rogue/level.py`，随机只来自注入的 `RandomSource`（不变量 #1）；`level.py` 与 `game.py` 都不直接引入随机模块（seed-guard 拦截）。
- 生成流程：拒绝采样摆房间 → 按生成顺序连成链（L 形走廊，拐向经 `rng.chance`）→ 额外环路 → 定起点与楼梯 → 洪泛封填死口袋（不变量 #7）。
- 楼层尺寸 33×17、房间 4~8 × 3~5、最多 7 间；外圈恒为墙（不变量 #4）。
- 楼梯是**坐标属性** `Game.stairs`，**不写进 `grid`**（与道具同属实体层渲染，见假设 C/E）；玩家离开楼梯格后 `grid` 恢复为地板，楼梯仍在原处。
- 下潜：`can_descend()` 仅在站上楼梯时为真；`descend()` 重生成下一层、重置地图与实体，**保留**玩家 HP / 背包 / 纳米加成（M2/M4 状态跨层继承）。
- 撒点：非起始房间以 `MONSTER_ROOM_PROB` 判定「有没有怪」、再刷 1~2 只；整层保底 1 只；道具按 `ITEM_ROOM_PROB` 撒，复用 M4 的 `spawn_item`（不变量 #4/#5）。
